- 下载[人民教育出版社](https://jc.pep.com.cn)教材。


- 中小学人教版教材下载,请勿滥用,支持正版
  - 来源于github的一个开源项目github原项目 https://github.com/Senkita/Textbook-Crawler
  - 这个项目的好处是内容来来自于人教版官网,内容质量比较一致,获取的教材版本是最新的(虽然教材好多年才更新一次)
  - 下载的图片体积比较大,有些整本的电子版压缩的比较小,这里如果有需要的需要自己压缩

- 我给加一个重命名每个页面的脚本,方便合并为pdf文件
- 并且在text.jsonc中添加了初中数学的相关教材

#### Installation

```bash
pip install json5 requests Pillow
```

```bash
python main.py 信息技术选修二 1452001132201 136 # 书名 ID 总页数
python main.py # 需自行先在`textbooks.jsonc`中添加目标书籍信息
```
