单链表去重比较麻烦,因为单链表前进容易后退必须重新扫描链表

对于单链表数据都是正整数的情况下,利用一个辅助数组$q$来记录出现过的数据是改进算法时间复杂度的有效手段

若假设单链表中的数据都是正整数,并且不超过n,那么可以设立一个包含$n+1$个元素的整型数组(需要统计$0\sim{n}$共$n+1$个数)

辅助数组$q$每个计数器都初始化为0;在扫描单链表时,如果检查结点内的数据在数组中是否出现

```c
if(q[p->data]==0){
    q[p->data]++;
}else{
    //remove p node;
}
```

单链表节点的C语言数据类型定义:
```c
typedef struct node {
    int data;
    struct node *link;
} NODE;
typedef NODE *PNODE;//定义Node指针类型
```

算法实现如下：

如果链表中出现负整数,将其去绝对值(取相反数),对绝对值相同结点进行去重操作

```c
void func (PNODE h, int n) {
    PNODE p = h, r;//初始化p为h;定义未初始化指针变量r,用来辅助删除结点操作;
    int *q, m;
    q = (int *)malloc(sizeof(int) * (n + 1)); // 申请 n+1 个位置的辅助空间(使用动态申请的方式申请)
    for (int i = 0; i < n + 1; i++) {
        *(q + i) = 0; // 数组元素初值置 0
    }
    //检查并处理重复出现的元素,p是要被删除的结点的前驱
    //while中检查p的后继结点是否为空,如果不为空继续处理,否则表明p是最后一个结点,p的后继是空,无需删除
    while (p->link != NULL) {//从首元开始
        //将负整数处理为正整数
        m = p->link->data > 0 ? p->link->data : -p->link->data;
        //根据C语言语法,q[m]和*(q+m)效果相同
        //检查p的后继结点的数据是否出现过,没有则记录,否则删除p的后继(p->link)
        if (*(q + m) == 0) { // 判断该节点的 data 是否已出现过
            *(q + m) = 1; // 首次出现
            p = p->link; // 保留,并处理下一个结点
        } else { // 重复出现|m|值
            r = p->link;//p的后继赋值给临时指针r供后续free
            p->link = r->link;//更新后继
            free(r); // 释放结点r的空间
        }
    }
    free(q);
}
```
