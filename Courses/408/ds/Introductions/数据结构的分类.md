## abstract

在数据结构中，线性结构（Linear Structure）和非线性结构（Non-linear Structure）是两类主要的结构类型。这两者的区别在于数据元素之间的关系和存储方式。

## 数据结构三要素

### 数据的逻辑结构

**逻辑结构**是指**数据元素**之间的**逻辑关系**，即从**逻辑关系上描述数据**。

**它与数据的存储无关**，是**独立于计算机**的。(然而,存储结构却不是独立于逻辑结构的,解决问题是,先设计逻辑结构,然后考虑实现(存储结构),总是虽然说逻辑结构独立于存储结构,但不表示两者相互独立,有先后确定只别)

数据的逻辑结构分为线性结构和非线性结构，线性表是典型的线性结构;集合、树和图是典型的非线性结构。

- 集合。结构中的数据元素之间除“同属一个集合”外，别无其他关系
- 线性结构。结构中的数据元素之间只存在一对一的关系
- 树形结构。结构中的数据元素之间存在一对多的关系

- 图状结构或网状结构。结构中的数据元素之间存在多对多的关系

例如

- 顺序表、哈希表和单链表是三种不同的数据结构，既描述逻辑结构，又描述存储结构和数据运算。

- **有序表**是指**关键字有序**的线性表，**仅描述元素之间的逻辑关系**，它既可以链式存储，又可以顺序存储，所以属于逻辑结构。

### 数据的存储结构

存储结构是指数据结构在计算机中的表示（又称映像），也称物理结构。它包括数据元素的表示和关系的表示。

数据的存储结构是用**计算机语言实现**的逻辑结构，它**依赖于计算机语言**。

数据的存储结构主要有顺序存储、链式存储、索引存储和散列存储。

1）顺序存储。把逻辑上相邻的元素存储在物理位置上也相邻的存储单元中，元素之间的关系由存储单元的邻接关系来体现。其优点是可以实现随机存取，每个元素占用最少的存储空间：缺点是只能使用相邻的一整块存储单元，因此可能产生较多的外部碎片。

2）链式存储。不要求逻辑上相邻的元素在物理位置上也相邻，借助指示元素存储地址的指针来表示元素之间的逻辑关系。其优点是不会出现碎片现象，能充分利用所有存储单元：缺点是每个元素因存储指针而占用额外的存储空间，且只能实现顺序存取。

3）索引存储。在存储元素信息的同时，还建立附加的索引表。索引表中的每项称为索引项，索引项的一般形式是（关键字，地址）。其优点是检索速度快：缺点是附加的索引表额外占用存储空间。另外，增加和删除数据时也要修改索引表，因而会花费较多的时间。

4）散列存储。根据元素的关键字直接计算出该元素的存储地址，又称哈希（Hsh）存储。其优点是检索、增加和删除结点的操作都很快：缺点是若散列函数不好，则可能出现元素存储单元的冲突，而解决冲突会增加时间和空间开销

### 思考

01.对于两种不同的数据结构，逻辑结构或物理结构一定不相同吗？
02.试举一例，说明对相同的逻辑结构，同一种运算在不同的存储方式下实现时，其运算效率不同。

01.【解答】
应该注意到，数据的运算也是数据结构的一个重要方面。
对于两种不同的数据结构，它们的逻辑结构和物理结构完全有可能相同。比如二叉树和二叉排序树，二叉排序树可以采用二叉树的逻辑表示和存储方式，前者通常用于表示层次关系，而后者通常用于排序和查找。虽然它们的运算都有建立树、插入结点、删除结点和查找结点等功能，但对于二义树和二义排序树，这些运算的定义是不同的，以查找结点为例，二叉树的平均时间复杂度为$O(n)$,而二叉排序树的平均时间复杂度为$O(\log_{2}{n})$
02.【解答】
线性表既可以用顺序存储方式实现，又可以用链式存储方式实现。在顺序存储方式下，在线性表中插入和删除元素，平均要移动近一半的元素，时间复杂度为$O(n)$:而在链式存储方式下，插入和删除的时间复杂度都是$O(1)$

### 数据的运算

施加在数据上的运算包括运算的定义和实现。运算的定义是针对逻辑结构的，指出运算的功能；运算的实现是针对存储结构的，指出运算的具体操作步骤。

## 数据结构基本分类

### 线性结构

线性结构指的是数据元素按顺序依次排列的结构，在**这种结构中，每个数据元素只有一个前驱（Predecessor）和一个后继（Successor）**。

线性结构主要包括数组（Array）、链表（Linked List）、栈（Stack）和队列（Queue）等。

#### 数组（Array）
- **概念**：数组是一组相同类型数据元素的集合，每个元素在内存中按照连续的方式排列，且可以通过下标（Index）快速访问。
- **特点**：随机访问时间复杂度为 \(O(1)\)，但插入、删除需要移动元素，导致时间复杂度为 \(O(n)\)。
- **应用**：常用于需要快速访问和存储连续数据的场景，如缓存、静态表等。

#### 链表（Linked List）
- **概念**：链表是一种线性结构，每个节点包含数据和指向下一个节点的指针，典型类型包括单链表（Singly Linked List）、双向链表（Doubly Linked List）等。
- **特点**：插入、删除操作时间复杂度为 \(O(1)\)，但查找操作的时间复杂度为 \(O(n)\)。
- **应用**：适用于需要频繁插入和删除操作的数据集合，如动态存储管理、队列等。

#### 栈（Stack）
- **概念**：栈是一种后进先出（LIFO, Last In First Out）的线性结构，仅允许在一端（栈顶）进行插入和删除操作。
- **特点**：插入、删除操作时间复杂度为 \(O(1)\)。
- **应用**：常用于递归问题、语法分析、表达式求值等。

#### 队列（Queue）
- **概念**：队列是一种先进先出（FIFO, First In First Out）的线性结构，仅允许在一端（队尾）插入，另一端（队头）删除。
- **特点**：插入、删除操作时间复杂度为 \(O(1)\)。
- **应用**：常用于需要按顺序处理任务的场景，如任务调度、消息队列等。

### 非线性结构

非线性结构则指数据元素之间存在一对多或多对多的关系，常见的有树（Tree）结构和图（Graph）结构。这类结构更复杂，适合表示层级关系和网络关系。

#### 树（Tree）
- **概念**：树是一种具有层次关系的非线性结构，由节点（Node）和边（Edge）组成。每个节点有零个或多个子节点，且只有一个父节点（Root）没有父节点。
- **特点**：树结构可以有效地组织和管理具有层次关系的数据，常用遍历方式有前序、中序、后序等。
- **类型**：常见树结构包括二叉树（Binary Tree）、二叉搜索树（Binary Search Tree, BST）、平衡树（如AVL树）、B树等。
- **应用**：广泛应用于文件系统、数据库索引、表达式解析等领域。

#### 图（Graph）
- **概念**：图是一种更复杂的非线性结构，由顶点（Vertex）和边（Edge）组成，可以表示数据元素间的任意关系。
- **特点**：图没有层级限制，顶点可以相互连接形成循环。根据边的方向性分为有向图（Directed Graph）和无向图（Undirected Graph），根据权值分为加权图（Weighted Graph）和非加权图（Unweighted Graph）。
- **应用**：广泛用于社交网络、路径搜索（如地图）、推荐系统等。

### 线性结构和非线性结构的比较

| 比较维度     | 线性结构                     | 非线性结构                       |
| ------------ | ---------------------------- | -------------------------------- |
| 数据关系     | 每个元素有唯一前驱和唯一后继 | 元素之间存在多对多的复杂关系     |
| 存储方式     | 一般为顺序存储或链式存储     | 多采用链式存储                   |
| 典型数据结构 | 数组、链表、栈、队列         | 树、图                           |
| 适用场景     | 适合有顺序要求的数据处理     | 适合复杂的层级和网络关系数据     |
| 常见操作效率 | 访问较快，插入、删除较慢     | 插入、删除复杂，遍历操作灵活性高 |

### 总结
线性结构的核心在于顺序性，而非线性结构更注重表示数据间的复杂关系。对于线性结构，主要关注如何高效地进行插入、删除和查找；对于非线性结构，更强调如何管理和遍历复杂的数据关系。

## 2.1.1 线性表的定义

线性表是具有相同数据类型的$n(n\ge 0)$个数据元素的有限序列，其中{n}为表长，当{n}=0 时线性表是一个空表。若用{L}命名线性表，则其一般表示为
$$L=(a_{1},a_{2},\cdots,a_{i},a_{i+1},\cdots,a_{n})$$ 
式中，$a_{1}$是唯一的“第一个”数据元素，又称表头元素；$a_{n}$是唯一的“最后一个”数据元素，又称表尾元素。除第一个元素外，每个元素有且仅有一个直接前驱。除最后一个元素外，每个元素有且仅有一个直接后继(“直接前驱”和“前驱”、“直接后继”和“后继”通常被视为同义词)。

以上就是线性表的逻辑特性，这种线性有序的逻辑结构正是线性表名字的由来。

### 线性表的特点

- 表中元素的个数有限。
- 表中元素具有逻辑上的顺序性，表中元素有其先后次序。
- 表中元素都是数据元素，每个元素都是单个元素。
- 表中元素的数据类型都相同，这意味着每个元素占有相同大小的存储空间。
- 表中元素具有抽象性，即仅讨论元素间的逻辑关系，而不考虑元素究竟表示什么内容。

线性表是一种**逻辑结构**，表示**元素之间一对一的相邻关系**。

顺序表和链表是指**存储结构**

线性表（Linear List）的存储方式分为两大类：**顺序存储**和**链式存储**，而链式存储又分为多种类型。下面逐一介绍相关概念：

## 线性表

线性表是指一种有序的数据元素集合，在该结构中，每个数据元素除了第一个元素之外有且只有一个前驱，除了最后一个元素之外有且只有一个后继。线性表可以通过两种主要方式来实现：顺序存储和链式存储。

#### 顺序存储
- **概念**：顺序存储是指将线性表中的数据元素按顺序存储在计算机内存中的一段连续地址空间中。每个元素的相对位置由其物理地址决定，因此可以通过下标快速访问元素。
- **优点**：顺序表可以通过下标 \(O(1)\) 时间复杂度快速访问任意位置的元素。
- **缺点**：插入和删除操作不够灵活，尤其是在中间位置插入或删除元素时，需要移动大量数据元素，时间复杂度为 \(O(n)\)。

#### 链式存储
链式存储是通过指针或引用将元素连接在一起，存储在内存中不连续的地址位置。链式存储的优点是插入和删除操作更加灵活，链表中的元素可以动态分配和释放内存。链式存储进一步分为以下几种类型：

1. **单链表（Singly Linked List）**：
   - **概念**：每个节点包含数据和指向下一个节点的指针。链表的头节点指向第一个元素，最后一个节点的指针为空（NULL），即没有后继节点。
   - **优点**：插入和删除操作的时间复杂度为 \(O(1)\)，可以动态调整长度。
   - **缺点**：只能单向遍历，访问任意节点的时间复杂度为 \(O(n)\)。

2. **双向链表（Doubly Linked List）**：
   - **概念**：与单链表不同，双向链表中的每个节点包含指向前一个节点和后一个节点的指针。因此可以在链表中进行双向遍历。
   - **优点**：不仅支持从前向后的遍历，还可以从后向前遍历，灵活性更强。
   - **缺点**：每个节点需要存储两个指针，占用更多的内存。

3. **循环链表（Circular Linked List）**：
   - **概念**：在单链表或双向链表的基础上，将链表的尾节点指向头节点，使链表形成一个环形结构。
   - **优点**：可以从尾部循环回到头部，无需在遍历时区分头尾节点。
   - **缺点**：处理边界条件时较为复杂，遍历时需要避免无限循环。

4. **静态链表（Static Linked List）**：
   - **概念**：使用数组来模拟链表结构，即通过数组下标表示指针。虽然数组是顺序存储，但通过数组元素中的“游标”或“指针”来指向下一个节点，形成链表的效果。
   - **优点**：利用数组实现链表，避免了内存的动态分配问题，尤其在一些内存管理复杂的系统中应用广泛。
   - **缺点**：仍然受限于数组的大小，不如动态链表灵活。

### 总结
线性表的存储方式直接影响数据操作的效率和复杂性。顺序存储适合需要快速随机访问的场景，而链式存储则更适合频繁的插入和删除操作。根据应用场景的不同，可以选择不同的链式存储方式，如单链表、双向链表或循环链表。
