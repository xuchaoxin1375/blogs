## abstract

要通过遍历序列构造二叉树，通常需要两种遍历序列的组合。常见的方法包括利用**前序遍历 (Preorder)**、**中序遍历 (Inorder)** 和**后序遍历 (Postorder)**的组合。以下是构造二叉树的步骤和示例。

### 利用前序和中序遍历构造二叉树

前序遍历的特点是：根节点在第一个位置。
中序遍历的特点是：根节点的左子树和右子树分布在根的两侧。

#### 算法步骤

1. 从前序遍历中获取当前子树的根节点。
2. 在中序遍历中定位该根节点，分割中序遍历序列为左子树和右子树。
3. 递归处理左子树和右子树，继续分割序列。

#### 示例代码（Python）

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def build_tree(preorder, inorder):
    if not preorder or not inorder:
        return None

    # 前序遍历的第一个节点是根节点
    root_val = preorder.pop(0)
    root = TreeNode(root_val)

    # 找到根节点在中序遍历中的位置
    idx = inorder.index(root_val)

    # 分割中序遍历：左子树和右子树
    root.left = build_tree(preorder, inorder[:idx])
    root.right = build_tree(preorder, inorder[idx + 1:])

    return root

# 示例
preorder = [3, 9, 20, 15, 7]
inorder = [9, 3, 15, 20, 7]
root = build_tree(preorder, inorder)
```

### 利用后序和中序遍历构造二叉树

后序遍历的特点是：根节点在最后一个位置。
中序遍历的特点是：根节点的左子树和右子树分布在根的两侧。

#### 算法步骤

1. 从后序遍历中获取当前子树的根节点（最后一个元素）。
2. 在中序遍历中定位该根节点，分割中序遍历序列为左子树和右子树。
3. 递归处理右子树和左子树（注意，后序遍历的处理顺序是先右后左）。

#### 示例代码（Python）

```python
def build_tree_post_in(postorder, inorder):
    if not postorder or not inorder:
        return None

    # 后序遍历的最后一个节点是根节点
    root_val = postorder.pop()
    root = TreeNode(root_val)

    # 找到根节点在中序遍历中的位置
    idx = inorder.index(root_val)

    # 分割中序遍历：右子树和左子树
    root.right = build_tree_post_in(postorder, inorder[idx + 1:])
    root.left = build_tree_post_in(postorder, inorder[:idx])

    return root

# 示例
postorder = [9, 15, 7, 20, 3]
inorder = [9, 3, 15, 20, 7]
root = build_tree_post_in(postorder, inorder)
```

### 注意事项

1. **唯一性假设**：构造二叉树需要假设树中没有重复值。如果有重复值，需要额外信息区分。
2. **递归结束条件**：遍历序列为空时返回`None`。
3. **时间复杂度**：每次查找根节点在中序遍历中的索引，最坏情况下是`O(n)`，整体时间复杂度为`O(n^2)`。可以使用哈希表优化为`O(n)`。

 

| 遍历组合    | 特点                     |
| ----------- | ------------------------ |
| 前序 + 中序 | 根节点在前序第一个元素   |
| 中序 + 后序 | 根节点在后序最后一个元素 |
| 前序 + 后序 | 无法唯一确定一棵二叉树   |

### 层序遍历和中序遍历构造二叉树

层序遍历（Level-order）和中序遍历（Inorder）序列也可以用来构造二叉树。层序遍历提供了节点按层的顺序，中序遍历提供了子树的划分信息。

#### 算法思路

1. 层序遍历的第一个元素是整棵树的根节点。
2. 在中序遍历中定位根节点，将中序序列分割为左子树和右子树。
3. 根据层序遍历的顺序，依次将剩余的节点分配到左右子树。
4. 使用队列（Queue）来逐层构造左右子树。

#### 示例代码（Python）

```python
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def build_tree_level_in(levelorder, inorder):
    if not levelorder or not inorder:
        return None

    # 根节点是层序遍历的第一个元素
    root_val = levelorder.pop(0)
    root = TreeNode(root_val)

    # 在中序遍历中找到根节点位置
    idx = inorder.index(root_val)

    # 分割中序遍历为左子树和右子树
    left_inorder = inorder[:idx]
    right_inorder = inorder[idx + 1:]

    # 队列用于辅助分配左右子树节点
    queue = deque([root])
    while queue:
        node = queue.popleft()
        if left_inorder:
            # 找出层序中第一个属于左子树的节点
            for i in range(len(levelorder)):
                if levelorder[i] in left_inorder:
                    node.left = TreeNode(levelorder.pop(i))
                    queue.append(node.left)
                    break
        if right_inorder:
            # 找出层序中第一个属于右子树的节点
            for i in range(len(levelorder)):
                if levelorder[i] in right_inorder:
                    node.right = TreeNode(levelorder.pop(i))
                    queue.append(node.right)
                    break

    return root

# 示例
levelorder = [3, 9, 20, 15, 7]
inorder = [9, 3, 15, 20, 7]
root = build_tree_level_in(levelorder, inorder)
```

#### 算法说明

1. 根节点识别
   - 层序遍历的第一个元素为根节点。
2. 左右子树划分
   - 利用中序遍历划分为左子树和右子树。
3. 节点分配
   - 层序遍历的顺序提供了节点构造的优先级。
   - 利用队列逐层将节点分配到左右子树。

#### 时间复杂度

1. **中序分割**：`O(n)`（每次查找根节点在中序中的位置）。
2. **层序分配**：`O(n)`（每个节点在队列中被访问一次）。
3. **总体复杂度**：`O(n^2)`，可以通过哈希表优化中序查找为`O(n)`，使总复杂度为`O(n)`。
