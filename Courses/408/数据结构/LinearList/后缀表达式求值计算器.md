## abstract

栈（stack）是一种非常适合用于解决表达式求值问题的数据结构，特别是对于中缀表达式、后缀表达式（逆波兰表示法）和前缀表达式等计算。后缀表达式是运算符位于操作数之后的一种表示法。在后缀表达式中，不需要括号来指明运算顺序，运算顺序完全由运算符的位置决定。栈的使用可以有效地处理这些表达式。

在这里，我们主要讨论如何使用栈来计算后缀表达式（Reverse Polish Notation, RPN）的值。

后缀表达式的求值算法比中缀表达式转后缀表达式转换算法要简单

- 后缀表达式没有括号这类东西需要处理,需要注意到是运算符两侧操作数的顺序和栈中弹出的两个操作数的对应关系,栈顶操作数对应于运算符的第一二个操作数

- 例如依次弹出`o1,o2`,配给二元运算符`op`,则`o2 op o1`;举个最简单的例子:`a-b`对应的后缀表达式为`ab-`,操作数栈中依次入`ab`(第一个操作数先压入,第二个操作数后压入,而后压入的先弹出,所以先弹出的是第二个操作数),还原为中缀表达式`a-b`计算后压回栈中

综合中缀表达式转后缀表达式算法和后缀表达式算法,就可以得到中缀表达式的算法(利用栈实现的适合机器运行的算法)

## 后缀表达式求值算法

通过后缀表示计算表达式值的过程：从左往右依次扫描表达式的每一项，若该项是操作数，则将其压入栈中：若该项是操作符`<op>`,则从栈中退出两个操作数Y和X,形成运算指令`X <op> Y`,并将计算结果压入栈中。

当所有项都扫描并处理完后，栈顶存放的就是最后的计算结果。

例如，后缀表达式 `3 4 + 2 * 7 /` 表示的数学表达式是 `((3 + 4) * 2) / 7`。

## 求值过程

我们可以按照以下步骤来利用栈计算后缀表达式：

1. **遍历表达式中的每个字符**：
   - 如果是操作数（数字），将其压入栈中。
   - 如果是运算符（如 `+`, `-`, `*`, `/` 等），则弹出栈顶的两个操作数(注意操作数顺序,栈顶数作为运算符的第二个操作数,次栈顶作为第一个操作数)，进行运算，然后将结果压入栈中。
2. **最终栈中只会剩下一个元素**，即为表达式的最终结果。

### 示例代码（Python）

下面是一个简单的 Python 实现，展示如何使用栈来计算后缀表达式的值：

```python
def evaluate_postfix(expression):
    stack = []
    # 遍历每个字符
    for token in expression.split():
        if token.isdigit():  # 如果是数字，压入栈
            stack.append(int(token))
        else:  # 如果是运算符，弹出栈顶元素进行计算
            b = stack.pop()
            a = stack.pop()
            if token == '+':
                stack.append(a + b)
            elif token == '-':
                stack.append(a - b)
            elif token == '*':
                stack.append(a * b)
            elif token == '/':
                stack.append(a / b)
    # 栈中最后剩下的元素就是结果
    return stack[0]

# 测试后缀表达式
expression = "3 4 + 2 * 7 /"
result = evaluate_postfix(expression)
print("Result:", result)
```

### 解释：

1. **初始化一个栈**，然后遍历表达式中的每个元素（使用空格分隔）。
2. **数字处理**：如果当前元素是数字，就将其转换为整数并压入栈。
3. **运算符处理**：如果当前元素是运算符，就从栈中弹出两个操作数，进行运算，然后将结果重新压入栈。
4. **结束时，栈中只有一个元素**，它就是最终的计算结果。

### 示例解析

以表达式 `"3 4 + 2 * 7 /"` 为例：

1. 第一个操作数 `3` 被压入栈中，栈变为 `[3]`。
2. 第二个操作数 `4` 被压入栈中，栈变为 `[3, 4]`。
3. 运算符 `+` 被遇到，弹出栈顶的两个数 `3` 和 `4`，进行加法运算，结果为 `7`。将 `7` 压入栈中，栈变为 `[7]`。
4. 操作数 `2` 被压入栈中，栈变为 `[7, 2]`。
5. 运算符 `*` 被遇到，弹出栈顶的两个数 `7` 和 `2`，进行乘法运算，结果为 `14`。将 `14` 压入栈中，栈变为 `[14]`。
6. 操作数 `7` 被压入栈中，栈变为 `[14, 7]`。
7. 运算符 `/` 被遇到，弹出栈顶的两个数 `14` 和 `7`，进行除法运算，结果为 `2.0`。将 `2.0` 压入栈中，栈变为 `[2.0]`。
8. 最终栈中的元素 `2.0` 就是表达式的结果。

### 扩展

栈不仅可以用于后缀表达式，还可以用于中缀表达式和前缀表达式的求值。不过，对于中缀表达式，我们通常需要首先将其转换为后缀表达式，然后再使用栈来求值。

栈解决表达式求值的优势在于能够有效地处理操作数和运算符的顺序，尤其是在没有括号的情况下，能够确保运算的优先级和顺序得到正确执行。

## 例

利用栈求表达式的值时，设立运算数栈OPEN(operand)。假设OPEN只有两个存储单元，则在下列表达式中，不会发生溢出的是（B）
A. `A-B*(C-D)` 

B. `(A-B)*C-D` 

C. `(A-B*C)-D` 

D. `(A-B)*(C-D)` 

不溢出的条件下,A,B,C,D分别至少需要4,2,3,3个存储单元的OPEN栈

分析:基本思路是将中缀表达式化为后缀表达式,以A为例:`ABCD-*-`算法开始时需要入栈的有`ABCD`4个元素

又比如D:`AB-CD-*`,开始AB入栈和运算符`-`计算得到`A-B=X`,`X`压回栈中,此时栈内有1个元素,`C,D`两个元素入栈后栈内有3个元素,和后续的`-`运算弹出两个元素`C,D`计算`C-D=Y`,`Y`压回栈中,遇到`*`弹出`Y,X`计算`*`得到最终结果`X*Y`
