### 字符串逆序存放并输出

```c
/* 字符串逆序存放并输出
假设字符串长度不超过999
*/
#include <stdio.h>
#include <string.h>

int main()
{
    const int size = 1000;
    char a[size], t;
    int len;

    printf("请输入一个字符串:\n");
    scanf("%s", a);
    len = strlen(a);
    // 字符序列左半边元素数量为len/2,无论len为奇数还是偶数
    // 交换字符序列左半边和右半边的元素,从收尾对开始交换
    for (int i = 0; i < len / 2; i++)
    {
        t = a[i];
        a[i] = a[len - 1 - i];
        a[len - 1 - i] = t;
    }
    printf("%s", a);
}
```

### 数组元素循环左移

设序列$a_{0},a_{1},\cdots,a_{p-1},\cdots,a_{n-1}$这$n$个元素中前$p$个元素记为序列$A$,后$n-p$个元素记为$B$,则数组内元素循环左移$p$位后,数组内前$n$个元素序列为$B,A$,简记为$BA$

基本思路有3中,借助一个辅助变量,逐次移位,每次移位将第一个元素存到辅助变量里,移位完成后将辅助变量内的值放回元素末尾,这种方法效率不高

另一种思路是借助一个辅助数组($p$个元素),将原序列前$p$个元素备份到辅助元素中,将剩余序列一次性移动$p$位,最后将辅助序列中的元素复制回原序列的末尾$p$个位置

此方法时间复杂度为$O(n)$,空间复杂度为$O(p)$

还可以通过拆分逆序的方法来实现$AB\to{BA}$,分别将$A,B$原地逆序,得到$A^{-1}B^{-1}$,然后对$A^{-1}B^{-1}$再做一次整体逆序,得到$BA$

其中逆序的方法先计算要逆序的序列元素范围,用数组内的下标为位置区间表示$[p,q]$,然后逆序操作就是对序列的左半边的元素和右半边元素交换,交换次数为序列长度的一半(向下取整)

确定逆序操作的次数后,用循环变量$i=0,\cdots,(p+q)/2$表达式作为交换元素的下标($p+i$,$q-i$)

元素交换的写法有多种,下面列出三种

```c
#include <stdio.h>

// 反转数组a中从索引p到q的部分
// 参数:
//   a: 指向数组的指针
//   p: 起始索引
//   q: 结束索引
void reverse(int *a, int p, int q)
{
    // 遍历数组的前半部分，交换对称位置的元素
    for (int i = 0; i < (q - p + 1) / 2; i++)
    {
        // 方案1:普通方案(写法简单,推荐)
        // 交换当前索引和对称索引处的元素
        int tmp = a[p + i];
        a[p + i] = a[q - i];
        a[q - i] = tmp;

        // 方案2:使用数组和异或运算(采用亦或方案需要的辅助空间位0,但是空间复杂度仍然记为O(1)(常数级))
        // 通过异或运算交换元素，无需额外变量
        // a[p + i] = a[p + i] ^ a[q - i];
        // a[q - i] = a[p + i] ^ a[q - i];
        // a[p + i] = a[p + i] ^ a[q - i];

        // 方案3:使用指针和异或运算
        // 通过指针和异或运算交换元素，无需额外变量
        // *(a + p + i) = *(a + p + i) ^ *(a + q - i);
        // *(a + q - i) = *(a + p + i) ^ *(a + q - i);
        // *(a + p + i) = *(a + p + i) ^ *(a + q - i);
    }
}

int main()
{
    const int size = 10;
    int a[size];
    for (int i = 0; i < size; i++)
    {
        a[i] = i + 1;
    }

    int shift = 4;
    reverse(a, 0, shift - 1);
    reverse(a, shift, size - 1);
    reverse(a, 0, size - 1);
    for (int i = 0; i < size; i++)
    {
        printf("%d ", a[i]);
    }

    return 0;
}
```
