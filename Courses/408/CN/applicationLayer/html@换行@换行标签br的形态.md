在 HTML 中，`<br>` 和 `<br />` 是用于**换行**的标签。它们看起来不同，但功能是一样的：**插入一个换行符（line break）**。下面详细对比它们的区别、适用场景以及类似标签。

---

## 🧾 一、`<br>` vs `<br />`

| 特性             | `<br>`                    | `<br />`                              |
| ---------------- | ------------------------- | ------------------------------------- |
| **语法风格**     | HTML 风格（推荐现代使用） | XHTML 风格                            |
| **是否自闭合**   | 是（HTML 允许不带斜杠）   | 是（严格要求自闭合）                  |
| **是否有效**     | ✅ 合法 HTML5 标签         | ✅ 合法（XHTML/部分 XML 解析器更喜欢） |
| **浏览器兼容性** | 所有浏览器支持            | 所有浏览器也支持                      |

### 🔍 示例：

```html
<p>第一行<br>第二行</p>
<!-- 或 -->
<p>第一行<br />第二行</p>
```

两种写法在浏览器中都会显示为：

```
第一行
第二行
```

---

## 📌 二、为什么会有两种写法？

- `</br>` ❌ 错误！这是常见的错误写法，不要使用。
- `<br>` 是 HTML 的标准写法，适用于所有现代浏览器。
- `<br />` 是从 **XHTML** 延续下来的写法，它模仿了 XML 的自闭合语法规范，常见于早期网页或某些 CMS 系统中。

---

## 🔄 三、与类似换行方式的比较

| 方法                                      | 描述                                     | 是否推荐                               |
| ----------------------------------------- | ---------------------------------------- | -------------------------------------- |
| `<br>` / `<br />`                         | 强制换行，适合段落内的小换行             | ✅ 推荐在需要换行时使用                 |
| `\n`（换行符）                            | 在文本中表示换行，但在 HTML 中无效       | ❌ 不起作用，除非配合 CSS `white-space` |
| `&nbsp;`                                  | 插入不可断行的空格，不能单独实现换行     | ❌ 仅用于空格控制                       |
| 使用多个 `<p>` 或 `<div>`                 | 语义上是“新段落”或“新块”，不是简单的换行 | ⚠️ 可用，但语义不同                     |
| CSS `white-space: pre-line` 或 `pre-wrap` | 保留空白字符和换行符                     | ✅ 控制文本格式时可用                   |

---

## 🧪 四、示例对比

### ✅ 推荐写法（HTML5）

```html
<p>你好<br>世界</p>
```

### ⚠️ 不推荐（语义不符）

```html
<p>你好</p><p>世界</p>
<!-- 虽然视觉上是两行，但语义上是两个段落 -->
```

### ⚠️ 不推荐（XHTML 遗留风格）

```html
<p>你好<br /></p>
<!-- 对现代网页开发无必要，除非你使用严格的 XML 解析器 -->
```

---

## ✅ 总结建议

| 场景                           | 推荐写法                                    |
| ------------------------------ | ------------------------------------------- |
| 现代 HTML5 页面                | `<br>`                                      |
| XML/XHTML 页面                 | `<br />`                                    |
| 想要保留原始换行格式（如代码） | 使用 `<pre>` 标签或 `white-space: pre-line` |
| 段落之间分隔                   | 使用多个 `<p>` 或 `<div>` 更合适            |
| 换行 + 保持样式                | `<br>` + CSS 控制                           |
