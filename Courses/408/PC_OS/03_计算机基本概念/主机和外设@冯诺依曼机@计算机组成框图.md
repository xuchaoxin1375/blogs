## 主机与外设

- 对于完整的计算机系统而言,主机和外设仅仅是硬件部分,软件部分本文不讨论

- 主机:cpu和主存共同构成:
  - 这种划分计算机硬件的方式和冯诺依曼五大部件是两个风格
  - cpu集成了控制器和运算器,以及主存的寄存器部分(MAR,MDR)以及Cache
  
- 外设:主机之外的其他硬件装置
  - 外存
    - 注意,外存和内存都是存储器,只有其中的主存才是构成主机的部分之一
  - IO设备

### CPU（中央处理单元）

#### 运算器（Arithmetic Logic Unit, ALU）

- **功能**：负责执行算术运算（如加、减、乘、除）和逻辑运算（如与、或、非）。
- 组成部分：
  - **ACC（累加器，Accumulator）**：
     用于存储运算的中间结果，是ALU的重要工作寄存器。
  - **MQ（乘商寄存器，Multiplier Quotient Register）**：
     在乘法和除法操作中存储乘数、被除数或运算结果的商。
  - **X**：
     可能是一个临时寄存器，用于存储 ALU 操作中的辅助数据。

#### 控制器（Control Unit, CU）

- **功能**：协调和控制计算机系统各部分的操作，解释指令并发出相应的控制信号。
- 组成部分：
  - **IR（指令寄存器，Instruction Register）**：
     用于存储当前正在执行的指令。
  - **PC（程序计数器，Program Counter）**：
     存储下一条将要执行的指令的地址。它在每次指令执行后自动递增，指向程序中的下一条指令。

------

### 主存储器（Main Memory, M）

- **主存储器**：
   也称为**内存（RAM）**，用于存储程序和数据。它是 CPU 可直接访问的存储设备。
- **MAR（存储器地址寄存器，Memory Address Register）**：
   存储需要访问的内存单元的地址。CPU 通过 MAR 指定要读取或写入的数据的位置。
- **MDR（存储器数据寄存器，Memory Data Register）**：
   存储从内存中读取或写入内存的数据。它在 CPU 和内存之间传递数据。

------

### I/O设备（Input/Output Devices）

- **功能**：
   用于计算机与外界进行数据交换。输入设备将外部信息输入计算机，输出设备将计算结果输出给用户或其他系统。例如，键盘、显示器、打印机等。

------

### 整体工作流程

1. **取指令**：
    程序计数器（PC）提供下一条指令的地址，地址被送入 MAR，从内存读取指令送入 MDR，然后送入指令寄存器（IR）。
2. **指令译码**：
    控制器（CU）对 IR 中的指令进行译码，生成相应的控制信号。
3. **执行指令**：
    ALU 根据指令执行相应的运算，ACC 和 MQ 配合存储中间结果。
4. **数据传输**：
    数据通过 MDR 在主存储器与 CPU 之间传输。I/O 设备与主存或 CPU 交换数据。

------

### 总结

这幅框图展示了计算机内部各主要部件的相互关系。CPU 通过控制器（CU）和运算器（ALU）执行指令，主存储器提供数据和指令的存储空间，而 I/O 设备则实现数据的输入与输出。
