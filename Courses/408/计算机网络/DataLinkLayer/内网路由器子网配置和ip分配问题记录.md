## abstract

即便是同一个局域网下,有一种情况需要注意,比如我有一个台式机`a`连接到(家用)路由器`r`的有线网络端口(或者中加隔着一个交换机),而另一个笔记本`b`则使用wifi链接;

这种网络情况下,两个设备的ip可能只能单向ping通,而不一定双向ping通.

> 例如台式机`a`的ip为`192.168.1.m`,而笔记本ip为`192.168.5.x` (字母代表一个十进制数整数),就可能导致这种情况;
> 

这是一个非常经典的网络排障场景。虽然物理上它们都连接在同一个“路由器”上，但从逻辑上看，你的台式机 `a` 和笔记本 `b` 其实处于**不同的子网（Subnets）**。

## 基础概念

### LAN和WAN以及相关端口

在网络世界中，**WAN** 和 **LAN** 是最基础的两个概念。简单来说，它们区分了网络覆盖的**地理范围**以及**所有权**。

------

1. LAN (Local Area Network) - 局域网

LAN 是指在较小地理范围内（如家庭、办公室、学校或数据中心）互联的计算机网络。

- **范围**：通常限制在一个建筑物或校园内。
- **速度**：由于物理距离短且通常使用高速线缆（如五类/六类网线或 Wi-Fi 6），LAN 的延迟极低，带宽极高（通常为 1Gbps 到 100Gbps）。
- **所有权**：由个人或单一组织拥有和维护。
- **典型设备**：交换机、路由器、无线接入点（AP）、网线。

------

2. WAN (Wide Area Network) - 广域网

WAN 是将分布在不同城市、国家甚至洲际的多个 LAN 连接起来的大型网络。**互联网（Internet）就是全球最大的 WAN。**

- **范围**：跨越极大的物理距离。
- **速度**：由于需要经过漫长的光缆、海底电缆甚至卫星，WAN 的延迟通常高于 LAN，且受限于服务商提供的带宽。
- **所有权**：由电信运营商（ISP）或大型机构租赁和管理。
- **典型设备**：核心路由器、调制解调器（光猫）、基站。

------

3. WAN vs. LAN：核心区别

| **特性**      | **LAN (局域网)**         | **WAN (广域网)**         |
| ------------- | ------------------------ | ------------------------ |
| **覆盖范围**  | 小（家庭、办公室）       | 大（城市、全球）         |
| **速度/带宽** | 极高（1Gbps+）           | 相对较低且昂贵           |
| **延迟**      | 极低（1-5ms）            | 较高（几十到几百ms）     |
| **典型技术**  | 以太网 (Ethernet), Wi-Fi | 光纤 (FTTH), 4G/5G, MPLS |
| **管理者**    | 你自己或公司 IT          | 电信运营商 (ISP)         |

------

4. 路由器中的 WAN 口与 LAN 口

在你家里的路由器背面，通常能看到这两种物理端口：

- **WAN 口**：通常只有一个（颜色可能不同）。它是连接“外部世界”的通道。你需要把光猫出来的网线插到这里，让路由器获取公网 IP。
- **LAN 口**：通常有 3-4 个。它们用于连接你家里的本地设备（如台式机、NAS、电视）。

> **逻辑关联**：
>
> 当数据从你的笔记本（LAN 设备）发往网页服务器时，数据包会先经过路由器的 **LAN 口** 进入，经过 **NAT（网络地址转换）**，再从 **WAN 口** 出发，穿越广域网到达目的地。

### AP(access point)

在网络世界中，**AP** 是 **Access Point** 的缩写，中文全称为 **“无线访问点”** 或 **“无线接入点”**。

简单来说，AP 的作用就像是**“无线信号的延伸器”**，它将有线网络转换成无线信号（Wi-Fi），让手机、电脑等设备能够联网。

------

1. AP 的核心功能

如果把互联网比作水源，有线网线就是水管，那么 AP 就是一个**水龙头**。它负责把水管里的水（数据）以无线喷洒的方式（Wi-Fi 信号）覆盖到特定区域。

- **转换信号：** 将路由器传来的有线电信号转换为无线电磁波信号。
- **连接设备：** 作为中心节点，允许数十甚至上百个无线设备同时接入。
- **扩展覆盖：** 在大房子或办公室中，单个路由器的信号无法穿透所有墙壁，这时就需要多个 AP 来填补信号盲区。

------

2. 路由器（Router）与 AP 的区别

这是最容易混淆的地方。事实上，我们家里常用的“无线路由器”其实是一个**三合一**的设备：

| **功能模块**        | **作用**                                     | **形象比喻** |
| ------------------- | -------------------------------------------- | ------------ |
| **路由器 (Router)** | 负责拨号上网、分配 IP 地址、管理数据包去向。 | 调度中心     |
| **交换机 (Switch)** | 扩展网口，让多台设备通过网线连接。           | 插线板       |
| **访问点 (AP)**     | 发射 Wi-Fi 信号，让设备无线接入。            | 无线基站     |

**区别总结：**

- **路由器**是网络的“大脑”，负责规划路径和连接外网。
- **AP** 是网络的“触手”，只负责发射无线信号，它本身通常不具备拨号、分配 IP（DHCP）或防火墙功能。

------

3. 常见的 AP 形式

胖 AP (Fat AP)

通常指具备独立管理能力的 AP。它不仅能发射 Wi-Fi，还能独立完成拨号、路由等功能。我们家用的无线路由器在关闭路由功能、仅开启 Wi-Fi 时，就可以看作是一个“胖 AP”。

瘦 AP (Fit AP)

这是目前企业、商场或大户型（AC+AP 方案）中最常见的。

- **特点：** 它不能独立工作，必须配合 **AC（无线控制器）** 使用。
- **优势：** 由 AC 统一管理。比如你在商场从 1 楼走到 3 楼，Wi-Fi 会自动无缝切换，这正是因为 AC 在后台调度多个瘦 AP。

------

4. 什么时候需要用到 AP？

1. **大户型/别墅：** 一台路由器覆盖不了全家，在每个房间布置一个墙壁开关大小的 **面板 AP**。
2. **公司/仓库：** 需要接入大量设备，且要求信号在移动时不断网（漫游）。
3. **已有路由器但 Wi-Fi 差：** 可以关掉老路由器的 Wi-Fi，接一个高性能 AP 专门负责无线传输。

## 原因分析

------

### 1. 存在二级路由器（路由级联）

这是最常见的原因。如果你的 WiFi 并不是由主路由器 `r` 直接发出，而是连接了一个**二级路由器**（例如为了增强信号），且网线插在了二级路由器的 **WAN口** 上。

- **逻辑结构**：主路由分配 `192.168.1.x` 给台式机，而二级路由器开启了自身的 DHCP 服务，为 WiFi 设备分配了 `192.168.5.x`。
- **为什么单向通？**
  - **笔记本到台式机（通）**：笔记本访问台式机是“向上”访问，二级路由器会通过 NAT（网络地址转换）将请求发往主路由，这通常是被允许的。
  - **台式机到笔记本（不通）**：台式机访问笔记本是“向下”访问，请求到达二级路由器的 WAN 口时，会被其防火墙拦截，因为它认为这是一个来自外部网络的未经请求的访问。

------

### 2. 开启了“访客网络”模式

很多现代家用路由器提供“访客 WiFi”功能。为了保护主网安全，路由器会利用 **VLAN（虚拟局域网）** 技术将访客网络物理隔离。

- **特征**：访客网络通常拥有完全不同的网段（如你的 `192.168.5.x`）。
- **结果**：路由器内部设置了 ACL（访问控制列表），禁止访客网段与主网段（有线网口）进行二层或三层互访。

------

### 3. 子网掩码与路由表限制

即便是同一个物理设备，如果配置了不同的子网掩码，也会导致逻辑隔离。

- **计算差异**：如果子网掩码是 `255.255.255.0`，那么 `192.168.1.m` 认为只有 `1.x` 是邻居。
- **寻找网关**：当台式机 `a` 试图 ping `192.168.5.x` 时，它发现对方不在自己的网段内，于是把包发给网关。如果网关上没有配置通往 `5.x` 段的静态路由，或者防火墙策略禁止跨段转发，ping 就会失败。

------

### 4. 软件层面的“隐形推手”：防火墙策略

即使网络层打通了，操作系统本身的策略也会造成“单向通”的假象：

- **Windows 防火墙**：默认情况下，Windows 可能会将有线连接识别为“专用网络”，而将某些 WiFi 连接识别为“公用网络”。
- **策略差异**：在“公用网络”模式下，Windows 默认禁止 ICMP 回显请求（即不响应 Ping）。这就会导致：**你能从笔记本 Ping 台式机，但台式机 Ping 笔记本时，请求被笔记本自身的防火墙拦下了。**

------

### 如何解决？

如果你希望实现真正的双向互通，可以尝试以下操作：

1. **统一网段（最推荐）**：如果是二级路由器，请将网线从其 **WAN口** 拔出，插到 **LAN口**，并关闭二级路由器的 DHCP 功能。这样它就变成了一个纯粹的无线交换机（AP），所有设备都会获取 `192.168.1.x` 的 IP。
2. **检查防火墙**：确保两台机器的防火墙都允许“文件和打印机共享（回显请求）”。
3. **检查路由设置**：查看主路由是否开启了“AP 隔离”或“访客隔离”功能。
