## 主存储器(内存)



**主存储器**（简称主存或内存）是计算机系统中用于临时存放数据和程序的重要组成部分。它由存储体M、各种逻辑部件及控制电路等组成。



### 存储单元相关概念

存储体由多个**存储单元**构成，每个存储单元又包含若干个能够寄存一位二进制代码“0”或“1”的**存储元件**(存储基元/存储元)。

一组存储单元可以保存一串二进制代码，这串代码被称为一个**存储字**，其位数即为存储字长，常见的长度有8位、16位或32位等。

- **存储字的应用**：一个存储字可以表示不同的信息：
  - 作为数值，如二进制数。
  - 作为字符编码，例如ASCII码。
  - 作为指令。
- **存储单元与地址**：将存储体比作一栋大楼，每个存储单元就像是楼中的房间，而每个存储元件则相当于房间内的床位。床位有人代表“1”，无人代表“0”。每个房间（存储单元）都有唯一的编号——地址号，通过这个地址号可以对存储单元进行读写操作。

### 存取方式

主存储器采用**按地址存取**的方式工作，这种方式对于计算机的组织和操作非常有利：

- **程序执行**：编好的程序被顺序地存入主存各单元，运行时给出首地址后，机器自动完成整个程序的操作。
- **数据复用**：当需要重复使用某个数据或指令时，只需引用其所在单元的地址即可，无需重复存储，从而提高了空间利用率。
- **统一操作**：由于指令和数据都通过地址来访问，因此它们的取操作可以视为相同，使得一套控制线路就能处理两种不同类型的访问。

### 关键寄存器

为了支持按地址访问，主存中配置了两个重要寄存器：

- **MAR (Memory Address Register)**：存储器地址寄存器，用于**存放当前要访问的存储单元的地址**。
  - MAR位数对应**存储单元的个数**（如 MAR 为 $10$ 位，则有 $2^{10}=1024$ 个存储单元，记为 $1 K$）

- **MDR (Memory Data Register)**：存储器数据寄存器，用来暂时存放从存储体取出或将要写入的数据。
  - MDR位数与**存储字长**相等


随着技术进步，现代计算机通常将MAR和MDR集成在CPU芯片内，以提高效率。

### 字节与字长

早期计算机的设计倾向于使**存储字长**与**指令字长**及**数据字长**相等。

然而，随着应用需求的增长和技术的发展，现在更倾向于支持**可变长度的指令和数据**。

为此，引入了字节的概念，其中1个字节定义为8位(bit)二进制代码。这样，无论是指令还是数据，都可以根据实际需要以字节为单位灵活调整长度，但必须保证这些长度是字节的整数倍。



## 运算器

### 基础寄存器

运算器最少包括3个寄存器（现代计算机内部往往设有通用寄存器组）和一个算术逻辑单元(ALU)。

- ACC(Accumulator)为**累加器**，
- MQ(Multiplier-Quotient Register)为**乘商寄存器**，
- X为**操作数寄存器**。

这3个寄存器在完成不同运算时，所存放的操作数类别也各不相同。

下表列出了寄存器存放不同类别操作数的情况。

|      | 加法       | 减法       | 乘法           | 除法         |
| ---- | ---------- | ---------- | -------------- | ------------ |
| ACC  | 被加数及和 | 被减数及差 | 乘积高位       | 被除数及余数 |
| MQ   |            |            | 乘数及乘积低位 | 商           |
| X    | 加数       | 减数       | 被乘数         | 除数         |

加法和减法很好理解,乘法用到了MQ,此时存放的是乘数和乘积的低位;并且ACC存放乘积的高位

乘法和除法运算比加减法复杂得多,以乘法为例,乘积的存储要分成两部分,ACC在计算乘法过程中要用来存放乘积的高位,所以计算中途不能用它来存放被乘数或乘数,如果运算开始前ACC存放被乘数,那么需要将被乘数放到X中,然后清理ACC,以准备存放乘积高位,而乘数则存放到MQ,并且MQ不仅仅存放乘数,还要在计算过程中移位,并存放乘积低位

- 在加法运算中，ACC存储的是被加数及其和，X则是加数。
- 在减法运算中，ACC存储的是被减数及其差，X则是减数。
- 在乘法运算中，ACC存储的是乘积的高位部分，MQ存储的是乘数及乘积的低位部分，X则是被乘数。
- 在除法运算中，ACC存储的是被除数及其余数，MQ存储的是商，X则是除数。

不同机器的运算器结构是不同的。

### 四则运算操作过程示例

下面简要地分析一下上述基本结构的运算器加、减、乘、除四则运算的操作过程。

设：M 表示存储器的任一地址号，[M]表示对应 M 地址号单元中的内容；

X 表示 X 寄存器，[X]表示 X 寄存器中的内容；

ACC 表示累加器，[ACC]表示累加器中的内容；

MQ 表示乘商寄存器，[MQ]表示乘商寄存器中的内容。

---



假设 ACC 中已存有前一时刻的运算结果，并作为下述运算中的一个操作数，则

- 加法操作过程为
  $[M]\rightarrow X$
  $[ACC]+[X]\rightarrow ACC$

即将[ACC]看作被加数，先从主存中取一个存放在 M 地址号单元内的加数[M]，送至运算器的 X 寄存器中，然后将被加数[ACC]与加数[X]相加，结果（和）保留在 ACC 中。

- 减法操作过程为
  $[M]\rightarrow X$
  $[ACC]-[X]\rightarrow ACC$

即将[ACC]看作被减数，先取出存放在主存 M 地址号单元中的减数[M]并送入 X，然后[ACC]-[X], 结果（差）保留在 ACC 中。

- 乘法操作过程为
  $[M]\rightarrow MQ$
  $[ACC]\rightarrow X$
  $0\rightarrow ACC$
  $[X]\times [MQ]\rightarrow ACC//MQ$ (// 表示两个寄存器串接)

即将$[ACC]$看作被乘数，先取出存放在主存 M 号地址单元中的乘数[M] 并送人乘商寄存器 MQ，再把被乘数[ACC]送人 X 寄存器，并将 ACC 清“0”，然后$[X]$ 和 $[MQ]$ 相乘，结果（积）的高位保留在 ACC 中，低位保留在 MQ 中。

- 除法操作过程为
  $[M]\rightarrow X$
  $[ACC]\div[X]\rightarrow MQ$
  余数 R 在 ACC 中

即将[ACC]看作被除数，先取出存放在主存 M 号地址单元内的除数[M] 并送至 X 寄存器，然后[ACC]除以[X]，结果（商）暂留于 MQ，[ACC]为余数 R。



### 通用寄存器和程序状态寄存器

- 运算器的核心
- 包含多个**通用寄存器**:通用寄存器组GPRs:([GPR - General Purpose Registers](https://www.acronymattic.com/General-Purpose-Registers-(GPR).html))
  - 用于暂存操作数和中间结果
    - 必须寄存器:
      - 累加寄存器(简称累加器)ACC
      - 乘商寄存器MQ
      - 操作数寄存器X
    - 非必须寄存器:
      - 变址寄存器(IX,Index Register) 
      - 基址寄存器(BR,Base Register)

- **程序状态寄存器**(标志寄存器)PSW(Program Status Word)
  - 用于存放ALU运算得到的一些标志信息/处理机的状态信息
    - 是否溢出/进位/借位/结果是否为负/...

## 控制器

控制器是计算机的神经中枢，由它指挥各部件自动、协调地工作。

### 完成指令的三阶段

1. 具体而言，它首先要命令存储器读出一条指令，称为取指过程（也称取指阶段）。
2. 接着，它要对这条指令进行分析，指出该指令要完成什么样的操作，并按寻址特征指明操作数的地址，称为分析过程（也称分析阶段）。
3. 最后根据操作数所在的地址以及指令的操作码完成某种操作，称为执行过程（也称执行阶段）。

以上就是通常所说的完成一条指令操作的**取指,分析和执行**3个阶段

### 控制器组成

控制器由程序计数器（Program Counter, PC），指令寄存器（Instruction Register, IR）以及控制单元（Control Unit, CU）组成。

1. PC 用来存放当前欲执行指令的地址，它与主存 MAR 之间有一条直接通路，且具有自动加 1 的功能，即可自动形成下一条指令的地址。

2. IR 用来存放当前的指令，IR 的内容来自主存的 MDR。

   - IR 中的操作码 $OP(IR)$ 送至 CU，记作 $OP(IR) \to CU$，用来分析指令；

   - 其地址码 $Ad(IR)$ 作为操作数的地址送至存储器的 MAR，记作 $Ad(IR) \to MAR$。

CU 用来**分析当前指令所需完成的操作，并发出各种微操作命令序列，用以控制所有被控对象**。

### CU和ALU以及各类寄存器



- **CU（控制单元，Control Unit）** 和 **ALU（算术逻辑单元，Arithmetic Logic Unit）** 都是CPU中的重要组成部分，负责计算机的核心运算与控制操作，但它们的功能和作用有所不同。

  - 算术逻辑单元 (ALU，Arithmetic Logic Unit） 算术逻辑单元主要负责执行算术运算和逻辑运算。它处理像加法、减法、乘法、除法等数学运算，以及与、或、非、异或等逻辑运算。

  - 控制单元（CU，Control Unit）是CPU的一个功能模块。它的主要作用是控制和协调计算机系统中各个部件的操作，比如指令的获取、解码、以及控制信号的生成等。

- **寄存器**：是用于存储数据的小型高速存储单元。它们通常用于存储数据、指令或地址等，支持CPU的工作。例如，IR存储当前指令，PC存储下一条要执行指令的地址。

### CU与ALU的协作

CU和ALU通常是密切协作的，共同完成指令的执行过程：

1. **CU指挥执行：** 当计算机执行指令时，CU首先从内存中获取指令并解码。
2. **CU控制ALU：** 根据解码后的指令，CU决定是否需要ALU进行算术或逻辑操作，并发出相应的控制信号来触发ALU。
3. **ALU执行运算：** ALU根据CU提供的控制信号执行具体的算术或逻辑运算。
4. **返回结果：** ALU将结果存储到寄存器中，或者将结果返回给内存，CU会继续进行下一条指令的执行。

### 控制器相关寄存器

- 程序计数器PC
  - PC存放当前与执行指令的地址
  - 可以自动加1来形成下一条指令的地址
  - 与主存的MAR之间有条直接通路
- 指令寄存器IR
  - 存放当前指令,内容来自于主存的MDR
  - 指令中的操作码OP(IR)被送至CU
  - 地址码AD(IR)送往MAR,用以获取操作数
- 控制单元CU
  - 指令中的操作码OP(IR)被送至CU,用以分析指令,并发出各种微操作命令序列
  - 需要区分**控制器**和**控制单元**,级别不一样,是包含与被包含的关系

## 寄存器的可见性(透明性)

### 可见寄存器

- 汇编程序员可以操作/设置
  - PC(程序计数器)
  - PSW状态寄存器
  - GPR通用寄存器
- 这些寄存器可见,能够进行汇编编程

### 透明寄存器(不可见)

- CPU内部的:

  - IR(指令寄存器)
  - MAR(地址寄存器)
  - MDR(数据寄存器)

## 相关总线三种信号线

- **cpu和主存**之间通过一组**总线**相连
- 总线中有三种**信号线**:
  - 地址线
    - MAR中的**地址**会直接送到地址线上,用于指向读写操作的主存存储单元
  - 控制线
    - 读/写信号线,指出数据是从cpu写入到主存还是从主存读出到cpu
    - 根据读写操作决定:
      - 将MDR中的数据直接送入到**数据线**上
      - 将**数据线**上的数据接收到MDR
  - 数据线
    - 配合控制器有向传输数据

## CPU和寄存器

- MAR,MDR属于存储器的一部分,但是却存在于CPU内,物理位置不影响逻辑范畴的划分
- 高速缓存Cache(高速SRAM制作的速度介于寄存器和普通内存(DRAM)之间的小容量存储)也是位于CPU内
- CPU不属于冯诺依曼机的五大基本部件,它是众多组件的整合体,包含了五大基础部件的多种成分
  - CPU至少囊括了5部中的3部
    - 运算器
    - 控制器
    - 存储器的部分组件
  - 几乎所有的寄存器物理位置都在cpu里
    - 主存,运算器,控制器的从属寄存器都布局在cpu内
