## abstract

研究素数是数论的核心内容之一。

### 素数

这类大于1，而且正约数只有1和自身的整数叫做素数。

素数也称为质数。

要特别注意，1不是素数。

### 合数

如果大于1的整数不是素数，则称其为合数。

## 素数的分布

素数在自然数中的分布很不规律，有时隔一个数就有一个素数，如3,5；有时隔三个数有一个素数，如19,23.有的相邻两素数相隔很远，寻找素数和判别一个数是否为素数是很艰难的。



## 定理1:任意数的最小约数和素数的关系

合数的素约数性质

设 $a$ 是任一大于1的整数，则$a$的**除1以外的最小正约数$q$**必是素数。当$a$是合数时，$q \leqslant \sqrt{a}$。

证明：用反证法。

- 设$q$不是素数，由$q > 1$知$q$是合数。由此可知存在$q$的正约数$q_1$，使$1 < q_1 < q$。由$q_1 | q$，$q | a$，可得$q_1 | a$，这与$q$是$a$除1以外的最小正约数矛盾。所以$q$是**素数**

- 当$a$是合数时，设$a = a_1 q$，(其中$q$仍然表示$a$的大于1的最小正约数)。则显然有$a_1 \geqslant q$，故$q^2 \leqslant a$，即$q \leqslant \sqrt{a}$。

### 小结

由定理1知，对于每一个合数$n$(或者说若$n$是合数)，则存在素数$p$，使$p | n$，且$p \leqslant \sqrt{n}$

- 相反,如果整数$n$在$2,\cdots,[\sqrt{n}]$以内不存在满足$p|n$的素数$p$,那么这个数就是不是合数,而是素数
  - 因为一个大于1的正整数不是合数就是素数,通过筛除所有合数,剩下的就全是素数
- 或者说,如果一个不超过$N$的整数$n_{j}$是合数,则必须能够被不超过$\sqrt{n}$的素数(分别记为$(P_{1},\cdots,P_{s})$中的至少一个整除,如果不满足(找不到满足$P_{i}|n_{j}$的素数$P_{i}$),那么整数$n_{j}$不是合数,而是素数

- 这里我们不强调$p$是$n$的最小正约数,而强调存在这样的素数$p$,由定理可知至少$n$的非1最小正约数是满足$p|n$的素数$p$


## 定理2:素数的数量是无穷多的

素数有无穷多个

证明：用反证法.

> 数论很多结论地方都用反证法来证明,反证法对比较抽象的结论往往很有效,或者提供简洁的证明

假设自然数中只有有限多个**素数**，不妨记为 $P_1, P_2, \ldots, P_k$。那么$P_{k}$之后的数都不是素数,也就是都为合数

考虑构造整数 $N_0 = P_1P_2\cdots P_k$,$N_{0}$特点是$P_{i}|N_{0}$,$(i=1,2,\cdots,k)$;显然$N_{0}>P_{k}$,$N_{0}$是合数;

令$N=N_{0}+1$,则$N/P_{i}$的余数为1,显然$P_{i}\nmid{N}$,$(i=1,2,\cdots,k)$,

既然$N$是合数,由 $N > 1$ 及定理 1 知存在素数 $P | N$。

此时必有 $P \neq P_i$，$(1 \leq i \leq k)$，否则 $P_{i}|N$或$P|1$,这是不可能的。所以 $P$ 是上述 $k$ 个素数以外的素数。这导出矛盾。所以素数有无穷多个。

## 寻找素数

### 埃氏筛|厄拉多塞筛法(Eratosthenes sieve)👺

由上述讨论,可得出找出不超过$N$的**全体素数**的方法：

- 先找出不超过$\sqrt{N}$的全体素数，且按大小顺序排列(这个步骤中用到的素数需要事先准备

  - $2 = P_1 < P_2 < \cdots < P_s \leqslant \sqrt{N}.$
  - 考虑到$P_{s}$是整数,所以$P_{s}\leqslant{\lfloor{\sqrt{N}}}\rfloor$
- 然后把大于1，且不超过$N$的自然数按大小顺序排列

  - $$2, 3, \cdots, N.$$`(1)`,该序列的长度为$N-1$
- 在序列(1)中
  - 留下$P_1 = 2$，而把$P_1$的倍数全部划掉。
  - 再留下$P_2 = 3,$ 而把$P_2$的倍数全部划掉。
  - 继续这一手续，....
  - 直到最后留下$P_s$，而把$P_s$的倍数全部划掉。
  - 留下的数都无法被$P_{1},\cdots,P_{s}$中的任意一个数整除,即$P_{i}\nmid{n_{j}}$,$(i=1,2,\cdots,s)$,$n_{j}$表示留下来的第$j$个数,$(n_{j}\leqslant{N})$,这就是说,对于$n_{j}$,不存在这样的$p_{i}$,使得$P_{i}|n_{j}$,且$P_{i}\leqslant{\sqrt{N}}$,所以$n_{j}$不是合数而是素数
  - 综上,留下的就是**不超过$N$的全体素数**。
- 这种寻找素数的方法，称为 Eratosthenes)筛法,译为**厄拉多塞筛法**,或**埃拉托斯特尼筛法**,简称**埃氏筛**
  - 方法的不遗漏性在于其通过筛除所有合数,保留下来的就是所有的素数,做到不遗漏
  - 筛除合数的过程中是逐步层级的,需要筛$s$遍才能筛掉所有合数



### 案例👺

- 例如，为寻求100以内的全体素数，先找出不超过 $\sqrt{100}=10$ 的全体素数：
  $$2, 3, 5, 7$$
  把从2到100的数按大小排列，把2, 3, 5, 7留下，再先后划掉2, 3, 5, 7这四个数的倍数(2倍以上)，剩下的就是100以内全部的素数。
- 更简单的例子:寻求20以内的全体素数,先找出$[\sqrt{20}]=4$以内的素数,即$2,3$,将$2,3,4,\cdots,20$内的所有$2k,3k$,$(k=2,\cdots)$划掉,得到$2,3,5,7,11,13,17,19$

## 判断一个数是否为素数

- 判断一个正整数 $a$ 是否为素数，原则上要用不超过 $\sqrt{a}$ 的素数逐个试除。
- 在计算机程序设计中,这个结论应用很直接

### 缩小操作

适合手算或口算验证

如果我们要判断整数$a$是否为素数,但是$a$不是一个完全平方数,可将$a$缩小一些到最近的完全平方数$b=r^2$,例如$r^{2}\leqslant{b}<{(r+1)^{2}}$

例如判断$119$是否素数,$10^{2}=100<119<121=11^{2}$,或者说$[\sqrt{119}]=10$,可以判断$10$以内(不超过10)的所有素数$2,3,5,7$是否能够整除$119$,如果都不能,说明119是素数

那么放大操作可以验证一个数是否为素数呢?

如果一个数$b$不能被$2,3,\cdots,\lceil{\sqrt{b}}\rceil$中的任何一个整数整除,说明$b$是素数,因为该序列一定包含了$2,3,\cdots,\lfloor{\sqrt{b}}\rfloor$,能够判定是素数;

例如判断$119$能否被$2,3,5,7,11$中的某个数整除,如果都不能,说明119是素数,否则显然是合数

但是根据定理1,判断到$\lfloor{\sqrt{b}}\rfloor$即可,判断更大的数能否整除$b$是多余的操作

### 案例

- 结合我们对较小素数的认识(记忆),可以快速判断不太大的整数是否为素数
- 对较小的数 $a$，工作量不是很大。
  - 例如，$a=97$，你会比较快的看出它是素数，因为 97 不是 2、3、5、7 的倍数。
  - 又如 $a=191$，也是素数，因为191 不是 2、3、5、7、11、13 的倍数，因此 191 是素数。

## 程序设计找素数(筛法)

有两类筛法

### 埃氏筛

判断一个数n是不是素数，可以用2到$\sqrt{n}$之间的所有整数去除n，看能否整除。如果都不能整除，那么n是素数。

求$n$以内的所有索数，可以对3至$n$中的每个数都重复上述过程，发现是素数则输出。但是这样做速度比较慢

如果用空间换时间，分配一个大数组，用筛法求素数，则速度会提高一倍左右。

前面介绍的Era(埃氏筛)法提到需要先找出$\sqrt{n}$以内的素数,然后进行筛选,这个可操作性不是那么好,不方便程序设计;

事实上,我们可以不用事先找出$\sqrt{n}$内的素数,直接进行筛选;

### 引理

假设序列$2,3,\cdots,n$中最小的$m$个素数为$p_{1}\cdots{p_{m}}$,将$p_{1}\cdots{p_{m}}$的倍数(2倍及以上)的数都被划去(保留$p_{1}\cdots{p_{m}}$本身),并记剩下的序列中的第一个数为$p_{m+1}$(显然$p_{m},p_{m+1}$之间没有留下任何元素,此时两个数在序列中是相邻的),则:

- $p_{m+1}$是素数,而且是最接近$p_{m}$的素数

证明:反证法

若$p_{m+1}$是合数,由合数的素约数性质,序列$2,\cdots,p_{m+1}-1$中一定有一个数$t$是$p_{m+1}$的约数

- 如果$t$是被划掉的数,那么说明$t$被${p_{1},\cdots,{p_{m}}}$中至少一个素数整除,
- 如果$t$不是被划掉的数,则$t\in\set{p_{1}\cdots{p_{m}}}$,因此$t\in\set{p_{1},\cdots,p_{m}}$,而已知筛操作已经保证$p_{m+1}$不可能是$p_{1},\cdots p_{m}$中任意一个素数整除,所以$p_{m+1}$是素数而不是合数;

筛法求素数的基本思想是把2到$n$中所有的数都列出来，然后从2开始，先划掉$n$内所有2的倍数，再每次从下一个剩下的第一个数（必然是素数）开始，划掉其$n$内的所有倍数,重复操作,直到序列内的所有数都被遍历过。最后剩下的数就都是素数。

### C++程序

```c++
/* 埃氏筛法求素数

 */
#include <iostream>
#include <cmath>
using namespace std;

const int MAX_NUM = 1e3;	// 假设我们要找出1000(1e3)以内的素数
bool isPrime[MAX_NUM + 10]; // 最终如果isPrime[i]为true，则表示i是素数

int main()
{
	int cnt = 0;
	for (int i = 2; i <= MAX_NUM; ++i) // 初始化状态:开始假设所有数都是素数
		isPrime[i] = true;
	for (int i = 2; i <= MAX_NUM; ++i)
	{ // 每次将一个素数的所有倍数标记为非素数
		if (isPrime[i])
		{
			++cnt;
			cout << i << endl; // 直接打印素数
			// 素数的倍数(2倍以上)标记位非素数
			for (int j = 2 * i; j <= MAX_NUM; j += i)
			{

				isPrime[j] = false; // 将素数 i 的倍数标记为非素数
			}
		}
	}
	// 集中输出所有素数
	// for (int i = 2; i <= MAX_NUM; ++i)
	// 	if (isPrime[i])
	// 		cout << i << endl;
	cout << "prime number count in [2," << MAX_NUM << "]:" << cnt << endl;
	return 0;
}

```

筛法的效率很高,最终个元素都被访问过一遍,合数全部被划去

但是如果`MAX_NUM`很大,即便指定范围内素数已经被全部确定,但是打印速度受限,输出过程可能会比较久

### 欧拉筛

对埃氏筛算法的时间复杂度优化得到欧拉筛

```c++
#include <iostream>
#include <vector>
using namespace std;

// 函数：用欧拉筛法找出所有小于等于n的素数
void eulerSieve(int n) {
    // 创建一个布尔数组标记是否为素数，初始默认全部为素数(true)
    vector<bool> isPrime(n + 1, true);
    // 创建一个向量用于存储找到的素数
    vector<int> primes;
    
    // 遍历每个数字i，从2开始一直到n
    for (int i = 2; i <= n; ++i) {
        // 如果isPrime[i]仍为true，则i是素数
        if (isPrime[i]) {
            primes.push_back(i); // 将素数加入到列表中
        }
        // 对于每一个已经找到的素数pj，如果i * pj > n则跳出循环
        for (size_t j = 0; j < primes.size() && i * primes[j] <= n; ++j) {
            // 标记合数i * primes[j]
            isPrime[i * primes[j]] = false;
            // 当primes[j]能整除i时，停止筛选更大的素数
            if (i % primes[j] == 0) break;
        }
    }

    // 打印所有的素数
    cout << "Primes up to " << n << ": "<<endl;
    for (int prime : primes) {
        cout << prime << " ";
    }
    cout << endl;
}

int main() {
    int n;
    cout << "请输入要查找的范围上限n: ";
    cin >> n;
    eulerSieve(n); // 调用函数执行欧拉筛
    return 0;
}
```



## 筛法小结

埃氏筛（Eratosthenes Sieve）和欧拉筛（Euler Sieve）是两种用于找出一定范围内所有素数的算法。它们在效率和实现复杂度上有所不同。

### 埃氏筛

埃氏筛是一种非常直观的方法，用来找到不大于给定整数n的所有素数。其基本思想如下：

1. 创建一个列表，包含从2到n的所有整数。
2. 列表中的第一个数2是最小的素数。
3. 将列表中2的所有倍数标记为非素数（即合数）。
4. 找到下一个未被标记的数（这是下一个最小的素数），然后将这个素数的所有倍数标记为非素数。
5. 重复步骤4，直到达到列表的末尾。

埃氏筛的时间复杂度大约是$O(n \log \log n)$。

### 欧拉筛

欧拉筛是对埃氏筛的一种优化，它保证每个合数只会被它的最小质因数筛掉一次，从而提高了效率。其核心思想如下：

1. 创建一个布尔数组`isPrime[]`，其中`isPrime[i]`表示i是否为素数，初始化时全部设为真。
2. 创建一个数组`prime[]`来存储已经找到的素数。
3. 遍历2到n的每一个数i：
   - 如果`isPrime[i]`为真，则将i加入到`prime[]`数组中。
   - 对于每一个已知的素数$p_j$，如果$i \times p_j > n$则跳出循环；否则，将$\rm isPrime[i \times p_j]$标记为假（不是素数）。
   - 如果$p_j$能整除i，则停止对更大的素数进行筛选，因为对于任何更大的素数$p_k$（$k>j$），$(i \times p_k)$将会被$(i \cdot p_j / p_j \times p_k)$更早地筛掉。

欧拉筛的时间复杂度是$O(n)$，因为它确保每个合数只被它的最小素因子筛除一次。

这两种方法都是有效的求素数的方法，但在实际应用中，欧拉筛由于其线性时间复杂度而更加高效。
