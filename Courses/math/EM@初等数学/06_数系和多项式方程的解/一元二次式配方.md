## 配方化为平方差

- 有理式积分和二阶微分方程的特征方程中需要利用二次函数(一元二次方程)的一些性质

对于$f(x)=ax^2 + bx+c$=$a(x^2 + \frac{b}{a}x + \frac{c}{a}) = 0$

等价于$(x^2 + \frac{b}{a}x + \frac{c}{a}) = 0$

令$p = \frac{b}{a}; q = \frac{c}{a}$

和类型：$x^2 + px + q = 0$只相差一个系数$a$, 所以下面仅讨论类型$x^2 + px + q = 0$`(1)`

对该方程配方可得

$x^2 + px + q = (x + \frac{1}{2}p)^2 - (\frac{1}{2}p)^2 + q = 0$

$(x + \frac{1}{2}p)^2 = \frac{1}{4}p^2 - q$`(2)`

特别的，当$r$是方程(1)的一个二重根的时候

- 判别式$\Delta = b^2 - 4ac = p^2 - 4q = 0$`(3)`

- $r$满足方程(2),即:$(r + \frac{1}{2}p)^2 = \frac{1}{4}p^2 - q$`(4)`
- 由式(3)可得$\frac{1}{4}p^{2}-q$=$\frac{1}{4}(p^2 - 4q)$=$\frac{1}{4}\times0=0$`(5)`

将(5)带入到(4)得$r+\frac{1}{2}p=0$,有$2r + p = 0$的结论

并且有二重根$r = -\frac{1}{2}p = -\frac{b}{2a}$

---

求根公式：$|x + \frac{1}{2}p| = \sqrt{\frac{1}{4}p^2 - q}$

$x + \frac{1}{2}p = \pm \sqrt{\frac{1}{4}p^2 - q}$

$x = -\frac{1}{2}p \pm \sqrt{\frac{1}{4}p^2 - q} = -\frac{1}{2}p \pm \frac{1}{2}\sqrt{p^2 - 4q}$

$= \frac{-b + \sqrt{\Delta}}{2a}$

$= \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$

其中：$\Delta = b^2 - 4ac$

对于复数域内:(判别式$\Delta<0$):
$$
-1=i^2
\\
\sqrt{-1}=\sqrt{i^2}=i\\
\sqrt{f(x)}=\sqrt{-1\cdot|f(x)|}=i\cdot\sqrt{|f(x)|}
\\对于\Delta=b^2-4ac<0
\\
\sqrt{\Delta}=i\sqrt{|\Delta|}=i\sqrt{-\Delta}=i\sqrt{4ac-b^2}
\\
x=\frac{-b\pm i\sqrt{4ac-b^2}}{2a}
$$
