## 🧰 终端进程控制命令速查表

| 操作                   | 命令                 | 说明                                       |
| ---------------------- | -------------------- | ------------------------------------------ |
| 挂起当前前台进程       | `Ctrl + Z`           | 暂停正在运行的前台程序（如 Vim）           |
| 查看所有挂起/后台任务  | `jobs`               | 显示当前 shell 中的所有作业（job）         |
| 将任务恢复到前台       | `fg` 或 `fg %作业号` | 如：`fg %1`                                |
| 将任务放到后台继续运行 | `bg` 或 `bg %作业号` | 如：`bg %1`                                |
| 终止一个挂起的任务     | `kill %作业号`       | 如：`kill %1`（谨慎操作）                  |
| 列出所有正在运行的进程 | `ps` 或 `ps aux`     | 查看系统中的进程信息                       |
| 终止指定 PID 的进程    | `kill 进程ID`        | 如：`kill 5244`（从 `jobs -l` 可查看 PID） |

---

## 📌 示例流程

```bash
# 1. 编辑文件
vim ~/.zshrc

# 2. 不小心按了 Ctrl+Z，Vim 被挂起
[1]  + suspended  vim ~/.zshrc

# 3. 查看当前挂起的任务
jobs
# 输出：
# [1]  + suspended  vim ~/.zshrc

# 4. 恢复 Vim 到前台
fg
```

---

## 📝 补充说明

- `%1` 表示作业编号为 1 的任务。
- 如果你有多个挂起任务，可以通过 `jobs` 查看编号。
- 使用 `jobs -l` 可以同时显示作业编号和对应的进程 ID（PID）：

```bash
jobs -l
# 输出示例：
# [1]  + 5244 suspended  vim ~/.zshrc
```
