以下是一份更全面的 **Screen 命令使用总结表**，涵盖基础操作、会话管理、窗口控制、分屏功能、日志记录和高级配置等场景：

---

### **Screen 命令全面总结**

#### **1. 会话管理**
| **操作**       | **命令/快捷键**          | **说明**                                |
| -------------- | ------------------------ | --------------------------------------- |
| 启动新会话     | `screen`                 | 创建匿名会话                            |
| 启动命名会话   | `screen -S <会话名>`     | 创建可标识的会话（推荐）                |
| 列出所有会话   | `screen -ls`             | 显示会话ID、状态和名称                  |
| 恢复会话       | `screen -r <ID/名称>`    | 重新连接已分离的会话                    |
| 多用户共享会话 | `screen -x <ID/名称>`    | 多人同时连接同一会话（需权限）          |
| 强制恢复会话   | `screen -r -d <ID/名称>` | 踢出其他用户后恢复（管理员权限）        |
| 分离当前会话   | `Ctrl + a` `d`           | 保持会话后台运行                        |
| 结束会话       | `exit` 或 `Ctrl + d`     | 终止当前会话并关闭窗口                  |
| 锁定会话       | `Ctrl + a` `x`           | 密码保护当前会话（需设置`~/.screenrc`） |

---

#### **2. 窗口管理**
| **操作**       | **快捷键**       | **说明**                     |
| -------------- | ---------------- | ---------------------------- |
| 新建窗口       | `Ctrl + a` `c`   | 创建新窗口并切换到它         |
| 切换下一个窗口 | `Ctrl + a` `n`   | 按编号顺序切换               |
| 切换上一个窗口 | `Ctrl + a` `p`   | 反向顺序切换                 |
| 选择窗口       | `Ctrl + a` `0-9` | 直接跳转到指定编号窗口       |
| 窗口列表       | `Ctrl + a` `"`   | 可视化选择窗口               |
| 重命名当前窗口 | `Ctrl + a` `A`   | 修改窗口标题                 |
| 关闭当前窗口   | `Ctrl + a` `k`   | 终止当前窗口（需确认）       |
| 杀死所有窗口   | `Ctrl + a` `\`   | 终止整个会话（包括所有窗口） |

---

#### **3. 分屏与区域管理**
| **操作**     | **快捷键**                | **说明**                   |
| ------------ | ------------------------- | -------------------------- |
| 水平分屏     | `Ctrl + a` `S`            | 将当前区域分为上下两部分   |
| 垂直分屏     | `Ctrl + a` `\|`           | 将当前区域分为左右两部分   |
| 切换分屏区域 | `Ctrl + a` `Tab`          | 循环切换活动区域           |
| 关闭当前区域 | `Ctrl + a` `X`            | 仅保留当前区域             |
| 关闭其他区域 | `Ctrl + a` `Q`            | 关闭除当前区域外的所有区域 |
| 调整区域大小 | `Ctrl + a` `:` + `resize` | 动态调整分屏比例           |

---

#### **4. 日志与输出控制**
| **操作**       | **命令/快捷键**          | **说明**                    |
| -------------- | ------------------------ | --------------------------- |
| 启用日志记录   | `screen -L`              | 记录会话输出到`screenlog.x` |
| 自定义日志文件 | `screen -Logfile <路径>` | 指定日志路径                |
| 实时监控输出   | `Ctrl + a` `H`           | 开启/停止日志记录（需配置） |
| 清除屏幕缓冲区 | `Ctrl + a` `C`           | 清空当前窗口内容            |
| 进入滚动模式   | `Ctrl + a` `[`           | 查看历史输出（按`Esc`退出） |

---

#### **5. 高级配置与技巧**
| **操作**         | **说明**                                           |
| ---------------- | -------------------------------------------------- |
| 自定义快捷键     | 在`~/.screenrc`中添加：`bind <键> <命令>`          |
| 启动时执行命令   | `screen -dmS <名称> <命令>` 后台启动会话并运行命令 |
| 多显示器支持     | 使用`-t`参数为窗口设置标题：`screen -t "Shell1"`   |
| 会话密码保护     | 在`~/.screenrc`中设置：`password <密码>`           |
| 禁用启动欢迎信息 | 在`~/.screenrc`中添加：`startup_message off`       |

### **典型使用场景示例**
1. **后台运行长期任务**  
   ```bash
   screen -S data_processing
   # 运行任务后按 Ctrl + a d 分离
   ```

2. **恢复丢失的SSH会话**  
   ```bash
   screen -ls           # 查找会话ID
   screen -r 1284.data  # 恢复指定会话
   ```

3. **分屏操作演示**  
   - `Ctrl + a S` → 水平分屏  
   - `Ctrl + a Tab` → 切换区域  
   - `Ctrl + a c` → 在新区域创建窗口  

4. **记录服务器操作日志**  
   ```bash
   screen -L -S admin_log
   # 所有操作将记录到screenlog.0
   ```

---

### **配置文件示例（~/.screenrc）**
```bash
# 启用状态栏
caption always "%{= kw}%-w%{= BW}%n %t%{-}%+w %-= %d/%m/%Y %c"

# 设置默认日志路径
logfile /tmp/screenlog_%t.log

# 自定义快捷键
bind ^u kill
bind j focus down
bind k focus up
```
