## abstract

介绍 Bash 中处理整数运算的核心机制。

------

### `let` 命令及算术求值

用法： `let 参数 [参数 ...]`

功能： 计算算术表达式。

将每个“参数”作为一个算术表达式进行求值。计算采用**固定宽度整数**，不检查溢出；但除以 0 会被捕获并报错。以下运算符列表按**优先级从高到低**排列，同一行的运算符优先级相同：

1. `id++`, `id--`：变量后自增、后自减
2. `++id`, `--id`：变量前自增、前自减
3. `-`, `+`：一元负号、正号
4. `!`, `~`：逻辑取反、按位取反
5. `**`：指数运算
6. `*`, `/`, `%`：乘法、除法、取模（余数）
7. `+`, `-`：加法、减法
8. `<<`, `>>`：左移、右移位运算
9. `<=`, `>=`, `<`, `>`：比较运算
10. `==`, `!=`：相等、不等判断
11. `&`：按位与
12. `^`：按位异或
13. `|`：按位或
14. `&&`：逻辑与
15. `||`：逻辑或
16. `expr ? expr : expr`：三元条件运算符
17. `=`, `*=`, `/=`, `%=`, `+=`, `-=`, `<<=`, `>>=`, `&=`, `^=`, `|=`：赋值运算

### 表格

| **分类**     | **运算符**        | **说明**                         | **示例**                | **结果 / 备注**                |
| ------------ | ----------------- | -------------------------------- | ----------------------- | ------------------------------ |
| **基础算术** | `+ - * / % **`    | 加、减、乘、除、取模、**幂运算** | `((a=3**3))`            | `a` 为 27 (3³)                 |
| **自增减**   | `++ --`           | 前置/后置 自增或自减             | `((b=a++))`             | 先赋值 `b=a`，再执行 `a=a+1`   |
| **逻辑比较** | `< <= > >= == !=` | 比较大小，**返回 0 或 1**        | `((3 > 2))`             | 退出状态 `$?` 为 0 (真)        |
| **位运算**   | `<< >> & | ^ ~`   | 位移、按位与、或、异或、取反     | `((8 >> 2))`            | 结果为 2 (二进制 1000 变成 10) |
| **逻辑组合** | `&& || !`         | 逻辑与、逻辑或、非               | `((a>0 && a<10))`       | 用于组合多个判断条件           |
| **赋值类**   | `= += -= *=...`   | 运算并赋值                       | `((a += 5))`            | 等同于 `a = a + 5`             |
| **三元运算** | `? :`             | 条件表达式                       | `((max = a>b ? a : b))` | 取 a 和 b 中的较大值           |

### 按位运算

> 假设我们有两个操作数（以 8 位二进制为例）：
>
> - **A = 60** (二进制: `0011 1100`)
> - **B = 13** (二进制: `0000 1101`)

| **运算符** | **名称**           | **原理**                        | **示例 ((C = A op B))** | **C 的结果 (二进制)** |
| ---------- | ------------------ | ------------------------------- | ----------------------- | --------------------- |
| **`&`**    | **按位与 (AND)**   | 两位均为 1 则为 1，否则为 0     | `((C = A & B))`         | `12` (`0000 1100`)    |
| **`|`**    | **按位或 (OR)**    | 两位只要有一个 1 则为 1         | `((C = A | B))`         | `61` (`0011 1101`)    |
| **`^`**    | **按位异或 (XOR)** | 两位不同则为 1，相同则为 0      | `((C = A ^ B))`         | `49` (`0011 0001`)    |
| **`~`**    | **按位取反 (NOT)** | 0 变 1，1 变 0 (符号位也会转置) | `((C = ~A))`            | `-61` (补码形式)      |
| **`<<`**   | **左移 (L-Shift)** | 位向左移动，右侧补 0            | `((C = A << 2))`        | `240` (`1111 0000`)   |
| **`>>`**   | **右移 (R-Shift)** | 位向右移动，左侧补符号位        | `((C = A >> 2))`        | `15` (`0000 1111`)    |

```bash
$ echo $((8>>2))
2
```



### 变量使用

**Shell 变量可以直接作为操作数**。在表达式内部，**变量名会被替换为其对应的值**（强制转换为固定宽度整数）。使用变量时，不需要提前为变量开启整数属性（declare -i）。

执行顺序：

运算符按优先级求值。括号内的子表达式优先计算，可覆盖上述优先级规则。

退出状态（Exit Status）：

如果最后一个参数的计算结果为 0，let 返回 1；否则返回 0。

## 展开介绍：深度解析与实战技巧

#### 1. `let` 与 `(( ))` 的关系

手册里说 `let` 计算表达式，而 `(( ))` 实际上是 `let` 的**高级语法糖**。

- `let "a = 5 + 2"` 等价于 `(( a = 5 + 2 ))`。
- **区别**：`(( ))` 不需要引号，支持空格更友好，是现代脚本的首选。

#### 2. 令人困惑的“退出状态” (Exit Status)

这是初学者最容易出错的地方。Bash 的逻辑是：

- **算术结果为 0** $\rightarrow$ **退出码为 1** (代表“假/失败”)。
- **算术结果非 0** $\rightarrow$ **退出码为 0** (代表“真/成功”)。

**例子：**

```Bash
a=0
(( a )) 
echo $?  # 输出 1，因为 a 是 0，逻辑判定为“失败”

(( a + 5 ))
echo $?  # 输出 0，因为结果是 5，逻辑判定为“成功”
```

*提示：这和 C 语言的逻辑一致（0 为假），但与 Shell 命令执行的逻辑（0 为成功）刚好相反。*

#### 3. 变量引用的简化

在 `let` 或 `(( ))` 内部，引用变量**不需要**加 `$` 符号。

```Bash
x=10
y=20
let "z = x + y"   # 正确，不需要 $x + $y
(( z = x + y ))   # 同样正确
```

如果变量是空的或未定义，它会被当作 `0` 处理。

#### 4. 固定宽度整数与溢出

Bash 的整数通常是 **64 位有符号整数**（取决于编译环境，可用 `getconf LONG_BIT` 查看）。

- 它不支持浮点数（如 `1/2` 结果是 `0`）。
- **溢出示例**：如果你计算超过 $2^{63}-1$ 的数，它会回绕到负数，且不会报错。

#### 5. 进制转换技巧

`let` 强大之处在于支持任意进制（2 到 64 进制）：

- **格式**：`[进制#]数值`(进制就是**基**)

```bash
let "x = 2#1010"  # 二进制1010转换为十进制就是10，x 变为 10
let "y = 16#FF"    # 十六进制，y 变为 255
let "z = 8#77"     # 八进制
```

------

```bash
$ echo "$((2#1111))"
15

$ echo "$((c=2#1101))"
13
$ echo $c
13
```
