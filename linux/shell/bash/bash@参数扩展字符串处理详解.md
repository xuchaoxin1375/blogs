## abstract

下面是对 Bash Reference Manual 中 **“Shell Parameter Expansion（参数展开）”**这一节的要点梳理，并按功能做成了总结表格，方便当速查表用。 

---

## 总体规则（理解表格前先记住这 4 条）

1. **基本形式**：`${parameter}` 展开为参数值；花括号用于“**保护变量名边界**”。当你用多位位置参数（如第 11 个参数）或变量名后紧跟字母数字等字符时，**花括号是必须的**。   
2. **`word` 会先被展开**：在 `:-`、`:=`、`:?`、`:+` 等形式里，`word` 会先经历（至少）tilde/参数/命令/算术展开。   
3. **“带冒号”和“不带冒号”差别很关键**：  
   - `:-` / `:=` / `:?` / `:+`：测试 **unset 或 null（空串）**  
   - `-` / `=` / `?` / `+`：只测试 **unset**（变量已设置但为空串时，视为“已设置”）   
4. **很多展开的结果仍会继续参与“分词 + 文件名展开（globbing）”**（除非你正确引用/用数组等方式控制）。

## 总结表 1：默认值 / 赋值 / 报错 / 条件替换（最常用）

| 形式         | 何时触发                   | 展开结果（做什么）                                           | 常见用途/注意点                                             |
| ------------ | -------------------------- | ------------------------------------------------------------ | ----------------------------------------------------------- |
| `${p:-word}` | `p` **unset 或空串**       | 用 `word` 替代；否则用 `$p`                                  | “给默认值（不修改变量）”                                    |
| `${p-word}`  | `p` **unset**              | 用 `word`；否则用 `$p`（即使 `$p` 是空串也算“否则”）         | 只关心“是否存在”而不把空串当缺省                            |
| `${p:=word}` | `p` **unset 或空串**       | 把 `word` **赋给 `p`**，并返回赋值后的值                     | “懒初始化（会修改变量）”；**位置参数/特殊参数不能这样赋值** |
| `${p=word}`  | `p` **unset**              | 把 `word` 赋给 `p`，并返回它                                 | 不把空串当缺省；同样会修改变量                              |
| `${p:?word}` | `p` **unset 或空串**       | 向 stderr 输出 `word`（或默认提示）；非交互 shell 会退出非 0 | “强制要求变量必须有值”；交互 shell 不退出但会中止该命令     |
| `${p?word}`  | `p` **unset**              | 同上（但空串不算触发）                                       | 用于“必须设置过”，允许为空串                                |
| `${p:+word}` | `p` **已设置且非空串**     | 展开为 `word`；否则为空                                      | “如果有值就启用某段文本/参数”；注意：返回的不是 `$p`        |
| `${p+word}`  | `p` **已设置**（哪怕空串） | 展开为 `word`；否则为空                                      | “只要变量存在就启用”                                        |

## 总结表 2：子串（切片）/ 枚举 / 长度

| 形式                                        | 含义                                                         | 关键规则/坑                                                  |
| ------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `${p:offset}` / `${p:offset:length}`        | 子串展开：从 `offset` 开始取最多 `length` 个字符             | `offset/length` 是算术表达式；`offset<0` 表示从末尾倒数；**负 offset 要和冒号至少隔一个空格**避免被解析成 `:-`；`length<0` 有特殊含义（按“从末尾倒数的终点”解释） |
| `${@:offset:length}` / `${*:offset:length}` | 对位置参数做子串式“切片”（返回若干个位置参数）               | `offset` 允许负数（从最后倒数）；`length<0` 是错误；`offset=0` 时会把 `$0` 加进结果 |
| `${array[@]:offset:length}`                 | 对索引数组切片                                               | 关联数组上做子串切片**结果未定义**                           |
| `${!prefix*}` / `${!prefix@}`               | 展开为**变量名列表**：所有名字以 `prefix` 开头的变量         | 默认用 `IFS` 首字符分隔；当用 `@` 且在双引号内时，每个变量名作为独立词 |
| `${!name[@]}` / `${!name[*]}`               | 若 `name` 是数组：展开为数组下标（key）列表；若不是数组：`name` 已设置则为 `0`，否则为空 | 同样：`@` 在双引号内会逐个成词                               |
| `${#p}`                                     | 返回 `$p` 的长度（字符数）                                   | `p` 为 `@/*` 时返回位置参数个数；`array[@]` 返回元素个数；索引数组允许负下标（从末尾倒数） |

## 总结表 3：按模式删除前缀/后缀（“修剪字符串”神器）

这些 `word` 不是正则，而是 **glob 模式**（`* ? [...]` 等；必要时可配合 `extglob`）。   

| 形式            | 做什么                        | “短/长匹配”      |
| --------------- | ----------------------------- | ---------------- |
| `${p#pattern}`  | 删除开头匹配 `pattern` 的部分 | 删除**最短**匹配 |
| `${p##pattern}` | 删除开头匹配 `pattern` 的部分 | 删除**最长**匹配 |
| `${p%pattern}`  | 删除结尾匹配 `pattern` 的部分 | 删除**最短**匹配 |
| `${p%%pattern}` | 删除结尾匹配 `pattern` 的部分 | 删除**最长**匹配 |

补充：当 `p` 是 `@/*` 或 `array[@]` 这类“多值”，上述操作会对每个元素逐个应用，得到列表。

## 总结表 4：按模式替换（类似“内置的 sed 轻量版”）

| 形式                     | 做什么                                     | 关键规则/注意点                                              |
| ------------------------ | ------------------------------------------ | ------------------------------------------------------------ |
| `${p/pat/str}`           | 把 **第一个**匹配 `pat` 的子串替换成 `str` | 说明里强调：替换的是“最长匹配”；`str` 会经历多种展开（含命令/进程替换等） |
| `${p//pat/str}`          | 替换 **所有**匹配                          | 同上                                                         |
| `${p/#pat/str}`          | 只有当 `pat` 匹配**开头**时才替换          | 等价“锚定开头”                                               |
| `${p/%pat/str}`          | 只有当 `pat` 匹配**结尾**时才替换          | 等价“锚定结尾”                                               |
| `${p/pat}`（省略 `str`） | 删除匹配（当 `str` 展开为空时）            | 匹配会被删除，并且 `pat` 后的 `/` 可省略                     |

两个实战坑点（文档讲得很细）：
- 若 `shopt -s patsub_replacement`，则替换串里**未引用的 `&`**会被替换为“匹配到的那段”。想要字面量 `&` 需要引用/转义。   
- 引用会影响替换串的行为：只引用替换串的一部分，会只对那部分禁用一些替换效果；文档也提示一般很少需要“只给 str 加双引号”。

## 总结表 5：大小写转换（按字符匹配 pattern）

| 形式            | 做什么                           | 规则                                                     |
| --------------- | -------------------------------- | -------------------------------------------------------- |
| `${p^pattern}`  | 将**第一个字符**（若匹配）转大写 | `pattern` 是 glob 模式；省略时等价 `?`（匹配任意单字符） |
| `${p^^pattern}` | 将**所有匹配字符**转大写         | 同上                                                     |
| `${p,pattern}`  | 将第一个匹配字符转小写           | 同上                                                     |
| `${p,,pattern}` | 将所有匹配字符转小写             | 同上；并提示：pattern 不应试图匹配多个字符               |

同样地：当 `p` 是 `@/*` 或 `array[@]`，会逐个元素应用。

## 总结表 6：`${parameter@operator}`（“变换/自省”操作符）

| 形式                | operator 含义                                                | 典型用途                                 |
| ------------------- | ------------------------------------------------------------ | ---------------------------------------- |
| `${p@U}` / `${p@L}` | 全部转大写 / 全部转小写                                      | 快速做大小写归一化                       |
| `${p@u}`            | 首字母转大写（若为字母）                                     | 标题化、格式化输出                       |
| `${p@Q}`            | 生成“可复用为输入”的引用形式（quoted）                       | 做安全打印/生成可回放命令片段            |
| `${p@E}`            | 解释反斜杠转义（类似 `$'...'`）                              | 需要把 `\n` 等转义真正变成换行时         |
| `${p@P}`            | 把值当作 prompt 字符串方式展开                               | 自定义提示符相关玩法                     |
| `${p@A}`            | 输出可重建该变量的赋值/declare 语句                          | 调试、序列化变量（含属性）               |
| `${p@K}` / `${p@k}` | 输出数组 key/value（`K` 更偏“可重用输入格式”；`k` 会把 key/value 分成多个词） | 导出数组内容、调试数组                   |
| `${p@a}`            | 输出表示变量属性的 flag 字符串                               | 查看变量属性（readonly/export/array 等） |

## 额外但非常重要：间接展开（Indirect Expansion）

- `${!p}`：如果 `p` 的值是另一个变量名，那么会再取“那个变量”的值（相当于“指针解引用”）。   
- 文档也强调：如果 `p` 是 nameref（`declare -n`），`${!p}` 的含义会偏向“返回被引用变量名”，以保持兼容；并且 `${!prefix*}`、`${!name[@]}` 这两类有专门规则。   

---

## 实用速记

- 默认值：`:-`（不改变量） vs `:=`（会把默认值写回变量）   
- 必填参数：`${VAR:?message}`（脚本里常用“缺参即退出”）   
- 去扩展名：`${f%.*}`（最短后缀） / `${f%%.*}`（最长后缀）   
- 去目录：`${path##*/}`（取 basename）/ `${path%/*}`（取 dirname 的简化版，注意根目录等边界）   
- 替换所有：`${s//old/new}`
