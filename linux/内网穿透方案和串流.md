## 串流

- “串流”（Streaming）是一种在互联网上传输数据的方法，特别常用于传输音频和视频内容。
- 与传统的下载方式不同，串流技术允许用户在数据传输过程中即时播放内容，而无需等待整个文件下载完成。下面是一些关键概念和应用领域：

### 关键概念

1. **实时传输**（Real-Time Transmission）：数据在传输的同时可以被接收和播放，用户可以立即观看或听到内容。
2. **缓存**（Buffering）：在播放过程中，数据会提前被下载到本地缓存，以避免播放中断。
3. **带宽**（Bandwidth）：网络的传输速率，对于高质量的串流（如4K视频），需要更高的带宽支持。

### 应用领域

1. **视频串流**（Video Streaming）：如Netflix、YouTube、Hulu等平台，用户可以在线观看电影、电视剧、短视频等。
2. **音频串流**（Audio Streaming）：如Spotify、Apple Music、Pandora等平台，用户可以在线收听音乐、播客（Podcast）等。
3. **游戏串流**（Game Streaming）：如Twitch、YouTube Gaming、Nvidia GeForce Now、Google Stadia等平台，用户可以实时观看或参与游戏直播。
4. **直播**（Live Streaming）：实时视频传输，用于在线会议、网络研讨会、直播活动等。

### 技术实现

1. **协议**（Protocols）：常用的串流协议包括RTMP（Real-Time Messaging Protocol）、HLS（HTTP Live Streaming）、DASH（Dynamic Adaptive Streaming over HTTP）等。
2. **编解码器**（Codecs）：用于压缩和解压缩音视频数据，常见的编解码器包括H.264、H.265、AAC等。
3. **内容分发网络**（CDN, Content Delivery Network）：分布式服务器网络，帮助加快内容传输速度并减少延迟。

## 内网穿透

内网穿透（NAT Traversal），也称为内网映射，是一种技术，用于使处于防火墙或NAT（网络地址转换）设备后面的设备能够与外部互联网进行通信。这对于需要外部访问内部网络服务（如远程桌面、家庭服务器、物联网设备等）特别重要。

### 关键概念

1. **NAT（网络地址转换）**：
   - **静态NAT**：将内部网络的私有IP地址静态映射为外部网络的公共IP地址。
   - **动态NAT**：使用一组公共IP地址动态映射内部网络的私有IP地址。
   - **PAT（端口地址转换）**：也称为NAT Overload，将多个私有IP地址映射到一个公共IP地址，但使用不同的端口号来区分不同的内部设备。

2. **防火墙**：一种网络安全系统，监控和控制进入和离开网络的流量，防止未经授权的访问。

### 内网穿透方法

1. **端口映射（Port Forwarding）**：在路由器上配置端口转发规则，将来自外部的特定端口的流量重定向到内部网络设备的相应端口。适合家庭网络中的简单应用。

2. **UPnP（通用即插即用）**：自动配置路由器上的端口映射，适用于不熟悉网络配置的用户。

3. **反向代理（Reverse Proxy）**：使用反向代理服务器接收来自外部的请求，并将请求转发给内部服务器。常见的反向代理软件有Nginx和Apache。

4. **VPN（虚拟专用网络）**：通过加密隧道将外部设备连接到内部网络，使得外部设备仿佛位于内部网络中。适用于需要安全连接的场景。

5. **STUN/TURN**：主要用于实时通信（如视频通话）的内网穿透技术。STUN（Session Traversal Utilities for NAT）帮助设备发现自己的公共IP地址和端口，TURN（Traversal Using Relays around NAT）则用于在直接通信失败时提供中继服务。

6. **第三方服务**：如Ngrok、Frp等，通过第三方服务器实现内网穿透，用户只需简单配置即可使用，非常适合个人和小型项目。

## 内网穿透方案

相关方案有不少,有些有一定的免费额度

### 使用Ngrok实现内网穿透

Ngrok是一个非常流行的内网穿透工具，允许你将本地服务器公开到互联网上。

- [Overview | ngrok documentation](https://ngrok.com/docs)

- [Quickstart | ngrok documentation](https://ngrok.com/docs/getting-started/)

Ngrok 为开发测试用途提供了一个有限的免费套餐

- 注册并下载Ngrok：https://ngrok.com/

- 例如映射http端口,启动Ngrok并指定本地端口：

  - [ngrok http documentation](https://ngrok.com/docs/http/)

  ```bash
  ngrok http 8080
  ```

  这将本地的8080端口映射到一个公开的URL。
