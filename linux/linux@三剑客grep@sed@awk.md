`grep`、`sed` 和 `awk` 是 Linux/Unix 系统中三个非常强大且常用的**文本处理命令行工具**，常被称为“文本处理三剑客”。它们各自有不同的侧重点，但经常配合使用，能高效完成日志分析、数据提取、格式转换等任务。

---

## 1. `grep` —— 文本搜索工具

### 📌 作用：
在文件或标准输入中**查找匹配指定模式（正则表达式）的行**。

### 🔧 常用语法：
```bash
grep [选项] '模式' 文件
```

### ✅ 常用选项：
- `-i`：忽略大小写  
- `-v`：反向匹配（显示不匹配的行）  
- `-r`：递归搜索目录  
- `-n`：显示行号  
- `-E`：使用扩展正则表达式（等价于 `egrep`）  
- `-l`：只显示匹配的文件名  

### 🌰 示例：
```bash
# 查找包含 "error" 的行（忽略大小写）
grep -i "error" /var/log/syslog

# 查找以 "2024" 开头的行
grep "^2024" access.log

# 递归查找当前目录下所有 .conf 文件中包含 "listen" 的行
grep -r "listen" --include="*.conf" .
```

## 2. `sed` —— 流编辑器（Stream Editor）

### 📌 作用：
对输入流（文件或管道）进行**逐行文本替换、删除、插入、修改等操作**，常用于批量文本替换。

### 🔧 基本语法：
```bash
sed [选项] '命令' 文件
```

### ✅ 常用命令：
- `s/pattern/replacement/`：替换（最常用）  
- `d`：删除匹配行  
- `p`：打印（需配合 `-n` 使用）  
- `i` / `a`：在行前/后插入文本  

### 🌰 示例：
```bash
# 将文件中所有 "foo" 替换为 "bar"（仅输出，不修改原文件）
sed 's/foo/bar/g' file.txt

# 直接修改原文件（谨慎使用！）
sed -i 's/foo/bar/g' file.txt

# 删除所有空行
sed '/^$/d' file.txt

# 打印第 5 到第 10 行
sed -n '5,10p' file.txt
```

> 💡 `sed` 默认不修改原文件，除非加 `-i` 选项。

## 3. `awk` —— 文本分析与数据处理语言

### 📌 作用：
按**字段（列）**处理文本，适合结构化数据（如日志、CSV），功能接近一门小型编程语言。

### 🔧 基本语法：
```bash
awk [选项] 'pattern { action }' 文件
```

- 默认以**空格或制表符**分隔字段
- `$0` 表示整行，`$1`、`$2`... 表示第1、2...列
- `NR`：当前行号；`NF`：字段数量

### ✅ 常用功能：
- 提取列
- 条件过滤
- 数值计算
- 自定义格式输出

### 🌰 示例：
```bash
# 打印 access.log 中的第1列（IP地址）
awk '{print $1}' access.log

# 打印状态码为 404 的请求（假设状态码在第9列）
awk '$9 == 404 {print $0}' access.log

# 统计文件行数
awk 'END {print NR}' file.txt

# 按逗号分隔，并打印第2列
awk -F',' '{print $2}' data.csv
```

## 🔄 三者对比总结

| 工具   | 主要用途                    | 特点                           |
| ------ | --------------------------- | ------------------------------ |
| `grep` | **查找**匹配行              | 快速过滤，适合搜索             |
| `sed`  | **编辑**文本（替换/删除等） | 流式处理，适合批量修改         |
| `awk`  | **分析**结构化文本（按列）  | 编程能力强，适合数据提取与计算 |

---

## 💡 组合使用示例

```bash
# 查找日志中 404 错误，并提取 IP 和 URL
grep " 404 " access.log | awk '{print $1, $7}'

# 替换配置文件中的 IP，并只处理包含 "server" 的行
sed -n '/server/s/192.168.1.1/10.0.0.1/gp' nginx.conf

# 统计访问最多的前5个IP
awk '{print $1}' access.log | sort | uniq -c | sort -nr | head -5
```
