## abstract

在 Vim 中，删除操作非常强大且灵活，它通常由一个**操作符 (Operator)** 和一个**动作/范围 (Motion/Text Object)** 组成。

------

## ️ Vim 删除操作符：`d` (delete)

在 **普通模式 (Normal Mode)** 下，删除操作的核心是操作符 `d`。

当您输入 `d` 后，Vim 就会等待您输入一个动作或文本对象来指定删除的范围。

### 1. 结合动作 (Motion) 删除

动作定义了光标将移动的距离或方向，`d` 会删除从**当前光标位置**到**动作目标位置**的所有内容（不包括目标位置本身，除非动作是面向行的）。

| **命令** | **动作**             | **描述**                                                     |
| -------- | -------------------- | ------------------------------------------------------------ |
| `dw`     | `w` (word)           | 删除从光标到**下一个单词开头**的内容（包括空格）。           |
| `d$`     | `$` (end of line)    | 删除从光标到**行尾**的所有内容。                             |
| `d^`     | `^` (start of line)  | 删除从光标到**行首第一个非空白字符**的内容。                 |
| `d0`     | `0` (absolute start) | 删除从光标到**行首**（包括行首的空白字符）。                 |
| `de`     | `e` (end of word)    | 删除从光标到**当前单词末尾**的内容。                         |
| `dG`     | `G` (go to line)     | 删除从当前行到**文件末尾**的所有内容。                       |
| `dgg`    | `gg` (go to line)    | 删除从当前行到**文件开头**的所有内容。                       |
| `dfx`    | `fx` (find 'x')      | 删除从光标到**下一个字符 `x`** 出现位置（包含 `x`）之间的内容。 |
| `dtx`    | `tx` (to 'x')        | 删除从光标到**下一个字符 `x`** 出现位置（不包含 `x`）之间的内容。 |
| `d2l`    | `2l` (right)         | 删除光标右侧的两个字符。                                     |
| `d3j`    | `3j` (down)          | 删除从当前行到下面的三行（共四行）。                         |

快速删除整行

> 重复按两次 d，即 dd，可以快速删除当前光标所在的整行。

------

### 2. 结合文本对象 (Text Object) 删除

文本对象允许您删除结构化的文本块，如整个单词、句子、段落、括号内内容等，而**无需考虑光标的起始位置**。

文本对象通常以 `i` (inner, 内部) 或 `a` (a/around, 外部/周围) 开头。

| **命令**       | **文本对象**           | **描述**                                 |
| -------------- | ---------------------- | ---------------------------------------- |
| `daw`          | `aw` (a word)          | 删除**整个单词**和它周围的一个**空格**。 |
| `diw`          | `iw` (inner word)      | 删除**整个单词**（不包括周围的空格）。   |
| `das`          | `as` (a sentence)      | 删除**整个句子**和它周围的空格。         |
| `dip`          | `ip` (inner paragraph) | 删除**整个段落**（不包括其后的空行）。   |
| `dap`          | `ap` (a paragraph)     | 删除**整个段落**（包括其后的空行）。     |
| `di(` 或 `di)` | `i(`                   | 删除**小括号 `()`** 内部的所有内容。     |
| `da(` 或 `da)` | `a(`                   | 删除**小括号 `()`** 及其内部的所有内容。 |
| `di[` 或 `di]` | `i[`                   | 删除**中括号 `[]`** 内部的所有内容。     |
| `di{` 或 `di}` | `i{`                   | 删除**大括号 `{}`** 内部的所有内容。     |
| `di"`          | `i"`                   | 删除**双引号 `""`** 内部的所有内容。     |

------

### 3. 使用计数器 (Count)

您可以在 `d` 操作符或动作之前添加一个数字 (Count) 来重复该操作。

| **命令** | **描述**                                    |
| -------- | ------------------------------------------- |
| `3dd`    | 删除从当前行开始的** 3 行**。               |
| `5dw`    | 删除从当前位置开始的** 5 个单词**。         |
| `d2f,`   | 删除到**第二个逗号**（`,`）出现位置的内容。 |
| `4dap`   | 删除从当前位置开始的** 4 个段落**。         |

------

## ✂️ 删除与剪切/粘贴

在 Vim 中，**所有的删除操作实际上都是剪切 (Cut) 操作**：

1. 被删除的内容会被放入一个特殊的寄存器（Register）中，默认是**匿名寄存器 `"`**。
2. 您可以使用 **`p` (put) 或 `P` (Put)** 命令将删除的内容**粘贴**（Paste）回来。
   - `p`：粘贴在光标之后/下一行。
   - `P`：粘贴在光标之前/上一行。

> 🌟 实用技巧：
>
> 如果您想删除内容但不放入寄存器（即不想覆盖上一次的剪切内容），可以使用黑洞寄存器 "_：
>
> - 例如：**`"_dd`** 会删除当前行，但不会覆盖您的剪切板内容。

------

## ↩️ 撤销操作

无论您进行了何种删除操作，都可以使用 **`u` (undo)** 命令来**撤销**上一步的操作。
