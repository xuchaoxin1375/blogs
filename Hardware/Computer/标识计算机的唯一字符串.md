## abstract

标识计算机的唯一字符串通常指的是 **唯一标识符（UUID, Unique Identifier）**，用于识别一台计算机或其特定组件。以下是几种常见的方式来获取计算机的唯一标识符：

### 1. **基于硬件信息**

#### （1）主板UUID / BIOS序列号

- Windows:

  ```powershell
  wmic bios get serialnumber
  ```

- Linux/macOS:

  ```bash
  cat /sys/class/dmi/id/product_uuid  # Linux
  system_profiler SPHardwareDataType | grep "Hardware UUID"  # macOS
  ```

- 这种方法通常不会变更，适用于唯一标识计算机，但有些设备可能没有有效的 BIOS UUID。

#### （2）CPU ID🎈

- Windows:

  ```powershell
  wmic cpu get processorid
  ```

- Linux:

  ```bash
  cat /proc/cpuinfo | grep 'Serial'
  ```

- CPU ID 通常是唯一的，但某些情况下（如虚拟机）可能会相同。

#### （3）MAC 地址

- Windows:

  ```powershell
  getmac
  ```

- Linux/macOS:

  ```bash
  cat /sys/class/net/eth0/address
  ```

- **局限性**：MAC 地址可以被修改或克隆，且多网卡的设备可能有多个 MAC 地址。

### 2. **基于操作系统**

#### （1）Windows 安装 ID

```powershell
wmic path Win32_OperatingSystem get SerialNumber
```

- Windows 许可证密钥相关，可以用于标识系统但可能会随重装变化。

#### （2）Linux 机器 ID

```bash
cat /etc/machine-id  # 大多数 Linux 发行版
cat /var/lib/dbus/machine-id  # 部分 Linux 发行版
```

- **稳定性**：一般不会变，但重装系统可能会变更。

#### （3）macOS 设备 UUID

```bash
ioreg -rd1 -c IOPlatformExpertDevice | grep "IOPlatformUUID"
```

- 这个 UUID 是 Apple 提供的唯一标识符。

### 3. **组合多个信息生成唯一 ID**

为了更稳妥地唯一标识一台计算机，可以组合多个硬件信息生成哈希值：

```python
import hashlib
import platform
import uuid

def get_unique_id():
    system_info = f"{platform.node()}-{platform.system()}-{platform.processor()}-{uuid.getnode()}"
    return hashlib.sha256(system_info.encode()).hexdigest()

print(get_unique_id())
```

这个方法利用主机名、操作系统、CPU 信息和 MAC 地址的哈希值，生成一个唯一的标识符，避免单点数据的不稳定性。

### 4. **虚拟机环境识别**

在虚拟机或云服务器环境下，传统的硬件 UUID 可能会重复，因此需要结合 **虚拟机提供商的唯一标识符**：

- AWS: `curl http://169.254.169.254/latest/meta-data/instance-id`
- Google Cloud: `curl -H "Metadata-Flavor: Google" http://metadata.google.internal/computeMetadata/v1/instance/id`
- Azure: `curl -H Metadata:true --noproxy "*" "http://169.254.169.254/metadata/instance/compute/vmId?api-version=2021-01-01&format=text"`

### 结论

| 方法                 | 适用系统            | 是否唯一 | 是否会变更                 |
| -------------------- | ------------------- | -------- | -------------------------- |
| BIOS UUID            | Windows/Linux/macOS | 高       | 极少，除非更换主板         |
| CPU ID               | Windows/Linux       | 高       | 极少，除非更换 CPU         |
| MAC 地址             | Windows/Linux/macOS | 中       | 可能会变（网卡更换、修改） |
| Windows 安装 ID      | Windows             | 高       | 重装系统可能变化           |
| Linux `machine-id`   | Linux               | 高       | 重装系统可能变化           |
| macOS IOPlatformUUID | macOS               | 高       | 一般不会变                 |
| 组合哈希             | 通用                | 高       | 取决于组合数据             |

**推荐方式**：

- 若需要 **硬件层面** 唯一性，建议使用 **BIOS UUID 或 CPU ID**。
- 若需要 **软件层面** 唯一性，建议使用 **Linux `machine-id` 或 Windows 安装 ID**。
- 若需要 **最小变更影响**，建议组合多个信息后取哈希值。
