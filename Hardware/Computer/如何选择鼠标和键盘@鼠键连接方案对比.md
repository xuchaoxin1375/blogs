## 鼠标

关于蓝牙鼠标、2.4GHz无线鼠标和有线鼠标的详细对比表格，特别关注消费者相关的特性：

| 特性                | 蓝牙鼠标                               | 2.4GHz无线鼠标                        | 有线鼠标                              |
|---------------------|----------------------------------------|---------------------------------------|---------------------------------------|
| **连接方式**        | 蓝牙                                   | 2.4GHz无线接收器（USB Dongle）        | USB线缆                               |
| **便携性**          | 高，适合移动办公                       | 中等，需要携带接收器                  | 低，受限于线缆                        |
| **安装和配置**      | 简单，通过蓝牙配对                    | 简单，插入接收器自动连接               | 简单，插入USB接口即用                 |
| **响应速度**        | 中等，可能有轻微延迟                   | 高，响应速度快                         | 非常高                        |
| **电池寿命**        | 取决于电池类型和使用频率,以及是否有指示灯(比如电量指示灯,比较耗电) | 取决于电池类型和使用频率，通常较长    | 无需电池                              |
| **功耗** | 不同的蓝牙方案和版本有不同的功耗水平 | 均衡 | 插入电脑使用,功耗相比于计算机主体不值一提,通常不被关心 |
| **兼容性**          | 需要设备支持蓝牙，兼容性较广           | 需要USB接口，兼容性较广                | 需要USB接口，兼容性广                 |
| **稳定性**          | 可能受干扰影响                         | 稳定，但可能受其他2.4GHz设备干扰       | 非常稳定，不受无线干扰                |
| **价格**            | 中等至高                               | 中等                                  | 低至中等                              |
| **适用场景**        | 适合移动办公和轻度使用                 | 适合一般办公和游戏使用                | 适合专业游戏和高精度任务              |
| **外设需求**        | 无需额外外设                           | 需要携带接收器                        | 无需额外外设                          |
| **连接距离**        | 通常在10米以内                         | 通常在10米以内                        | 受限于线缆长度                        |
| **干扰情况**        | 可能受Wi-Fi和其他蓝牙设备干扰,但是需要点配对,所以比2.4Ghz的抗干扰要好 | 可能受Wi-Fi和其他2.4GHz设备干扰(比如在图书馆,时不时会出现别人的鼠标控制到你的计算机上了) | 无干扰                                |
| 电量信息 | 蓝牙设备的电量通常可以被操作系统读取,这是一大特色,蓝牙耳机的电量也是类似的 | 不带电量信息 | 不需要关心 |
| **设置复杂度**      | 需要蓝牙配对，可能稍复杂               | 插入接收器即可使用                    | 插入USB接口即可使用                   |
| 场景兼容性     | 需要进入系统才能够连接蓝牙使用 | 部分场景下未进入系统就可使用,例如有的BIOS下能使用 | 兼容性最好,无线鼠标能工作的场景有线一定可以(便携性除外) |

### 续航问题

- 充电鼠标的续航能力目前还远远无法和干电池无线鼠标匹敌;特别是带有电量显示和指示灯效果的鼠标要慎重选择,在充电鼠标本身续航能力不足的情况下,等效无疑会让不理想的续航雪上加霜
- 大部分充电式鼠标虽然重量和手感比干电池好,但续航能力是一个无线鼠标最基本的属性之一,优先级应该摆到更高的位置,毕竟频繁充电的话还不如直接用有线鼠标,延迟与价格还低,而且没有电池重量还轻

### 充电接口

- 现在Type-C口的充电鼠标基本普及,终于可以和手机笔电的快充线通用充电了,遗憾的是很多C口充电鼠标同时配上电量显示(而且几乎都是不可以单独关闭指示灯的),这样一来续航就很成问题
- 反而老式的Micro-B充电口的无线鼠标续航比较好
- 不过C口无指示灯的识别也是有的,或者直接选用干电池的方案来,续航拉满

### 鼠标模式数

- 通常支持蓝牙的鼠标同时也会支持2.4Ghz方案,也就是双模鼠标
- 现在支持双蓝牙(4.0+5.0)或者双5.0再外加一个2.4Ghz的三模鼠标也基本普及了

### 总结

- **蓝牙鼠标**：适合经常移动办公的用户，便携性高，但可能受干扰影响，响应速度中等。
- **2.4GHz无线鼠标**：适合一般办公和游戏使用，响应速度快，稳定性好，但需要携带接收器。
- **有线鼠标**：适合需要高精度和低延迟的专业用户，如游戏玩家和设计师，稳定性最高，无需担心电池问题。

希望这个表格可以帮助你更好地理解不同类型鼠标的优缺点，从而做出更合适的选择。

## 键盘

### 首要因素👺

- 对于**盲打**用户,键盘首先要看**布局**,其次是价格和种类
  - 对于盲打用户,改变键盘布局会大大影响输入效率,对于程序员更是如此,斜杠和回车经常用到
  - 在不同的电脑上来回切换,如果键盘布局不同,是很影响效率的
  - 总之,键盘布局不合适,那么无论做工,外观和用料以及延迟做得多么好,都难以让人满意
- 对于长期只操作一台计算机的用户可以,布局虽然变得不那么重要,我还是建议选择小回车键(也就是占一行的),因为这种布局和绝大多数笔记本是上的主体布局是一致的,和许多打字练习网站的布局也是一样的

### 下面是详细对比

- 选择键盘时，消费者通常关注以下几个重点内容：

  1. **键盘类型**：
     - **机械键盘**：使用物理开关（switches）触发按键，通常耐用且提供明显的按键反馈和音响效果。
     - **薄膜键盘**：按键通过薄膜电路触发，通常更轻便，但按键感觉和耐久性可能稍逊于机械键盘。

  2. **按键布局**：
     - **全尺寸键盘**：包含所有标准按键，包括数字键盘。
     - **TKL（无数字键盘）**：省略数字键盘，更紧凑，适合空间有限的环境。
     - **60%、75%、80%键盘**：更小巧的设计，省略不同程度的功能区，适合需要移动和便携的用户。

  3. **键盘连接**：
     - **有线键盘**：通过USB或PS/2接口连接。
     - **无线键盘**：使用蓝牙或RF连接，提供更大的灵活性和便携性，但需要电池或充电。

  4. **键盘功能**：
     - **背光键盘**：提供在暗光环境下使用的背光功能，有些键盘可调节颜色和亮度。
     - **多媒体控制**：额外的音量控制、媒体播放键等功能。

  5. **键盘品牌和质量**：
     - **知名品牌**：例如罗技（Logitech）、赛睿（SteelSeries）、雷蛇（Razer）等，在质量和售后服务上有一定保障。
     - **用户评价**：查看消费者对键盘的评价和反馈，了解实际使用体验。

  为了更清晰地比较不同种类的键盘，可以制作一张表格，列出各种键盘的特点和优缺点，如下所示：

  | 类型                | 特点                           | 优点                             | 缺点                               |
  | ------------------- | ------------------------------ | -------------------------------- | ---------------------------------- |
  | 机械键盘            | 使用物理开关，触感明显，耐用   | 易于长时间使用，音响效果好       | 价格较高，较大，按键有些嘈杂       |
  | 薄膜键盘            | 使用薄膜电路，轻便，价格较低   | 安静，价格相对较低               | 按键感觉较为模糊，寿命可能较短     |
  | TKL键盘             | 省略数字键盘，更紧凑           | 占用空间小，适合桌面环境较为狭窄 | 缺少数字键盘可能影响部分用户的使用 |
  | 小键盘 60%、75%键盘 | 极小巧设计，省略大部分功能区   | 便于携带，适合移动办公环境       | 功能较少，适应曲线较陡             |
  | 无线键盘            | 蓝牙或RF连接，便于移动         | 灵活性强，无线使用更方便         | 可能需要频繁充电或更换电池         |
  | 背光键盘            | 提供背光功能，适合暗光环境使用 | 美观，提升夜间使用体验           | 额外功耗，可能增加成本             |

  通过比较不同类型的键盘，消费者可以根据自己的需求和预算选择最适合的产品。
