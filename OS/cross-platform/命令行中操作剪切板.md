# 各系统Shell命令行操作剪切板方案

## 一、macOS

### 复制到剪切板
```bash
# pbcopy - macOS 内置命令
echo "hello" | pbcopy
cat file.txt | pbcopy
ls -la | pbcopy

# 复制文件内容
pbcopy < file.txt
```

### 从剪切板粘贴
```bash
# pbpaste - macOS 内置命令
pbpaste
pbpaste > output.txt
pbpaste | grep "keyword"
```

### 实用示例
```bash
# 复制当前路径
pwd | pbcopy

# 复制命令输出
git log --oneline | pbcopy

# 复制并查看内容
echo "hello" | tee /dev/tty | pbcopy
```

## 二、Linux（X11 环境）

### xclip
```bash
# 安装
sudo apt install xclip      # Debian/Ubuntu
sudo dnf install xclip      # Fedora
sudo pacman -S xclip        # Arch

# 复制到剪切板
echo "hello" | xclip -selection clipboard
cat file.txt | xclip -selection clipboard

# 从剪切板粘贴
xclip -selection clipboard -o
xclip -selection clipboard -o > output.txt

# 简写（primary selection，中键粘贴）
echo "hello" | xclip
xclip -o
```

### xsel
```bash
# 安装
sudo apt install xsel

# 复制
echo "hello" | xsel --clipboard --input
cat file.txt | xsel -bi

# 粘贴
xsel --clipboard --output
xsel -bo

# 清空剪切板
xsel --clipboard --clear
```

### 对比：xclip vs xsel
| 功能 | xclip                | xsel       |
| ---- | -------------------- | ---------- |
| 复制 | `xclip -sel clip`    | `xsel -bi` |
| 粘贴 | `xclip -sel clip -o` | `xsel -bo` |
| 清空 | -                    | `xsel -bc` |
| 追加 | -                    | `xsel -ba` |

## 三、Linux（Wayland 环境）

### wl-clipboard
```bash
# 安装
sudo apt install wl-clipboard

# 复制
echo "hello" | wl-copy
cat file.txt | wl-copy

# 粘贴
wl-paste
wl-paste > output.txt

# 复制文件（保持 MIME 类型）
wl-copy < image.png
wl-copy --type image/png < image.png

# 清空
wl-copy --clear

# 不换行复制
echo -n "hello" | wl-copy
```

## 四、Windows

### Windows 原生命令（CMD / PowerShell）

```cmd
:: CMD - 复制
echo hello | clip
type file.txt | clip
dir | clip

:: CMD - 粘贴（无内置命令，用 PowerShell）
powershell Get-Clipboard
```

```powershell
# PowerShell - 复制
"hello" | Set-Clipboard
Get-Content file.txt | Set-Clipboard
Set-Clipboard -Value "hello world"

# PowerShell - 粘贴
Get-Clipboard
Get-Clipboard | Out-File output.txt

# 复制多行
@("line1", "line2") | Set-Clipboard
```

### WSL（Windows Subsystem for Linux）

```bash
# 复制到 Windows 剪切板
echo "hello" | clip.exe
cat file.txt | clip.exe

# 从 Windows 剪切板粘贴
powershell.exe -command Get-Clipboard

# 创建别名（加入 .bashrc / .zshrc）
alias pbcopy='clip.exe'
alias pbpaste='powershell.exe -command Get-Clipboard'
```

## 五、跨平台统一方案

### 方案一：创建通用别名

```bash
# 加入 ~/.bashrc 或 ~/.zshrc

if [[ "$OSTYPE" == "darwin"* ]]; then
    # macOS
    alias clip='pbcopy'
    alias paste='pbpaste'
elif grep -qi microsoft /proc/version 2>/dev/null; then
    # WSL
    alias clip='clip.exe'
    alias paste='powershell.exe -command Get-Clipboard'
elif [[ -n "$WAYLAND_DISPLAY" ]]; then
    # Linux Wayland
    alias clip='wl-copy'
    alias paste='wl-paste'
elif [[ -n "$DISPLAY" ]]; then
    # Linux X11
    alias clip='xclip -selection clipboard'
    alias paste='xclip -selection clipboard -o'
fi
```

### 方案二：通用脚本函数

```bash
# clipboard.sh - 通用剪切板函数

cb_copy() {
    if command -v pbcopy &>/dev/null; then
        pbcopy
    elif command -v wl-copy &>/dev/null; then
        wl-copy
    elif command -v xclip &>/dev/null; then
        xclip -selection clipboard
    elif command -v xsel &>/dev/null; then
        xsel --clipboard --input
    elif command -v clip.exe &>/dev/null; then
        clip.exe
    else
        echo "No clipboard tool found" >&2
        return 1
    fi
}

cb_paste() {
    if command -v pbpaste &>/dev/null; then
        pbpaste
    elif command -v wl-paste &>/dev/null; then
        wl-paste
    elif command -v xclip &>/dev/null; then
        xclip -selection clipboard -o
    elif command -v xsel &>/dev/null; then
        xsel --clipboard --output
    elif command -v powershell.exe &>/dev/null; then
        powershell.exe -command Get-Clipboard
    else
        echo "No clipboard tool found" >&2
        return 1
    fi
}
```

## 六、Neovim / Vim 集成

```vim
" 系统剪切板集成
set clipboard=unnamedplus   " Linux
set clipboard=unnamed       " macOS

" 快捷键映射
vnoremap <C-c> "+y
nnoremap <C-v> "+p
```

```lua
-- Neovim Lua 配置
vim.opt.clipboard = "unnamedplus"
```

## 七、Tmux 集成

```bash
# ~/.tmux.conf

# 复制到系统剪切板
# macOS
bind-key -T copy-mode-vi y send-keys -X copy-pipe-and-cancel "pbcopy"

# Linux X11
bind-key -T copy-mode-vi y send-keys -X copy-pipe-and-cancel "xclip -sel clip"

# Linux Wayland
bind-key -T copy-mode-vi y send-keys -X copy-pipe-and-cancel "wl-copy"
```

## 九、实用技巧

```bash
# 1. 复制并同时显示内容
echo "hello" | tee /dev/tty | pbcopy

# 2. 格式化后复制（去除多余空格）
cat file.txt | tr -s ' ' | pbcopy

# 3. 复制命令历史
history | tail -20 | pbcopy

# 4. 复制 SSH 公钥
cat ~/.ssh/id_rsa.pub | pbcopy

# 5. 复制 base64 编码
cat image.png | base64 | pbcopy

# 6. 从剪切板执行代码
pbpaste | bash
```
