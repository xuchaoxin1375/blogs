## abstract

`cat` 是 Linux 和 Unix 系统中的一个常用命令，名称源自“con**caten**ate”(英[kən'kætɪneɪt]，美[kɑn'kætə,net])的缩写，意思是连接。

`cat` 主要用于

- 读取文件内容、
- 将多个文件连接起来输出到标准输出（通常是终端），
- 支持简单的重定向。

### cat 命令的主要功能

#### 显示文件内容

最基础用法:`cat` 可以直接输出文件内容到终端，便于快速查看小文件的内容：

```bash
cat filename.txt
```

#### 显示行号

使用 `-n` 选项可以为每一行显示行号，非常适合查看带行号的代码或长文本文件：

```bash
cat -n filename.txt
```





#### 合并多个文件

`cat` 可以将多个文件连接并输出，适合将多个文件合并为一个文件：

```bash
cat file1.txt file2.txt > merged.txt
```

上例将 `file1.txt` 和 `file2.txt` 的内容合并并输出到 `merged.txt` 文件中（会覆盖原文件内容）。若需要追加内容，可以使用 `>>` 追加到文件末尾：

```bash
cat file1.txt >> merged.txt
```

####  创建新文件👺

`cat` 还可以直接用来创建新文件，方法是将内容从标准输入写入到新文件(支持多行输入)：

```bash
cat > newfile.txt #使用Ctrl+D快捷键来结束输入,如果是追加,则用>>代替>
```

输入内容后，按 `Ctrl + D` 保存并退出。新文件 `newfile.txt` 会包含输入的内容。

示例

```bash
# cxxu @ bfxuxiaoxin in ~ [12:35:01]
$ cat > f1
1
22
333
# Ctrl+D结尾

# cxxu @ bfxuxiaoxin in ~ [14:40:48]
$ cat f1
1
22
333

# cxxu @ bfxuxiaoxin in ~ [14:42:19]
$ cat >> f1
44
5

# cxxu @ bfxuxiaoxin in ~ [14:42:32]
$ cat f1
1
22
333
44
5
```



#### **使用重定向运算符重定向标准输入**

当您将重定向与标准输入' **<** '（小于符号）一起使用时，它将文件名**test2**用作命令的输入，并且输出将显示在终端中。

`cat < file` 与 `cat file` 的比较

- `cat < file` 和 `cat file` 在功能上是等效的，都将文件内容输出到终端。
- 唯一的区别在于输入的方式：
  - `cat file` 直接将文件作为 `cat` 命令的参数。
  - `cat < file` 使用输入重定向，将文件内容提供给 `cat` 命令作为标准输入。



#### 压缩连续空行

使用 `-s` 选项可以压缩文件中的连续空行，使多行空行变成一行空行，便于阅读：

```bash
cat -s filename.txt
```



#### 行尾显示 `$` 符号

使用 `-E` 选项会在每行的结尾显示 `$`，用于标识换行符：

```bash
cat -E filename.txt
```

查看文件内容

```bash
# cxxu @ bfxuxiaoxin in ~ [14:42:35]
$ cat -E f1
1$
22$
333$
44$
5$
```



### 常用的 `cat` 选项总结

| 选项 | 功能              |
| ---- | ----------------- |
| `-n` | 显示行号          |
| `-s` | 压缩连续空行      |
| `-E` | 显示行尾 `$` 符号 |
| `-v` | 显示不可打印字符  |

### 示例：结合多个选项使用

可以同时使用多个选项。例如，以下命令会同时显示行号和行尾的 `$` 符号：

```bash
cat -nE filename.txt
```

### 总结
`cat` 命令适合快速查看文件、合并文件、创建文件，借助一些常用选项还能增强文件的可读性和排查格式问题的能力。
