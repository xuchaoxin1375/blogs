## 关键概念：文件的几种时间戳

| 时间类型         | 缩写      | 含义                           | 触发变更的操作                             |
| ---------------- | --------- | ------------------------------ | ------------------------------------------ |
| **访问时间**     | atime     | 文件最后被读取的时间           | `cat file`, `less file`                    |
| **修改时间**     | mtime     | **文件内容**最后被修改的时间   | `echo "x" > file`                          |
| **状态改变时间** | ctime     | inode **元数据**最后改变的时间 | `chmod`, `chown`, `mv`, **或内容修改**     |
| 创建时间         | birthtime | 文件被创建时的时间             | `touch`等命令创建文件,或者内容重定向到文件 |

**任何改变文件元数据或内容的操作都会更新 ctime**，但只有**内容修改**会更新 mtime( modify time)。

文件的变化可以是存放位置变化,权限以及所有者变化,还有最直观的的内容变化,内容是文件的最重要属性,因此内容变化有专门的时间标记mtime

> 也就是说,修改文件内容会引起mtime,ctime都变化,且如果mtime变换,一定意味着内容变化,也就意味着ctime会一同变化.但反过来不一定,ctime变化不一定是由文件内容变化引起的,从而mtime也不一定变化

## 使用stat精确查看时间戳信息👺

使用 `stat` 命令可清晰查看所有时间：

```bash
$ stat testfile
  File: testfile
  Size: 0          Blocks: 0          IO Block: 4096   regular empty file
Access: 2024-06-16 10:00:00.000000000 +0800  # atime
Modify: 2024-06-16 10:00:00.000000000 +0800  # mtime
Change: 2024-06-16 10:02:00.000000000 +0800  # ctime ← ls -lc 显示这个
 Birth: -
```

## ls -c的官方含义

`ls -c` 是一个在 `ls` 命令中**不太常用但有特定用途**的选项，它的行为**依赖于是否与其他选项（如 `-l` 或 `-t`）组合使用**。下面详细解释其含义并给出实用示例。

根据 POSIX 和 GNU `ls` 手册：

> ```bash
> -c    with -lt: sort by, and show, ctime (time of last change of file status information); 
>       with -l: show ctime and sort by name; 
>       otherwise: sort by ctime, newest first
> ```

`-c`(将文件的时间排列依据切换到状态信息修改时间),与`-l`配合与否是重点,`-l`让输出显示时间列，但同时会影响排序依据,再配合`-t`控制排序依据为时间

> 1. **当与 `-lt` 一起使用时**(`-ltc`)：显示的时间列是 **“状态改变时间”（ctime）**,但是排序是按 **ctime**。  
> 2. **当与 `-l`（长格式）一起使用时**(`-lc`)：显示的时间是 **“状态改变时间”（ctime）**,并按**文件名**排序（此时的时间不是默认的修改时间 mtime）。 
> 3. 其他情况下(不与`-l`或`-lt`一起使用),`-c`不会让输出显示**时间列**,但是会按照时间(ctime)排序(从新到旧)

**ctime ≠ 创建时间**！  

> - 在 **Linux/Unix** 中，**ctime = inode 最后改变时间**（如权限、属主、链接数变化，或文件内容修改）。  
> - 在 **macOS（BSD）** 中，`-c` 表示 **“创建时间”（birth time）**，行为不同！
> - linux中的文件的Birth time可以通过stat查看

## ✅ 实用示例（Linux 环境）

### 示例 1：查看文件的 ctime（需 `-l`）

首先创建1个全新的文件(testfile),此时其ctime,mtime相同

```bash
$ touch testfile
$ ls -lc testfile
-rw-r--r-- 1 user user 0 Jun 16 10:00 testfile
```

- 输出中的时间是 **ctime**（不是默认的 mtime）。
- 对比默认 `ls -l`：
  ```bash
  $ ls -l testfile      # 显示 mtime
  -rw-r--r-- 1 user user 0 Jun 16 10:00 testfile
  
  $ ls -lc testfile     # 显示 ctime（此时与 mtime 相同）
  -rw-r--r-- 1 user user 0 Jun 16 10:00 testfile
  ```

---

### 示例 2：修改权限后，ctime 更新，mtime 不变

```bash
$ sleep 2
$ chmod 755 testfile          # 只改权限，不改内容

$ ls -l testfile              # mtime 未变
-rwxr-xr-x 1 user user 0 Jun 16 10:00 testfile

$ ls -lc testfile             # ctime 已更新！
-rwxr-xr-x 1 user user 0 Jun 16 10:02 testfile
```

`-c` 让你看到**元数据变更时间**。

### 示例 3：按 ctime 排序（配合 `-t`）

```bash
$ touch file1 file2 file3
$ sleep 2
$ chmod +x file2              # 改变 file2 的 ctime
$ sleep 2
$ echo "data" > file3         # 改变 file3 的 mtime 和 ctime

# 按 ctime 降序列出（最新 ctime 在前）
$ ls -ct
file3  file2  file1

# 查看详细 ctime
$ ls -lct
total 4
-rw-r--r-- 1 user user 5 Jun 16 10:05 file3
-rwxr-xr-x 1 user user 0 Jun 16 10:03 file2
-rw-r--r-- 1 user user 0 Jun 16 10:00 file1
```

> 🔁 若用 `ls -lt`（默认按 mtime 排序），`file2` 会排在最后（因为 mtime 未变）。

---

### 示例 4：`-c` 单独使用？几乎没用！

```bash
$ ls -c
file1  file2  file3   # 仍按字母排序，不显示时间！
```

- 因为短格式（无 `-l`）不显示时间字段，`-c` 无法体现效果。
- **必须配合 `-l` 或 `-t` 才有意义**。

---

## 🍎 macOS / BSD 用户注意！

在 macOS 上：
- `ls -c` 表示 **按“创建时间”（birth time）排序**。
- `ls -lc` 显示的是 **创建时间**，而非 ctime。

```bash
# macOS 示例
$ ls -lc file
-rw-r--r--  1 user  staff  0 Jun 16 10:00 file  # 这是创建时间！
```

> 📌 **跨平台差异**：Linux 的 ctime ≠ macOS 的创建时间！脚本中慎用 `-c`。

---

## ✅ 总结：何时使用 `ls -c`？

| 场景                          | 命令                  | 作用                           |
| ----------------------------- | --------------------- | ------------------------------ |
| 查看文件元数据最后变更时间    | `ls -lc filename`     | 显示 ctime                     |
| 找出最近权限/属主被修改的文件 | `ls -lct`             | 按 ctime 降序列出              |
| 审计文件系统变更              | `ls -lct \| head -10` | 查看最近 10 个元数据变更的文件 |

> ❌ 不要用于：
> - 单独使用（`ls -c` 无意义）
> - 跨平台脚本（Linux vs macOS 行为不同）
> - 误以为是“创建时间”（Linux 中没有标准创建时间）

---



✅ **记住**：  

> **`ls -c` + `-l` → 显示 ctime**  
> **`ls -c` + `-t` → 按 ctime 排序**  
> **单独 `ls -c` → 无实际效果**
