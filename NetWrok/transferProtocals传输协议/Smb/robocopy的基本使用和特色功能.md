## abstract

在 Windows 的 `robocopy` 命令中，这些参数（`/Z`, `/B`, `/ZB`, `/J`）用于控制**复制文件时的模式和方式**，尤其适用于处理大文件、系统文件或需要高权限访问的情况。

---

## 特色参数

### ✅ `/Z`

> **在可重新启动模式下复制文件。**

- 文件是**以“可恢复”的方式**复制的。
- 如果复制过程中断（如网络中断），下次运行时可以从上次中断的位置继续，而不是从头开始。
- 适用于**网络路径**或可能中断的环境。
- 对本地文件也有效，但性能略低。

📌 示例：

```cmd
robocopy C:\Source D:\Dest /Z
```

---

### ✅ `/B`

> **在备份模式下复制文件。**

- 使用**Windows Backup API** 来复制文件。
- 可以绕过某些权限限制，读取被其他程序占用或受保护的系统文件（如注册表、页面文件等）。
- 需要管理员权限（UAC 提权）才能使用。
- 不支持断点续传。

📌 示例：

```cmd
robocopy C:\Source D:\Dest /B
```

---

### ✅ `/ZB`

> **优先使用可重新启动模式；如果拒绝访问，则自动切换到备份模式。**

- 智能组合了 `/Z` 和 `/B`。
- 是一个非常实用的选项，特别是在你不确定是否能访问某些文件的情况下。
- robocopy 会先尝试用 `/Z` 复制文件，如果遇到**访问被拒绝**的错误，就自动改用 `/B`。

📌 示例：

```cmd
robocopy C:\Source D:\Dest /ZB
```

---

### ✅ `/J`

> **复制时使用未缓冲的 I/O（推荐在复制大文件时使用）。**

- 直接将文件写入磁盘，跳过系统缓存。
- 减少内存使用，避免因大量缓存导致系统变慢。
- 特别适合复制**大型文件**（如视频、数据库、虚拟机镜像等）。
- 与 `/Z`、`/ZB` 等配合使用效果更佳。

📌 示例：

```cmd
robocopy C:\Source D:\Dest /J
```

---

🔁 参数对比总结

| 参数  | 描述                          | 是否支持断点续传 | 是否需要管理员权限    | 推荐场景                    |
| ----- | ----------------------------- | ---------------- | --------------------- | --------------------------- |
| `/Z`  | 可重启模式，复制中断后可继续  | ✅ 是             | ❌ 否                  | 网络传输、不稳定环境        |
| `/B`  | 备份模式，可复制锁定/系统文件 | ❌ 否             | ✅ 是                  | 复制系统文件、受保护文件    |
| `/ZB` | 先 `/Z`，失败则 `/B`          | ✅ 是（前半段）   | ✅ 是（若用到了 `/B`） | 最常用，通用性强            |
| `/J`  | 未缓冲 I/O，减少内存占用      | ❌ 否             | ❌ 否                  | 大文件复制，如视频、ISO、VM |

---

🛠 实用组合示例

✅ 复制所有文件，包括锁定文件（推荐）

```cmd
robocopy C:\Source D:\Dest /E /ZB /J
```

- `/E`：复制所有子目录（包括空目录）
- `/ZB`：优先可重启模式，不行就用备份模式
- `/J`：优化大文件复制

✅ 复制系统文件（如用户配置文件夹）

```cmd
robocopy C:\Users\John D:\Backup\John /E /ZB
```

---

⚠️ 注意事项

- 使用 `/B` 或 `/ZB` 时，如果你没有管理员权限，可能会提示“拒绝访问”。
- 使用 `runas` 提升权限后再运行命令：

```cmd
runas /user:Administrator "cmd /k robocopy C:\Source D:\Dest /ZB"
```
