# COLORFUL P15 23 无线网卡识别失败事件分析报告

- 报告日期:2026-08-30
- 设备:七彩虹 COLORFUL P15 23(i7-12700H)
- 无线网卡:Intel(R) Wi-Fi 6E AX211 160MHz(组合卡,WiFi + 蓝牙一体)
  - 设备实例:PCI\VEN_8086&DEV_51F0&SUBSYS_00948086&REV_01
  - 当前驱动:23.40.0.4(2024/3/10,INF: oem4.inf)
- BIOS:Insyde Corp. 1.07.10COLO2(2024/4/26)
- 系统:Windows 11 Pro(10.0.26200,2026/6/14 安装)

---

## 1. 事件概述

8/29 晚在**纯电池供电**状态下执行"更新并关机"后,8/30 晚插电开机发现:

- WiFi 网卡从设备管理器**完全消失**(正常视图下不显示);
- "查看 → 显示隐藏的设备"后可见灰色条目,提示 **"当前,这个硬件设备没有连接到计算机。(代码 45)"**;
- 多次重启无法恢复;
- 执行 **EC 放电重置**(关机 → 拔电源 → 长按电源键 30 秒 → 插电开机)后,WiFi 恢复正常。

## 3. 关键证据

1. **代码 45 = 硬件未连接,而非驱动问题**
   代码 45 表示设备"当前没有连接到计算机",即硬件没有出现在总线上。若为驱动损坏/不匹配,表现为代码 10/28/56 且设备仍可见。→ 指向硬件/供电层,而非软件层。

2. **驱动从未变更,排除"更新装了坏驱动"**
   当前驱动 23.40.0.4(2024/3/10)是 6 月装系统时的旧版本,更新流程没有更换 WiFi 驱动。

3. **整张组合卡同时掉电(含蓝牙)**
   故障期间,设备树中 `Intel Tile Device`(Intel 组合卡的桥接设备)、蓝牙射频(USB\VID_8087&PID_0033)、WLAN 射频设备全部处于"已断开连接"状态。修复后蓝牙与 WiFi 同步恢复 OK。→ WiFi(CNVi)与蓝牙(USB)分属不同总线却同时消失,证明是**整卡电源轨被关断**,而非单功能故障。

4. **重启无效、完全断电有效**
   EC(嵌入式控制器)在重启期间不会被复位,其状态跨重启保持;只有完全断电才会冷启动重新初始化。→ 故障状态保存在 EC 内,而非 Windows 内。

---

## 4. 根因分析

**直接原因**:AX211 整卡(含蓝牙)在 8/29 夜间"更新并关机"后,电源未被重新接通,EC 对无线模块的电源门控状态卡在"关闭"。

**触发链路**:

1. 用户在**拔掉电源适配器(纯电池)状态下**开机,并在该状态下点击"更新并关机";
2. "更新并关机"采用特殊关机序列(重启 → 安装更新 → 关机,日志中表现为 21:33 Reboot + 21:34 Shutdown 两次电源转换),该流程与 EC 的无线电源门控状态机配合要求完整的电源时序;
3. 在电池供电、无 AC 的电源条件下,EC 完成了本次电源转换但**未正确地将无线模块电源轨恢复到"下次开机可用"状态**,停留于关闭状态;
4. 8/30 插电开机时,EC 沿用其内部状态,未重新给 AX211 上电 → 卡不枚举 → Windows 只能显示残留注册表条目(灰色、代码 45);
5. EC 放电重置彻底清除 EC 状态,重新初始化后正确上电,卡恢复枚举。

**排除项**:

| 候选原因 | 结论 | 依据 |
|---|---|---|
| 鼠标/键盘热插拔 | 排除 | USB 子系统,与 CNVi 无线无关 |
| 驱动更新导致 | 排除 | 驱动版本未变化(2024/3 旧驱动) |
| 系统更新本身损坏 | 排除 | 补丁安装成功且系统正常 |
| 快速启动(Fast Startup)状态残留 | 辅助因素 | 已开启(HiberbootEnabled=1),但多次"快速启动"式重启均无效,证明根因不在 Windows 会话状态 |

---

## 5. 修复步骤有效性评估

| 操作 | 有效性 | 说明 |
|---|---|---|
| 重启计算机(4 次) | ❌ 无效 | EC 状态跨重启保持,重启不重置 EC |
| 再检查系统更新 | ⭕ 无关 | 检查失败(0x80240438),未安装任何补丁;8/29 的补丁本已装好 |
| **EC 放电重置**(关机→拔电→长按电源 30s→插电开机) | ✅ **有效(唯一)** | 完全断电使 EC 冷启动重新初始化,恢复无线模块电源门控,AX211 重新枚举 |

**结论**:本次故障唯一有效操作是 **EC 放电重置**。它解决的不是驱动或系统配置问题,而是 **EC 电源门控状态卡死** 问题。

---

## 6. 预防与后续建议

1. **执行"更新并关机"时务必插着电源适配器**,避免纯电池状态下进行更新+关机(本次的直接触发环境);
2. 若再次出现相同故障,重复 EC 放电重置即可恢复,无需拆机;
3. 若故障频繁复发(如每月多次),建议依次处理:
   - 更新 BIOS(当前 2024/4 的 1.07.10COLO2,关注七彩虹/同方官网新版本);
   - 更新 Intel WiFi 驱动(当前 23.40.0.4 偏旧,官网有新版);
   - 拆后盖重新插拔 M.2 无线网卡,排除接触不良;
4. 可选:关闭"快速启动"(控制面板 → 电源选项 → 取消"启用快速启动"),减少混合关机状态下的设备状态异常概率;
5. 本次为偶发事件(EC 状态类故障),若未来 1~2 个月不复发,无需进一步处理。
