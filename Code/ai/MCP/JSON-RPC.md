JSON-RPC 是一种**轻量级、无状态、传输无关**的远程过程调用（RPC）协议，使用 JSON 作为数据格式。它允许客户端调用远程服务器上的方法，并（可选地）获取结果。

目前广泛使用的是 **JSON-RPC 2.0** 版本，它与 1.0 不兼容，但可以通过 `jsonrpc` 字段轻松区分。

### 核心概念

#### 请求对象（Request）

**客户端**发送的 JSON 对象，主要包含以下字段：

*   `jsonrpc`：固定为 `"2.0"`。
*   `method`：要调用的方法名（字符串）。
*   `params`：参数，可以是**数组**（按位置）或**对象**（按名称），可选。
*   `id`：请求标识符。如果省略，则该请求被视为**通知**。

#### **响应对象（**Response**）**

**服务器**返回的 JSON 对象，包含以下字段：

*   `jsonrpc`：固定为 `"2.0"`。
*   `result`：成功时的结果。与 `error` 互斥。
*   `error`：错误时的对象，包含 `code`、`message` 和可选的 `data`。与 `result` 互斥。
*   `id`：必须与请求中的 `id` 相同。

**通知（Notification）**
一种特殊的请求，**没有 `id` 字段**。服务器**不得**对通知返回任何响应。这意味着客户端无法知道通知是否成功或失败。

**批量请求（Batch）**
可以发送一个包含多个请求对象的数组，服务器会返回一个包含对应响应的数组（通知不产生响应）。这有助于减少网络往返次数。

### 一组简单的例子

**请求（调用 `subtract` 方法）：**
```json
{"jsonrpc": "2.0", "method": "subtract", "params": [42, 23], "id": 1}
```

工具调用请求:

```json
{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"say_hello","arguments":{"name":"张三"}}}
```

**响应**:

成功响应:

```json
{"jsonrpc": "2.0", "result": 19, "id": 1}
```

错误响应（例如方法不存在**）：**

```json
{"jsonrpc": "2.0", "error": {"code": -32601, "message": "Method not found"}, "id": 1}
```

### 关键特点
*   **传输无关**：可以在 HTTP、WebSocket、原始 TCP 套接字甚至进程内使用。
*   **简单**：相比 XML-RPC 或 SOAP，JSON-RPC 的规范非常精简，易于实现。
*   **无状态**：每个请求都包含处理所需的所有信息，服务器不需要在请求之间保留会话状态。
