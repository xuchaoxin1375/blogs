## 2. 核心架构：它是怎么工作的？

为了让你听得懂，我们把 OpenClaw 比作一家**“智能外包公司”**。这家公司只有三个核心角色：

### 🏢 角色一：网关 (Gateway) —— “总经理兼总调度”

- **它是谁**：一个 7x24 小时不睡觉的常驻程序，跑在你的电脑或服务器上。
- **做什么**：
  - **统一入口**：无论是微信、Telegram、命令行还是网页，所有指令都先发给它。
  - **记忆大师**：它记得你和 AI 聊过的所有内容（会话状态），哪怕你换个设备接着聊，它也能接上茬。
  - **任务分发**：它不自己干活，而是把任务派给合适的“员工”（Pi Agent）。
- **新手理解**：没有网关，你的 AI 就是个失忆的临时工；有了网关，它就是一个拥有长期记忆、随时待命的正式员工。

### 🧠 角色二：Pi Agent —— “极简主义王牌员工”

- **它是谁**：OpenClaw 的核心执行引擎，由开发者 Mario Zechner 打造。名字里的 **Pi (π)** 象征着**极简**（代码极少）和**基础比率**（系统的核心）。
- **做什么**：
  - **只做四件事**：它没有花哨的功能，只保留了四个原子化工具：**读 (read)**、**写 (write)**、**改 (edit)**、**运行命令 (bash)**。
  - **超级专注**：因为它足够简单，所以极难出错。它负责理解总经理（网关）派发的任务，然后一步步去执行。
  - **模型无关**：你可以随意给它换“大脑”（比如今天用 Claude，明天用国产大模型），它都能完美适配。
- **新手理解**：它是一个不爱说话、只埋头苦干的实干家。你让它删文件，它绝不会跟你废话，直接执行。

### 📱 角色三：连接器 (Channels) —— “前台接待”

- **它是谁**：连接微信、Slack、手机 App 的接口。
- **做什么**：把不同平台的“方言”翻译成总经理（网关）能听懂的统一语言。

## 3. 实战演练：一条指令背后的旅程

让我们通过一个最简单的例子，看看 OpenClaw 是如何协同工作的。

**👤 你的指令**（在微信上发送）：

> “帮我把桌面上的 `Old_Project` 文件夹删了，如果是空的话。”

**🔄 内部流程**：

1. **接收 (前台)**：微信连接器收到消息，立刻转发给 **网关 (Gateway)**。

2. **记忆与路由 (总经理)**：

   - 网关查了一下记录：“哦，这是用户张三的请求，他之前让我关注过这个文件夹。”
   - 网关判断：“这需要操作文件系统，派给连接在张三电脑上的 **Pi Agent** 去处理。”

3. **思考与行动 (王牌员工)**：

   - **Pi Agent** 接到任务，开始思考：“用户说要‘如果是空的’才删，我得先检查。”
   - **第一步**：调用 `bash` 工具运行 `ls Old_Project`。
   - **反馈**：系统返回“文件夹存在，内部无文件”。
   - **第二步**：确认安全，调用 `bash` 运行 `rmdir Old_Project`。
   - **结果**：系统返回“删除成功”。

4. **汇报与存档 (闭环)**：

   - Pi Agent 向网关汇报：“老板，活干完了，成功了。”

   - 网关把这句话记入**长期记忆**（防止以后失忆），然后通过微信回复你：

     > “✅ 已确认 `Old_Project` 为空文件夹，并成功删除。”

**⏱️ 全程耗时**：约 2 秒。你只看到了一句回复，背后却是一次完美的自动化协作。

## 5. 如何开始？（简易起步）

如果你心动了，只需要三步即可体验：

1. **准备环境**：确保你的电脑安装了 `Node.js`（一个常见的运行环境）。
2. **一键安装**：在终端输入官方提供的安装命令（类似 `npx openclaw init`），系统会自动下载网关和 Pi Agent。
3. **连接你的聊天软件**：按照指引，将你的微信或 Telegram 账号连接到本地网关。

**🎉 完成！** 现在，试着对你的聊天软件说：“帮我创建一个名为 `Test` 的文件夹，并在里面放一个 `hello.txt` 文件。”
看着它自动在桌面上变出这个文件夹，你就正式进入了 **Agent 时代**。
