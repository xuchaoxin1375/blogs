# 元数据（Metadata）是什么？

## 简单定义

**元数据 = "关于数据的数据"**（Data about data）

它描述、解释或定位其他数据的信息。

------

## 生活中的例子

| 主数据   | 元数据                           |
| -------- | -------------------------------- |
| 一张照片 | 拍摄时间、地点、相机型号、分辨率 |
| 一本书   | 书名、作者、ISBN、出版日期、页数 |
| 一首歌   | 歌名、歌手、专辑、时长、比特率   |
| 一封邮件 | 发件人、收件人、发送时间、主题   |

------

## 技术领域的元数据

### 1. HTML 中的 meta 标签

HTML



```html
<head>
    <meta charset="UTF-8">
    <meta name="description" content="网页描述">
    <meta name="keywords" content="关键词1, 关键词2">
    <meta name="author" content="作者名">
</head>
```

### 2. 数据库中

- 表名、列名、数据类型、约束条件

### 3. 文件系统中

- 文件名、大小、创建时间、修改时间、权限

------

## 元数据的作用

| 作用     | 说明                      |
| -------- | ------------------------- |
| **描述** | 说明数据内容是什么        |
| **组织** | 帮助分类和检索            |
| **管理** | 追踪数据的来源和变化      |
| **发现** | 让搜索引擎理解内容（SEO） |

------

## 一句话总结

> 📌 元数据不是数据本身，而是**描述数据特征的标签信息**，帮助我们理解、查找和管理数据。
