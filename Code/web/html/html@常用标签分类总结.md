在 HTML（超文本标记语言）中，标签（Tag）用于定义网页的结构和内容。HTML 标签种类繁多，根据其功能和用途可以分为以下几类：

---

## 🧱 一、文档结构标签

这些标签用于定义整个 HTML 文档的基本结构。

| 标签      | 描述                                     |
| --------- | ---------------------------------------- |
| `<html>`  | 根元素，所有其他 HTML 元素都包含其中     |
| `<head>`  | 包含文档的元数据（如标题、样式、脚本等） |
| `<title>` | 定义文档的标题（显示在浏览器标签页上）   |
| `<body>`  | 包含页面可见的内容                       |

---

## 🔍 二、头部相关标签（位于 `<head>` 中）

| 标签       | 描述                                 |
| ---------- | ------------------------------------ |
| `<meta>`   | 定义元信息，如字符集、描述、关键词等 |
| `<link>`   | 引入外部资源（如 CSS 文件）          |
| `<style>`  | 定义内部 CSS 样式                    |
| `<script>` | 定义或引用 JavaScript 脚本           |
| `<base>`   | 指定页面上所有相对 URL 的基准 URL    |

---

## 📝 三、文本内容标签

### 1. 标题与段落

| 标签             | 描述                          |
| ---------------- | ----------------------------- |
| `<h1>` 到 `<h6>` | 标题标签，`<h1>` 是最高级标题 |
| `<p>`            | 段落                          |
| `<br>`           | 换行                          |
| `<hr>`           | 水平线，表示内容主题的分隔    |

### 2. 文本格式化

| 标签       | 描述               |
| ---------- | ------------------ |
| `<b>`      | 加粗（无语义强调） |
| `<strong>` | 加粗并具有语义强调 |
| `<i>`      | 斜体（无语义）     |
| `<em>`     | 斜体并具有语义强调 |
| `<u>`      | 下划线             |
| `<mark>`   | 高亮文本           |
| `<small>`  | 小号字体           |
| `<del>`    | 删除线             |
| `<ins>`    | 插入文本（下划线） |
| `<sub>`    | 下标               |
| `<sup>`    | 上标               |

---

## 📋 四、列表标签

### 1. 无序列表
- 使用 `<ul>` 和 `<li>`

```html
<ul>
  <li>项目1</li>
  <li>项目2</li>
</ul>
```

### 2. 有序列表
- 使用 `<ol>` 和 `<li>`

```html
<ol>
  <li>第一步</li>
  <li>第二步</li>
</ol>
```

### 3. 自定义列表（术语和描述）
- 使用 `<dl>`、`<dt>`、`<dd>`

```html
<dl>
  <dt>HTML</dt>
  <dd>超文本标记语言</dd>
</dl>
```

## 🖼️ 五、图像与多媒体标签

| 标签           | 描述                                     |
| -------------- | ---------------------------------------- |
| `<img>`        | 显示图片（自闭合标签）                   |
| `<figure>`     | 表示独立的内容（如图片、图表）           |
| `<figcaption>` | 为 `<figure>` 添加标题                   |
| `<audio>`      | 嵌入音频文件                             |
| `<video>`      | 嵌入视频文件                             |
| `<source>`     | 为 `<audio>` 或 `<video>` 提供多个媒体源 |

## 🔗 六、链接标签

| 标签    | 描述                            |
| ------- | ------------------------------- |
| `<a>`   | 超链接，`href` 属性指定目标地址 |
| `<nav>` | 导航区域（通常包含多个 `<a>`）  |

---

## 🧩 七、表格标签

| 标签        | 描述       |
| ----------- | ---------- |
| `<table>`   | 定义表格   |
| `<thead>`   | 表格的头部 |
| `<tbody>`   | 表格的主体 |
| `<tfoot>`   | 表格的底部 |
| `<tr>`      | 表格的一行 |
| `<th>`      | 表头单元格 |
| `<td>`      | 普通单元格 |
| `<caption>` | 表格的标题 |

---

以下标签是构建一个基本可用表格所**必须包含** 的：

| 标签      | 必要性 | 描述                                  |
| --------- | ------ | ------------------------------------- |
| `<table>` | ✅ 必须 | 定义整个表格的容器                    |
| `<tr>`    | ✅ 必须 | 表示表格中的一行（Table Row）         |
| `<td>`    | ✅ 必须 | 表示一个普通单元格（Table Data Cell） |

> 表格标签中有表示表行(区分行)的标签`<tr>`,但是没有表格列标签

```html
<table>
  <tr>
    <td>张三</td>
    <td>18</td>
  </tr>
  <tr>
    <td>李四</td>
    <td>17</td>
  </tr>
</table>
```



#### 完整表格

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>学生信息表</title>
  <style>
    table {
      width: 100%;
      /* border-collapse: collapse; */
      margin: 20px 0;
    }
    th, td {
      padding: 10px;
      border: 1px solid #ccc;
      text-align: center;
    }
  

  </style>
</head>
<body>

  <h2>学生信息表</h2>

  <table>
    <caption>2024年秋季学期学生基本信息</caption>

    <!-- 表头 -->
    <thead>
      <tr>
        <th>学号</th>
        <th>姓名</th>
        <th>性别</th>
        <th>年龄</th>
        <th>班级</th>
        <th>联系电话</th>
      </tr>
    </thead>

    <!-- 表体 -->
    <tbody>
      <tr>
        <td>20240101</td>
        <td>张三</td>
        <td>男</td>
        <td>18</td>
        <td>高三(1)班</td>
        <td>13800001111</td>
      </tr>
      <tr>
        <td>20240102</td>
        <td>李四</td>
        <td>女</td>
        <td>17</td>
        <td>高二(3)班</td>
        <td>13900002222</td>
      </tr>
      <tr>
        <td>20240103</td>
        <td>王五</td>
        <td>男</td>
        <td>19</td>
        <td>高三(2)班</td>
        <td>13700003333</td>
      </tr>
    </tbody>

    <!-- 表尾（可选） -->
    <tfoot>
      <tr>
        <td colspan="6">共计 3 条记录</td>
      </tr>
    </tfoot>
  </table>

</body>
</html>
```



## 📦 八、表单与输入控件

| 标签         | 描述                               |
| ------------ | ---------------------------------- |
| `<form>`     | 定义一个表单                       |
| `<input>`    | 输入控件（文本框、复选框、按钮等） |
| `<textarea>` | 多行文本输入框                     |
| `<select>`   | 下拉选择框                         |
| `<option>`   | `<select>` 中的一个选项            |
| `<label>`    | 为表单控件添加标签                 |
| `<button>`   | 按钮                               |
| `<fieldset>` | 将表单控件组合在一起               |
| `<legend>`   | 为 `<fieldset>` 添加标题           |

## 📎 九、布局与分区标签（HTML5 语义化标签）

| 标签        | 描述               |
| ----------- | ------------------ |
| `<header>`  | 页面或区块的头部   |
| `<footer>`  | 页面或区块的尾部   |
| `<main>`    | 页面主要内容区域   |
| `<section>` | 定义文档中的节     |
| `<article>` | 独立的文章内容     |
| `<aside>`   | 侧边栏内容         |
| `<nav>`     | 导航链接部分       |
| `<div>`     | 通用容器（无语义） |
| `<span>`    | 内联容器（无语义） |

## ⚙️ 十、交互与嵌入内容

| 标签        | 描述                            |
| ----------- | ------------------------------- |
| `<details>` | 用户可展开/收起的详细信息       |

## ✅ 总结分类

| 类别           | 标签示例                                                   |
| -------------- | ---------------------------------------------------------- |
| 文档结构       | `<html>`, `<head>`, `<body>`                               |
| 文本内容       | `<p>`, `<h1>`~`<h6>`, `<br>`, `<hr>`                       |
| 列表           | `<ul>`, `<ol>`, `<li>`, `<dl>`                             |
| 图像与多媒体   | `<img>`, `<audio>`, `<video>`                              |
| 链接           | `<a>`                                                      |
| 表格           | `<table>`, `<tr>`, `<td>`, `<th>`                          |
| 表单           | `<form>`, `<input>`, `<select>`, `<textarea>`              |
| 布局与语义标签 | `<header>`, `<footer>`, `<main>`, `<section>`, `<article>` |
| 嵌入内容       | `<iframe>`, `<canvas>`, `<svg>`                            |
| 交互与细节     | `<details>`, `<dialog>`, `<summary>`                       |
