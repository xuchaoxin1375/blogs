## 🖼️ 一、什么是图像？

在数字世界中，**图像（Image）**是由许多小点组成的，这些小点叫做**像素（Pixel）**。每一个像素都具有一定的颜色信息，将这些像素排列组合在一起，就形成了我们看到的图片。

---

## 🔷 二、图像的基本参数

### 1. **分辨率（Resolution）**
- 定义：图像的尺寸大小，通常用“宽度 × 高度”表示。
- 单位：像素（px）
- 示例：1920×1080 表示图像宽为1920个像素，高为1080个像素。
- 意义：分辨率越高，图像越清晰，但文件也越大。

### 2. **像素（Pixel）**
- 定义：图像中最小的单位，每个像素包含颜色信息。
- 彩色图像中的一个像素通常由红（R）、绿（G）、蓝（B）三个通道组成（RGB格式）。
- 灰度图中每个像素只有一个亮度值（0~255）。

### 3. **位深度（Bit Depth / Color Depth）**
- 定义：每个像素所占用的比特数，决定了颜色的数量。
- 常见类型：
  - 1位：黑白图像（0=黑，1=白）
  - 8位：256种灰度或颜色
  - 24位：真彩色（RGB各8位，共2^24 ≈ 1677万色）

### 4. **通道数（Channels）**
- 图像中颜色分量的数量。
- 常见类型：
  - 灰度图：1个通道
  - RGB彩色图：3个通道（红、绿、蓝）
  - RGBA图：4个通道（加透明度Alpha）

### 5. **图像格式（Image Format）**
常见的图像存储格式包括：
- JPEG（压缩率高，适合照片）
- PNG（支持透明，无损压缩）
- BMP（未压缩，体积大）
- GIF（支持动画）
- TIFF（高质量图像，常用于印刷）

## 📊 三、图像数据的结构（以RGB图像为例）

假设一张图像是 `Width × Height × Channels` 的三维矩阵：

例如：一张分辨率为 `800×600` 的RGB图像，其数据结构为：

```
shape = (600, 800, 3)
```

- 第一个维度是高度（行数）
- 第二个维度是宽度（列数）
- 第三个维度是颜色通道（R, G, B）

### 图片分辨率|像素点规模🎈

上述例子中的图片信息(图片像素为743x1066),第一个数值表示图片水平方向上的像素点数;而第二个数值表示垂直方向上的像素点数



又比如一张**800×600** 的图片,800×600这是一个常见的 **图像分辨率（resolution）** 表达方式，表示一张图片或屏幕的宽度和高度，单位是像素（px）。

它在网页设计、图片处理、显示设备设置中都非常常见。

| 表达式      | 含义                             |
| ----------- | -------------------------------- |
| `800`×`600` | 图片宽为 800 像素，高为 600 像素 |

你可以把它想象成一个矩形框：

- 横向有 800 个像素点（从左到右）
- 纵向有 600 个像素点（从上到下）

总像素数 = `800 × 600 = 480,000` 个像素点

## 🧮 四、图像文件大小估算

图像文件大小可以通过以下公式大致估算：

```
文件大小（字节） = 宽度 × 高度 × 通道数 × (位深度 ÷ 8)
```

例如：
- 分辨率：1024×768
- 格式：RGB（3通道）
- 位深度：24位（即每个像素3字节）

计算：
```
1024 × 768 × 3 = 2,359,296 字节 ≈ 2.25 MB
```

## ✅ 总结：图像常见参数一览表

| 参数     | 含义说明           | 示例值              |
| -------- | ------------------ | ------------------- |
| 分辨率   | 图像的宽和高       | 1920×1080           |
| 像素     | 图像的最小单位     | RGB值如(255,0,0)    |
| 位深度   | 每个像素的颜色深度 | 8位、24位           |
| 通道数   | 颜色分量数量       | 1（灰度）、3（RGB） |
| 图像格式 | 存储方式           | JPG、PNG、BMP等     |
| 文件大小 | 存储空间大小       | 2MB、10KB等         |
