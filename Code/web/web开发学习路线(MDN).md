## 系统地学习web

[核心学习模块 - 学习 Web 开发 | MDN --- Core learning modules - Learn web development | MDN](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core)

[扩展模块 - 学习 Web 开发 | MDN --- Extension modules - Learn web development | MDN](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions)

**核心模块**涵盖了我们认为每位 Web 开发人员都应该掌握的基础知识。这包括设计和构建符合现代最佳实践的基本、易于访问的 Web 应用程序所需的所有信息，以及使用合适的工具管理和部署代码所需的所有信息。

**扩展模块**为网络开发人员提供了有用的额外技能，帮助他们扩展知识并发展专业领域。
