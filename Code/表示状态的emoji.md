在日常沟通、文档、日志或代码注释中，使用 emoji 可以直观地表示**状态**，提升可读性和视觉反馈。以下是表示常见状态的常用 emoji 及其适用场景：

---

### ✅ 1. 成功 / 完成 / 正确
| Emoji | 含义             | 示例             |
| ----- | ---------------- | ---------------- |
| ✅     | 成功、通过、确认 | `✅ 配置更新成功` |
| ✔️     | 正确、已勾选     | `✔️ 任务已完成`   |
| 🎉     | 庆祝、完成里程碑 | `🎉 部署成功！`   |
| 💯     | 百分百、完美     | `💯 测试全部通过` |

---

### ❌ 2. 失败 / 错误 / 拒绝
| Emoji | 含义                   | 示例           |
| ----- | ---------------------- | -------------- |
| ❌     | 失败、错误、关闭       | `❌ 构建失败`   |
| 🛑     | 停止、禁止、中断       | `🛑 服务已停止` |
| 🔴     | 红色状态（常用于监控） | `🔴 服务宕机`   |
| 💥     | 崩溃、爆炸             | `💥 程序崩溃`   |

---

### ⚠️ 3. 警告 / 注意 / 待处理
| Emoji | 含义           | 示例               |
| ----- | -------------- | ------------------ |
| ⚠️     | 警告、注意     | `⚠️ 配置文件缺失`   |
| 📢     | 提醒、广播     | `📢 请注意系统维护` |
| 🔔     | 提醒、通知     | `🔔 有新消息`       |
| 🧨     | 危险、潜在问题 | `🧨 内存使用过高`   |

---

### 🔁 4. 进行中 / 加载 / 处理中

| Emoji | 含义           | 示例             |
| ----- | -------------- | ---------------- |
| 🔁     | 正在重试、循环 | `🔁 同步中...`    |
| 🔄     | 刷新、加载     | `🔄 数据加载中`   |
| ⏳     | 等待、计时     | `⏳ 正在处理请求` |
| 🚧     | 施工中、开发中 | `🚧 功能开发中`   |

---

### 📥 5. 待处理 / 未开始 / 挂起
| Emoji | 含义           | 示例                 |
| ----- | -------------- | -------------------- |
| 📥     | 待处理、已接收 | `📥 等待审核`         |
| ⏸️     | 暂停           | `⏸️ 任务已暂停`       |
| 🛌     | 休眠、未激活   | `🛌 服务处于休眠状态` |
| 📝     | 待办、记录中   | `📝 需求整理中`       |

---

### 🚀 6. 启动 / 部署 / 运行
| Emoji | 含义       | 示例             |
| ----- | ---------- | ---------------- |
| 🚀     | 发布、启动 | `🚀 项目已上线`   |
| ▶️     | 开始、运行 | `▶️ 开始执行脚本` |
| 🔌     | 连接、启用 | `🔌 数据库已连接` |
| 🌐     | 网络、在线 | `🌐 服务运行中`   |

---

### 📚 7. 信息 / 说明 / 文档
| Emoji | 含义       | 示例               |
| ----- | ---------- | ------------------ |
| ℹ️     | 信息说明   | `ℹ️ 详情见文档`     |
| 📄     | 文档、文件 | `📄 配置说明`       |
| 📘     | 手册、指南 | `📘 使用手册已更新` |
| 🔍     | 检查、查找 | `🔍 正在扫描漏洞`   |

---

### 📊 8. 监控 / 统计 / 状态面板
| Emoji | 含义       | 示例               |
| ----- | ---------- | ------------------ |
| 📊     | 数据仪表盘 | `📊 性能监控`       |
| 📈     | 上升趋势   | `📈 流量增长`       |
| 📉     | 下降趋势   | `📉 用户活跃度下降` |
| 🧮     | 计算、处理 | `🧮 正在计算结果`   |

---

### ✅ 推荐组合用法（日志/CI/脚本输出）

```bash
echo "✅ 成功: 数据库连接正常"
echo "❌ 失败: 配置文件解析错误"
echo "⚠️ 警告: 磁盘空间低于 10%"
echo "🔄 进行中: 正在下载依赖..."
echo "🚀 部署: 版本 v1.2.0 已发布"
```

---

### 💡 小贴士

- 在 **CI/CD 日志**、**运维脚本**、**Markdown 文档** 中使用 emoji 可显著提升可读性。
- 避免在正式生产日志中过度使用，以免影响解析。
- 确保终端/编辑器支持 emoji 显示（现代系统基本都支持）。
