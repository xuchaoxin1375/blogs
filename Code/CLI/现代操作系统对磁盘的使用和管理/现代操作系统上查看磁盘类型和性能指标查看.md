下面是一份**判断服务器磁盘类型和性能参数的实用指南**，适用于 Linux 服务器为主，也包含少量 Windows 方法。

# 一、判断磁盘类型

## 1. 查看磁盘基本信息

```bash
lsblk -o NAME,TYPE,SIZE,MODEL,SERIAL,ROTA,TRAN,HCTL
```

重点看：

| 字段    | 含义                                       |
| ------- | ------------------------------------------ |
| `NAME`  | 磁盘名称，如 `sda`、`nvme0n1`              |
| `SIZE`  | 容量                                       |
| `MODEL` | 型号                                       |
| `ROTA`  | 是否旋转盘，`1` 通常是 HDD，`0` 通常是 SSD |
| `TRAN`  | 传输协议，如 `sata`、`sas`、`nvme`         |
| `HCTL`  | SCSI 设备路径，对 SAS/SATA 盘有用          |

示例：

```bash
lsblk -d -o NAME,SIZE,MODEL,ROTA,TRAN
```

可能输出：

```text
NAME      SIZE MODEL              ROTA TRAN
sda       1.8T ST2000NM0033          1 sas
sdb       960G INTEL SSDSC2KB960G8   0 sata
nvme0n1   3.5T SAMSUNG MZQLB3T8      0 nvme
```

判断：

```text
ROTA=1  → 机械硬盘 HDD
ROTA=0  → SSD 或 NVMe
TRAN=sata → SATA 盘
TRAN=sas  → SAS 盘
TRAN=nvme → NVMe SSD
```

# 二、判断是否为 HDD、SATA SSD、SAS SSD、NVMe

## 1. HDD 机械盘

特征：

```text
ROTA=1
TRAN=sata 或 sas
```

命令：

```bash
cat /sys/block/sdX/queue/rotational
```

例如：

```bash
cat /sys/block/sda/queue/rotational
```

结果：

```text
1 → HDD
0 → SSD
```

## 2. SATA SSD

特征：

```text
ROTA=0
TRAN=sata
设备名通常是 /dev/sdX
```

命令：

```bash
lsblk -d -o NAME,ROTA,TRAN,MODEL
```

## 3. SAS SSD

特征：

```text
ROTA=0
TRAN=sas
设备名通常是 /dev/sdX
```

如果服务器使用 RAID 卡，系统可能看不到真实单盘信息，需要用 RAID 厂商工具。

常见工具：

```bash
storcli
megacli
perccli
ssacli
```

例如 MegaRAID / Broadcom RAID 卡：

```bash
storcli /c0 /eall /sall show
```

## 4. NVMe SSD

特征：

```text
设备名是 /dev/nvme0n1、/dev/nvme1n1
TRAN=nvme
```

命令：

```bash
nvme list
```

安装工具：

```bash
apt install nvme-cli
# 或
yum install nvme-cli
```

查看详细信息：

```bash
nvme id-ctrl /dev/nvme0
nvme smart-log /dev/nvme0
```

# 三、查看磁盘健康状态

## 1. SATA / SAS 磁盘

安装 smartmontools：

```bash
apt install smartmontools
# 或
yum install smartmontools
```

查看健康状态：

```bash
smartctl -H /dev/sda
```

查看完整 SMART 信息：

```bash
smartctl -a /dev/sda
```

重点关注：

| 指标                      | 含义                      |
| ------------------------- | ------------------------- |
| `Reallocated_Sector_Ct`   | 重映射扇区，越多越危险    |
| `Current_Pending_Sector`  | 待处理坏扇区，非 0 需警惕 |
| `Offline_Uncorrectable`   | 无法修复的错误            |
| `Power_On_Hours`          | 通电时间                  |
| `Temperature_Celsius`     | 温度                      |
| `Wear_Leveling_Count`     | SSD 磨损情况              |
| `Media_Wearout_Indicator` | SSD 寿命指标              |

## 2. NVMe 磁盘

```bash
nvme smart-log /dev/nvme0
```

重点看：

| 指标                 | 含义             |
| -------------------- | ---------------- |
| `percentage_used`    | 已使用寿命百分比 |
| `data_units_read`    | 读取量           |
| `data_units_written` | 写入量           |
| `media_errors`       | 介质错误         |
| `critical_warning`   | 关键告警         |
| `temperature`        | 温度             |

# 四、查看磁盘性能参数

磁盘性能主要看这些指标：

| 指标             | 含义                                  |
| ---------------- | ------------------------------------- |
| 顺序读带宽       | 大文件连续读取速度，单位 MB/s 或 GB/s |
| 顺序写带宽       | 大文件连续写入速度                    |
| 随机读 IOPS      | 小块随机读取能力                      |
| 随机写 IOPS      | 小块随机写入能力                      |
| 延迟 latency     | 单次 IO 响应时间                      |
| 队列深度 QD      | 并发 IO 队列数量                      |
| 吞吐量 bandwidth | 总传输速率                            |
| 使用率 util      | 磁盘忙碌程度                          |

# 五、使用 fio 测试磁盘性能

`fio` 是最常用的磁盘性能测试工具。

安装：

```bash
apt install fio
# 或
yum install fio
```

## 1. 顺序读测试

```bash
fio --name=seqread \
--filename=/data/testfile \
--size=10G \
--bs=1M \
--rw=read \
--iodepth=32 \
--direct=1 \
--runtime=60 \
--time_based \
--numjobs=1 \
--group_reporting
```

## 2. 顺序写测试

```bash
fio --name=seqwrite \
--filename=/data/testfile \
--size=10G \
--bs=1M \
--rw=write \
--iodepth=32 \
--direct=1 \
--runtime=60 \
--time_based \
--numjobs=1 \
--group_reporting
```

注意：写测试会覆盖测试文件，不要对重要数据路径随意执行。

## 3. 随机读 IOPS 测试

```bash
fio --name=randread \
--filename=/data/testfile \
--size=10G \
--bs=4k \
--rw=randread \
--iodepth=64 \
--direct=1 \
--runtime=60 \
--time_based \
--numjobs=4 \
--group_reporting
```

## 4. 随机写 IOPS 测试

```bash
fio --name=randwrite \
--filename=/data/testfile \
--size=10G \
--bs=4k \
--rw=randwrite \
--iodepth=64 \
--direct=1 \
--runtime=60 \
--time_based \
--numjobs=4 \
--group_reporting
```

## 5. 混合读写测试

例如 70% 读、30% 写：

```bash
fio --name=randrw \
--filename=/data/testfile \
--size=10G \
--bs=4k \
--rw=randrw \
--rwmixread=70 \
--iodepth=64 \
--direct=1 \
--runtime=60 \
--time_based \
--numjobs=4 \
--group_reporting
```

# 六、fio 结果怎么看

典型输出中重点看：

```text
read: IOPS=120k, BW=468MiB/s, lat=...
write: IOPS=80k, BW=312MiB/s, lat=...
```

核心字段：

| 字段      | 含义               |
| --------- | ------------------ |
| `IOPS`    | 每秒 IO 次数       |
| `BW`      | 带宽               |
| `lat`     | 延迟               |
| `clat`    | 完成延迟，重点关注 |
| `slat`    | 提交延迟           |
| `99.00th` | 99 分位延迟        |
| `99.99th` | 99.99 分位延迟     |

判断性能不能只看平均延迟，更应该看：

```text
99% 延迟
99.9% 延迟
99.99% 延迟
```

因为数据库、虚拟化、日志系统通常对尾延迟非常敏感。

# 七、实时观察磁盘性能

## 1. 使用 iostat

安装：

```bash
apt install sysstat
# 或
yum install sysstat
```

查看磁盘实时情况：

```bash
iostat -x 1
```

重点字段：

| 字段      | 含义             |
| --------- | ---------------- |
| `r/s`     | 每秒读请求数     |
| `w/s`     | 每秒写请求数     |
| `rkB/s`   | 每秒读取 KB      |
| `wkB/s`   | 每秒写入 KB      |
| `await`   | 平均 IO 等待时间 |
| `r_await` | 读等待时间       |
| `w_await` | 写等待时间       |
| `%util`   | 设备繁忙程度     |

一般判断：

```text
%util 长期接近 100% → 磁盘可能成为瓶颈
await 明显升高       → IO 延迟变大
IOPS 很高但带宽低    → 小块随机 IO 较多
带宽高但 IOPS 不高   → 大块顺序 IO 较多
```

## 2. 使用 pidstat 查看哪个进程在打磁盘

```bash
pidstat -d 1
```

## 3. 使用 iotop 查看实时 IO 进程

```bash
iotop -oPa
```

# 八、常见磁盘性能参考值

不同型号差异很大，下面是粗略参考：

| 类型            | 顺序读写         | 随机 4K IOPS | 延迟           |
| --------------- | ---------------- | ------------ | -------------- |
| SATA HDD        | 100–250 MB/s     | 100–300      | 毫秒级         |
| 10K/15K SAS HDD | 150–300 MB/s     | 200–500      | 毫秒级         |
| SATA SSD        | 400–550 MB/s     | 50k–100k     | 百微秒级       |
| SAS SSD         | 500 MB/s–2 GB/s+ | 100k–400k+   | 百微秒级       |
| NVMe SSD        | 2–7 GB/s+        | 300k–1M+     | 微秒到百微秒级 |

注意：实际性能会受这些因素影响：

```text
RAID 卡
缓存策略
文件系统
内核参数
CPU
NUMA
PCIe 代际
队列深度
业务 IO 模型
是否开启 direct I/O
是否是云盘
是否有写入放大或 GC
```

# 九、判断是否经过 RAID 卡

查看块设备：

```bash
lsblk
```

查看控制器：

```bash
lspci | grep -i raid
lspci | grep -i sas
lspci | grep -i storage
```

如果看到类似：

```text
MegaRAID
PERC
Smart Array
LSI
Broadcom
Adaptec
```

说明可能有 RAID 卡。

查看 RAID 卡信息：

```bash
storcli show
storcli /c0 show
storcli /c0 /vall show
storcli /c0 /eall /sall show
```

RAID 场景中，`/dev/sda` 可能不是一块真实物理盘，而是一个虚拟盘 VD。

# 十、快速判断流程

可以按这个顺序排查：

```bash
lsblk -d -o NAME,SIZE,MODEL,ROTA,TRAN
```

先判断设备类型：

```text
/dev/sdX + ROTA=1 → HDD
/dev/sdX + ROTA=0 + TRAN=sata → SATA SSD
/dev/sdX + ROTA=0 + TRAN=sas  → SAS SSD
/dev/nvmeXnY → NVMe SSD
```

再看健康状态：

```bash
smartctl -a /dev/sdX
nvme smart-log /dev/nvme0
```

再看实时负载：

```bash
iostat -x 1
iotop -oPa
pidstat -d 1
```

最后做基准测试：

```bash
fio ...
```

# 十一、生产环境测试注意事项

在生产服务器上测试磁盘性能时要谨慎：

1. 不要直接对裸盘执行破坏性写测试，例如：

```bash
fio --filename=/dev/sda --rw=write
```

这可能破坏数据。

1. 建议使用单独测试文件：

```bash
--filename=/data/testfile
```

1. 测试文件大小要大于内存缓存影响，例如：

```bash
--size=10G
```

如果服务器内存很大，可以用更大的测试文件。

1. 建议加：

```bash
--direct=1
```

避免被系统页缓存影响。

1. 测试前确认磁盘空间：

```bash
df -h
```

1. 测试完成后删除测试文件：

```bash
rm -f /data/testfile
```

# 十二、一键信息收集命令

可以先跑这一组：

```bash
echo "=== lsblk ==="
lsblk -d -o NAME,SIZE,MODEL,SERIAL,ROTA,TRAN

echo "=== block rotational ==="
for d in /sys/block/*; do
  dev=$(basename "$d")
  [ -f "$d/queue/rotational" ] && echo "$dev rotational=$(cat $d/queue/rotational)"
done

echo "=== lspci storage ==="
lspci | egrep -i "raid|sas|sata|nvme|storage"

echo "=== iostat ==="
iostat -x 1 3
```

如果是 NVMe，再执行：

```bash
nvme list
nvme smart-log /dev/nvme0
```

如果是 RAID 卡，再执行：

```bash
storcli show
storcli /c0 /vall show
storcli /c0 /eall /sall show
```

# 十三、结论模板

排查完成后，可以这样写结论：

```text
服务器磁盘类型：
- 系统盘：/dev/sda，SATA SSD，容量 960GB，ROTA=0
- 数据盘：/dev/nvme0n1，NVMe SSD，容量 3.84TB

健康状态：
- SMART overall-health：PASSED
- NVMe media_errors：0
- percentage_used：12%

性能测试：
- 顺序读：3.2 GB/s
- 顺序写：2.8 GB/s
- 4K 随机读：520k IOPS
- 4K 随机写：310k IOPS
- 99% 延迟：0.8 ms

判断：
- 磁盘为 NVMe SSD，性能正常
- 当前没有明显硬件故障迹象
- 若业务期间 await 或 %util 长期偏高，需进一步分析 IO 模型和应用负载
```

验盘时最实用的组合是：

```bash
lsblk + smartctl/nvme + iostat + fio
```

其中：

```text
lsblk 判断类型
smartctl/nvme 判断健康
iostat 判断当前压力
fio 判断理论性能
```

下面这段可以直接作为你原指南的补充章节。

## 1. 查看磁盘列表

```bash
diskutil list
```

示例：

```text
/dev/disk0 (internal, physical):
   #: TYPE NAME SIZE IDENTIFIER
   0: GUID_partition_scheme *1.0 TB disk0
   1: Apple_APFS_ISC Container disk1 524.3 MB disk0s1
```

重点看：

```text
internal / external
physical / synthesized
disk0 / disk1 / disk2
```

macOS 上经常会看到 APFS 容器盘，例如 `disk1` 是逻辑容器，真正物理盘通常是 `disk0`。

------

## 2. 查看单块磁盘详细信息

```bash
diskutil info disk0
```

重点字段：

| 字段                  | 含义                                   |
| --------------------- | -------------------------------------- |
| `Device / Media Name` | 磁盘型号                               |
| `Protocol`            | PCI-Express / SATA / USB / Thunderbolt |
| `Solid State`         | 是否 SSD                               |
| `Internal`            | 是否内置盘                             |
| `Removable Media`     | 是否可移动设备                         |
| `SMART Status`        | SMART 状态                             |

示例判断：

```text
Solid State: Yes
Protocol: PCI-Express
```

通常表示：

```text
PCI-Express + Solid State = NVMe / PCIe SSD
SATA + Solid State = SATA SSD
SATA + Solid State: No = SATA HDD
USB + Solid State = 外置 SSD，性能还受 USB 协议限制
```

## 4. 判断是否 SSD / HDD

### 方法一：diskutil

```bash
diskutil info disk0 | egrep -i "Solid State|Protocol|SMART|Media Name"
```

示例：

```text
Device / Media Name: APPLE SSD AP1024Q
Protocol: PCI-Express
Solid State: Yes
SMART Status: Verified
```

判断：

```text
Solid State: Yes → SSD
Solid State: No  → HDD 或其他非固态介质
Protocol: PCI-Express → 通常为 NVMe / PCIe SSD
Protocol: SATA → SATA SSD 或 SATA HDD
```

------

### 方法二：system_profiler

```bash
system_profiler SPStorageDataType | egrep -i "Medium Type|Protocol|Solid State|TRIM|SMART"
```

------

### 方法三：ioreg

```bash
ioreg -r -c IOBlockStorageDevice | egrep -i "Model|Solid|Rotational|Protocol"
```

这个方法偏底层，适合脚本化巡检，但输出可读性不如 `diskutil`。

## 5. 查看 SMART 健康状态

macOS 默认没有 `smartctl`，可以通过 Homebrew 安装：

```bash
brew install smartmontools
```

查看磁盘健康：

```bash
sudo smartctl -H /dev/disk0
```

查看完整 SMART 信息：

```bash
sudo smartctl -a /dev/disk0
```

重点关注：

| 指标                              | 含义                    |
| --------------------------------- | ----------------------- |
| `SMART overall-health`            | 总体健康状态            |
| `Power_On_Hours`                  | 通电时间                |
| `Temperature_Celsius`             | 温度                    |
| `Reallocated_Sector_Ct`           | HDD 坏块重映射          |
| `Current_Pending_Sector`          | 待处理坏扇区            |
| `Percentage Used`                 | NVMe / SSD 寿命使用比例 |
| `Data Units Written`              | 总写入量                |
| `Media and Data Integrity Errors` | 介质错误                |

注意：
Apple 内置 SSD 有些 SMART 字段可能不会完整暴露，这是 macOS 上的常见情况。

# 十五、Windows 上查看磁盘类型和性能

Windows 推荐使用：

## 1. 查看物理磁盘类型

PowerShell 管理员窗口执行：

```powershell
Get-PhysicalDisk
```

更清晰的输出：

```powershell
Get-PhysicalDisk | Select-Object FriendlyName,SerialNumber,MediaType,BusType,HealthStatus,OperationalStatus,Size
```

重点字段：

| 字段                | 含义                           |
| ------------------- | ------------------------------ |
| `FriendlyName`      | 磁盘型号                       |
| `SerialNumber`      | 序列号                         |
| `MediaType`         | HDD / SSD / Unspecified        |
| `BusType`           | SATA / SAS / NVMe / USB / RAID |
| `HealthStatus`      | 健康状态                       |
| `OperationalStatus` | 运行状态                       |
| `Size`              | 容量                           |

判断：

```text
MediaType = HDD  → 机械硬盘
MediaType = SSD  → 固态硬盘
BusType = NVMe   → NVMe SSD
BusType = SATA   → SATA SSD 或 SATA HDD
BusType = SAS    → SAS HDD 或 SAS SSD
BusType = RAID   → 可能经过 RAID 卡，需用 RAID 工具看物理盘
```

## 3. 查看磁盘、分区、盘符对应关系

```powershell
Get-Disk | Get-Partition | Get-Volume
```

或者查看某块磁盘：

```powershell
Get-Partition -DiskNumber 0 | Get-Volume
```

这一步很重要，因为 Windows 里业务通常看到的是 `C:`、`D:`，而底层磁盘是 `Disk 0`、`Disk 1`。

## 5. 查看健康状态

### PowerShell 原生命令

```powershell
Get-PhysicalDisk | Get-StorageReliabilityCounter
```

重点字段：

| 字段               | 含义         |
| ------------------ | ------------ |
| `Temperature`      | 温度         |
| `Wear`             | SSD 磨损程度 |
| `ReadErrorsTotal`  | 读错误       |
| `WriteErrorsTotal` | 写错误       |
| `PowerOnHours`     | 通电时间     |

如果没有返回完整字段，通常是因为驱动、RAID 卡或磁盘本身没有暴露这些信息。

------

### CrystalDiskInfo

Windows 上最常用的图形化健康检查工具之一。

可查看：

```text
Health Status
Temperature
Power On Hours
Power On Count
Total Host Reads
Total Host Writes
Reallocated Sectors Count
Current Pending Sector Count
NVMe Percentage Used
```

适合快速判断：

```text
SSD 寿命是否接近耗尽
HDD 是否出现坏道
NVMe 是否有介质错误
温度是否过高
```

------

### smartctl for Windows

也可以安装 Windows 版 smartmontools。

扫描设备：

```cmd
smartctl --scan
```

查看 SATA / SAS / NVMe 磁盘：

```cmd
smartctl -a /dev/sda
smartctl -a /dev/nvme0
```

如果经过 RAID 卡，可能需要指定设备类型，例如：

```cmd
smartctl -a -d sat /dev/sda
```

RAID 环境下不一定能直接看到物理盘 SMART，需要使用 RAID 厂商工具。

## 6. Windows 实时 IO 监控

### 任务管理器

路径：

```text
Task Manager → Performance → Disk
```

可查看：

| 指标                    | 含义                             |
| ----------------------- | -------------------------------- |
| `Active time`           | 磁盘忙碌程度，类似 Linux `%util` |
| `Average response time` | 平均响应时间                     |
| `Read speed`            | 读取带宽                         |
| `Write speed`           | 写入带宽                         |

判断：

```text
Active time 长期接近 100% → 磁盘繁忙或瓶颈
Average response time 明显升高 → IO 延迟偏高
Read/Write speed 高但响应时间低 → 大块顺序 IO
Read/Write speed 不高但响应时间高 → 可能是随机 IO 或队列积压
```

------

### 资源监视器

路径：

```text
Task Manager → Performance → Open Resource Monitor → Disk
```

重点看：

```text
Processes with Disk Activity
Disk Activity
Storage
Disk Queue Length
Response Time
```

它可以直接定位哪个进程在读写磁盘。

------

### Performance Monitor

打开：

```text
perfmon
```

常用计数器：

| Counter                                  | 含义         |
| ---------------------------------------- | ------------ |
| `PhysicalDisk\Disk Reads/sec`            | 每秒读 IO    |
| `PhysicalDisk\Disk Writes/sec`           | 每秒写 IO    |
| `PhysicalDisk\Disk Read Bytes/sec`       | 读带宽       |
| `PhysicalDisk\Disk Write Bytes/sec`      | 写带宽       |
| `PhysicalDisk\Avg. Disk sec/Read`        | 平均读延迟   |
| `PhysicalDisk\Avg. Disk sec/Write`       | 平均写延迟   |
| `PhysicalDisk\Current Disk Queue Length` | 当前队列长度 |
| `PhysicalDisk\% Disk Time`               | 磁盘忙碌比例 |

## 7. Windows 性能测试

### winsat，系统自带

```cmd
winsat disk
```

指定盘符：

```cmd
winsat disk -drive c
```

可获得大致的：

```text
Sequential Read
Sequential Write
Random Read
```

适合快速粗测，不适合严肃压测。

------

### DiskSpd，推荐用于服务器压测

DiskSpd 是 Windows 上常用的专业磁盘压测工具。

#### 4K 随机读

```cmd
diskspd.exe -c10G -d60 -r -w0 -b4K -o32 -t4 -L C:\diskspd_test.dat
```

#### 4K 随机写

```cmd
diskspd.exe -c10G -d60 -r -w100 -b4K -o32 -t4 -L C:\diskspd_test.dat
```

#### 70% 读 / 30% 写混合

```cmd
diskspd.exe -c10G -d60 -r -w30 -b4K -o32 -t4 -L C:\diskspd_test.dat
```

#### 顺序读

```cmd
diskspd.exe -c10G -d60 -w0 -b1M -o32 -t1 -L C:\diskspd_test.dat
```

#### 顺序写

```cmd
diskspd.exe -c10G -d60 -w100 -b1M -o32 -t1 -L C:\diskspd_test.dat
```

参数说明：

| 参数    | 含义                  |
| ------- | --------------------- |
| `-c10G` | 创建 10GB 测试文件    |
| `-d60`  | 测试 60 秒            |
| `-r`    | 随机 IO               |
| `-w30`  | 写比例 30%，即 70% 读 |
| `-b4K`  | IO 块大小 4K          |
| `-o32`  | 队列深度 32           |
| `-t4`   | 4 个线程              |
| `-L`    | 输出延迟统计          |

输出重点看：

```text
IOPS
MiB/s
Average latency
Latency percentile
```

------

### CrystalDiskMark

图形化性能测试工具，适合快速看：

```text
SEQ1M Q8T1
SEQ1M Q1T1
RND4K Q32T1
RND4K Q1T1
```

大致对应：

| 项目       | 含义         |
| ---------- | ------------ |
| `SEQ1M`    | 大块顺序读写 |
| `RND4K`    | 4K 随机读写  |
| `Q8 / Q32` | 队列深度     |
| `T1 / T4`  | 线程数       |

服务器场景更建议用 DiskSpd，因为参数更可控。

## 8. Windows RAID / 阵列卡场景

如果 `BusType` 显示为：

```text
RAID
```

或者只能看到一个大盘，例如：

```text
DELL PERC Virtual Disk
HPE LOGICAL VOLUME
MegaRAID Virtual Disk
```

说明 Windows 看到的是虚拟磁盘，不是真实物理盘。

这时需要使用厂商工具：

| 厂商 / 控制器             | 工具                   |
| ------------------------- | ---------------------- |
| Broadcom / LSI / MegaRAID | `storcli`              |
| Dell PERC                 | `perccli` / OpenManage |
| HPE Smart Array           | `ssacli`               |
| Adaptec                   | `arcconf`              |

示例：

```cmd
storcli64.exe show
storcli64.exe /c0 show
storcli64.exe /c0 /vall show
storcli64.exe /c0 /eall /sall show
```

# 十七、补充结论模板

## macOS 示例

```text
服务器磁盘类型：
- /dev/disk0，Apple SSD，Protocol=PCI-Express，Solid State=Yes
- 判断为内置 PCIe / NVMe SSD

健康状态：
- SMART Status：Verified
- 温度、写入量、寿命字段需结合 smartctl 输出进一步判断

性能：
- 顺序读：约 3.5 GB/s
- 顺序写：约 2.8 GB/s
- 4K 随机读写需使用 fio 进一步测试

结论：
- 当前磁盘为 PCIe SSD，健康状态正常
- 若业务中 iostat 显示 MB/s 不高但延迟高，需要进一步分析随机 IO 和进程负载
```

## Windows 示例

```text
服务器磁盘类型：
- Disk 0：Samsung SSD 980 PRO，MediaType=SSD，BusType=NVMe
- Disk 1：ST2000NM0033，MediaType=HDD，BusType=SATA

健康状态：
- HealthStatus：Healthy
- Get-StorageReliabilityCounter 未发现明显读写错误
- 建议结合 CrystalDiskInfo 查看 SSD Wear、HDD 坏道指标

性能：
- DiskSpd 4K 随机读：xxx IOPS
- DiskSpd 4K 随机写：xxx IOPS
- 顺序读写：xxx MB/s

结论：
- Disk 0 为 NVMe SSD，适合数据库、虚拟化、高 IOPS 场景
- Disk 1 为 SATA HDD，更适合冷数据、备份、归档
```

核心判断逻辑仍然是：

```text
磁盘类型：SSD / HDD / NVMe / SATA / SAS / RAID
健康状态：SMART / Wear / Bad Sector / Media Error
实时压力：IOPS / MB/s / latency / queue
基准性能：fio / DiskSpd / CrystalDiskMark / Blackmagic
```
