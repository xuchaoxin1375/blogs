## abstract

在 macOS 中，标准的 MacBook 笔记本键盘或小尺寸的苹果妙控键盘通常**没有独立的 `Home` 和 `End` 键**。

不过，你可以通过**系统原生快捷键**来完美替代，或者使用**软件改键**来实现。以下是具体的实现方法：

### 方法一：使用原生快捷键（最推荐）

Windows 用户习惯的 `Home` 键通常有两个作用：回到行首、回到页面顶部。在 Mac 上，这些功能被分配给了不同的组合键：

#### 1. 光标移动到“当前行的行首”（最符合 Windows 的 Home 键习惯）
**`Command (⌘) + 左方向键 (←)`**：光标瞬间跳转到当前行的最左侧。

**`Control (⌃) + A`**：光标跳转到段落/行首。（这是 Mac 继承自 Unix 的全局快捷键，在终端、代码编辑器或文本输入框中极其好用，且手不需要离开主键盘区）。

#### 2. 页面/光标跳转到“文档最顶部”
**`Fn + 左方向键 (←)`**：在硬件层面上，**这就是 Mac 的真正的 `Home` 键**。它通常用于将网页或文档滚动到最上方（注意：在某些文本编辑器中，它只滚动页面，光标位置不变）。

**`Command (⌘) + 上方向键 (↑)`**：将光标直接跳转到整个文档或网页的**最开头**（相当于 Windows 里的 `Ctrl + Home`）。

---

*附赠：对应的 `End` 键实现方式*

到行尾：`Command (⌘) + 右方向键 (→)` 或 `Control (⌃) + E`

到文档底端：`Fn + 右方向键 (→)` 或 `Command (⌘) + 下方向键 (↓)`

---

### 方法二：使用软件修改按键（适合重度依赖单键的用户）

如果你觉得按组合键太麻烦，希望把键盘上的某个不常用按键（比如右侧的 `Option` 或 `Command`）变成独立的 `Home` 键，可以使用免费且强大的开源改键软件：**Karabiner-Elements**。

**操作步骤：**

下载并安装 [Karabiner-Elements](https://karabiner-elements.pqrs.org/)。

打开软件，进入 `Simple Modifications`（简单修改）页面。

点击 `Add item`（添加项目）。

在左侧（From key）选择你想要牺牲的按键，比如 `right_command`（右 Command 键）。

在右侧（To key）下拉菜单中找到并选择 `home`。

设置立即生效，现在你按右侧的 Command 键，就等于按下了标准的 Home 键。

### 方法三：使用外接键盘
如果你使用的是**带有数字小键盘的全尺寸苹果妙控键盘**（Magic Keyboard with Numeric Keypad），或者任何**普通的 Windows 机械/薄膜键盘**，上面是有实体的 `Home` 键的。

按下外接键盘上的 `Home` 键，在 Mac 上默认等同于 `Fn + 左方向键 (←)`（即滚动到页面顶部）。

**总结建议：**
刚从 Windows 转到 Mac 的用户，建议强迫自己习惯 **`Command + 左右方向键`**（行首尾）和 **`Command + 上下方向键`**（文档首尾），习惯之后操作效率会非常高。
