## 切换用户和权限借用👺

在Linux上，用户切换通常使用`su` 

临时借用指定用户的角色权限使用`sudo`命令。

### su 命令(用户切换)

`su`（switch user）命令允许你切换到另一个用户，默认情况下是切换到超级用户（root）。使用方式如下：

- 切换到root用户：

```bash
su -
```

- 切换到其他用户（假设用户为`username`）：

```bash
su - username #加载目标用户的环境
#或
su username #保持当前用户环境
```

在使用`su`命令时，系统会提示你输入目标用户的密码。

使用`su -`可以**加载目标用户的环境变量**，`su username`则会**保持当前用户的环境**。

### sudo 命令(权限借用)

`sudo`（superuser do）命令允许用户以其他用户（通常是root）权限执行命令，而**无需完全切换到那个用户**。使用方式如下：

- 以root用户身份运行命令：

```bash
sudo command
```

例如：

```bash
sudo apt-get update
```

- 切换到其他用户并执行命令：

```bash
sudo -u username command
```

`sudo`命令需要用户在`/etc/sudoers`文件中有相应的权限。使用`sudo`时，系统会提示你输入当前用户的密码，而不是目标用户的密码。

### 总结

- 使用`su`命令可以切换到另一个用户，需输入**目标用户**的密码。
- 使用`sudo`命令可以执行命令并提升权限，需输入**当前用户**的密码，且要有相应的权限。

## 详解

### 1. **切换到其他用户：`su` 命令**

`su` (switch user) 是最常用的切换用户命令。

#### 基本用法：
```bash
su - username
```

*   **`su - username`**：这是**推荐**的用法。`-`（或 `--login`）参数会模拟一次完整的登录过程，会加载目标用户的环境变量（如 `$PATH`, `$HOME` 等），并将工作目录切换到该用户的家目录。
*   **`su username`**：不带 `-` 参数。只会切换用户身份，但**不会**加载目标用户的完整环境，工作目录也保持不变。这可能导致一些命令找不到或行为异常。

#### 示例：
```bash
# 从当前用户切换到名为 'alice' 的用户
su - alice

# 系统会提示你输入 'alice' 用户的密码
Password:
```

#### 切换回原用户：
切换后，只需输入 `exit` 或按 `Ctrl + D` 即可退出当前用户会话，返回到之前的用户。
```bash
exit
```

---

### 2. **以其他用户身份执行单条命令：`sudo -u`**

如果你不想完全切换用户，只想用另一个用户的身份运行一条命令，可以使用 `sudo`。

```bash
sudo -u username command
```

#### 示例：
```bash
# 以用户 'www-data' 的身份查看其家目录内容
sudo -u www-data ls -l /var/www

# 以用户 'postgres' 的身份启动 psql
sudo -u postgres psql
```

> **前提**：当前用户必须有权限使用 `sudo`，并且在 `/etc/sudoers` 文件中被配置为可以切换到目标用户（通常 `sudo` 组的用户默认可以切换到任何用户）。

---

### 3. **从普通用户切换到 root 用户**

这是 `su` 命令最常见的用途之一。

```bash
# 方法一：使用 su (需要知道 root 密码)
su - root
# 或者简写为
su -

# 方法二：使用 sudo (需要当前用户有 sudo 权限，输入自己的密码)
sudo -i
```

*   **`su -`**：需要输入 **root 用户的密码**。
*   **`sudo -i`**：需要输入 **当前用户的密码**（前提是当前用户在 `sudo` 组里）。

---

### 4. **查看当前用户**

在切换前后，你都可以使用以下命令确认当前是哪个用户：

```bash
# 方法一：显示当前用户名
whoami

# 方法二：显示用户ID和组ID等详细信息
id

# 方法三：查看当前登录的用户和终端
who
```

---

### 📌 总结与最佳实践

| 场景                     | 推荐命令                   | 说明                   |
| :----------------------- | :------------------------- | :--------------------- |
| **完整切换到另一个用户** | `su - username`            | ✅ 最常用，加载完整环境 |
| **仅执行一条命令**       | `sudo -u username command` | ✅ 安全，无需完全切换   |
| **切换到 root 用户**     | `sudo -i`                  | ✅ 推荐，使用自己的密码 |
| **切换到 root 用户**     | `su -`                     | ⚠️ 需要知道 root 密码   |
| **退出当前用户**         | `exit` 或 `Ctrl + D`       |                        |

**重要提示**：
*   使用 `su -` 而不是 `su`，以避免环境变量问题。
*   在生产环境中，尽量避免直接使用 root 用户，而是使用普通用户配合 `sudo` 来执行管理命令，这样更安全且有审计日志。
