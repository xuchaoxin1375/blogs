默认情况下，`sed` 一次只把一行放进模式空间。多行处理就是打破这个限制：用 `N` 把下一行追加进来，用 `P`、`D` 只处理其中一段，用保持空间把内容留到后面的循环。

这一篇的内容比前面进阶，但仍然是“循环 + 模式空间”这套模型的延伸。先把 `n`、`N`、`P`、`D` 四个命令分清，再看经典脚本，最后学标签和分支。

## n 与 N：一个替换，一个追加

### n：打印当前行，再读下一行

`n` 的行为可以拆成两步：

- 如果没有 `-n`，先打印当前模式空间；
- 然后不管有没有打印，都用下一行输入替换模式空间，继续执行 `n` 后面的命令。

如果已经没有下一行，`sed` 退出，不再执行后面的命令。用 `n;d` 删除偶数行来观察：

```shell
$ seq 6 | sed 'n;d'
1
3
5
```

- 第 1 行：`n` 打印 `1`，读入第 2 行；`d` 删除第 2 行，开始下一循环。
- 第 3 行：`n` 打印 `3`，读入第 4 行；`d` 删除第 4 行。
- 第 5 行：`n` 打印 `5`，读入第 6 行；`d` 删除第 6 行。

每次 `n` 都会先输出当前行、再读入下一行，所以 `n;n` 之后的 `s` 作用在每三行上：

```shell
$ seq 6 | sed 'n;n;s/./x/'
1
2
x
4
5
x
```

GNU 的步长地址 `0~3` 可以达到同样效果：

```shell
$ seq 6 | sed '0~3s/./x/'
1
2
x
4
5
x
```

### N：把下一行追加到模式空间

`N` 不打印当前行，而是在模式空间末尾加一个换行符，再把下一行追加进来。之后模式空间里就有两行内容：

```shell
$ printf 'a\nb\nc\nd\n' | sed 'N;s/\n/ /'
a b
c d
```

- 第 1 行 `a` 进入模式空间；`N` 追加 `b`，模式空间变成 `a\nb`；`s/\n/ /` 把换行换成空格，输出 `a b`。
- 第 3 行 `c` 同理，输出 `c d`。

如果行数是奇数，最后一行没有下一行可追加。GNU sed 默认会先打印当前模式空间再退出；加 `-n` 则不会打印：

```shell
$ printf 'x\n' | sed 'N;s/x/y/'
x
$ printf 'x\n' | sed -n 'N;p'
# 无输出
```

为了避免在最后一行执行 `N`，经典写法是 `$!N`：`$` 是最后一行，`!` 取反，所以“不是最后一行时才追加”。

### n 与 N 的对比

| 命令 | 是否打印当前行 | 对模式空间做什么 | 典型用途 |
| --- | --- | --- | --- |
| `n` | 默认打印 | 用下一行替换当前内容 | 跳过某些行、每 N 行处理一次 |
| `N` | 不打印 | 追加下一行，保留当前内容 | 合并行、跨行匹配、多行处理 |

## P 与 D：只处理第一段

当模式空间里包含多行（用 `N` 合并后），`p` 会打印整个模式空间，`P` 只打印第一个换行之前的部分：

```shell
$ printf 'a\nb\nc\nd\n' | sed -n 'N;P;D'
a
b
c
```

这段脚本的执行过程：

- `a` 进入模式空间；`N` 追加 `b`，变成 `a\nb`；`P` 打印第一段 `a`；`D` 删除第一段，模式空间剩下 `b`，然后**不读新行**，从脚本开头重新执行。
- 重新执行时，模式空间是 `b`；`N` 追加 `c`，变成 `b\nc`；`P` 打印 `b`；`D` 留下 `c`，重新开始。
- 依此类推，直到最后。

`D` 的关键是“删除第一段后重新开始循环，但不读新行”。如果模式空间里没有换行符，`D` 的行为和 `d` 一样：删除整个模式空间，开始下一循环。

`P` 和 `D` 经常成对出现，用来逐段处理一个多行缓冲区；`N` 负责不断补充新行。

这个写法有一个边界：最后一段没有下一行可追加时，`N` 会失败，`-n` 下不会打印。例子里最后的 `d` 就被丢掉了。实际使用时要单独处理最后一行，例如在循环结束后补一个 `p`，或改用更适合的工具。

## 保持空间

### 五个命令

保持空间从 `sed` 启动到结束一直存在，初始为空。普通命令碰不到它，只有下面五个命令能在两个空间之间搬运内容：

| 命令 | 作用 |
| --- | --- |
| `h` | 用模式空间覆盖保持空间 |
| `H` | 把模式空间追加到保持空间，前面加一个换行 |
| `g` | 用保持空间覆盖模式空间 |
| `G` | 把保持空间追加到模式空间，前面加一个换行 |
| `x` | 交换两个空间的内容 |

### H 和 G 会先加一个换行

这是最容易踩的坑。`H` 和 `G` 不是“直接拼接”，而是“先加一个换行，再拼接”。保持空间初始为空时，第一次 `H` 会得到一个以换行开头的内容：

```shell
$ printf 'a\nb\n' | sed -n 'H;${x;p}' | sed -n 'l'
$
a$
b$
```

输出第一行是空行，因为保持空间里先是 `\n`，再是 `a\nb`。想避免这个前导换行，可以在第一行用 `h` 而不是 `H`，或者用 `1!H` 跳过第一行。

`G` 同理：`sed 'G'` 会在每一行后面追加一个换行（保持空间为空），于是每行之间多出一个空行。

## 经典脚本

下面这些脚本很有名，但不要直接背。先看输入、输出和执行过程，理解它们怎么利用循环、模式空间和保持空间。

### 反转行序

```shell
$ printf '1\n2\n3\n' | sed '1!G;h;$!d'
3
2
1
```

执行过程：

- 第 1 行 `1`：`1!G` 跳过（第一行不追加保持空间）；`h` 把 `1` 存入保持空间；`$!d` 不是最后一行，删除模式空间，进入下一循环。
- 第 2 行 `2`：`1!G` 把保持空间的内容追加到模式空间，得到 `2\n1`；`h` 把它存回保持空间；`$!d` 删除模式空间。
- 第 3 行 `3`：`1!G` 得到 `3\n2\n1`；`h` 存回；`$!d` 在最后一行不执行，自动打印 `3\n2\n1`，显示为三行。

核心是：每读一行，就把“当前行 + 之前的内容”重新存进保持空间，最后一次性输出。

### 合并所有行

```shell
$ printf 'a\nb\nc\n' | sed ':a;N;$!ba;s/\n/, /g'
a, b, c
```

- `:a` 定义标签 `a`。
- `N` 追加下一行。
- `$!ba`：如果当前不是最后一行，跳回 `a` 继续追加。
- 到达最后一行后，`s/\n/, /g` 把模式空间里的换行全部换成逗号和空格。

这条脚本只适合小文件：它会把整个文件读进一个模式空间，文件很大时内存占用也会很大。

### 每两行合并

```shell
$ printf 'a\nb\nc\nd\ne\n' | sed '$!N;s/\n/ /'
a b
c d
e
```

`$!N` 保证最后一行不执行 `N`，避免“没有下一行”的边界情况；`s/\n/ /` 把两行之间的换行换成空格。奇数行时，最后一行单独输出。

### 压缩连续空行

```shell
$ printf 'a\n\n\nb\n' | sed '/^$/{N;/^\n$/D}'
a

b
```

执行过程：

- 遇到空行时，`N` 把下一行追加进来。
- 如果下一行也是空行，模式空间就是 `\n`，`/^\n$/` 匹配，`D` 删除第一段并重新开始，于是连续空行被逐个吃掉。
- 遇到非空行时，模式空间是 `\n内容`，不匹配 `/^\n$/`，循环结束，输出一个空行和内容。

结果是把连续空行压缩成一个。它不会删除所有空行；要删除所有空行用 `/^$/d`。

### 删除连续的重复行

```shell
$ printf 'a\na\nb\nb\nc\n' | sed '$!N;/^\(.*\)\n\1$/!P;D'
a
b
c
```

- `$!N` 追加下一行。
- `/^\(.*\)\n\1$/` 检查两行是否完全相同：`\(.*\)` 捕获第一行，`\1` 引用它。
- 如果相同，`!P` 不打印第一行；`D` 删除第一行，保留第二行继续比较。
- 如果不同，`P` 打印第一行；`D` 删除第一行，继续。

最终每段连续重复只保留一行。它只处理**连续**重复；要全局去重，用 `sort -u` 或 `awk` 更合适。

### 交换相邻两行

```shell
$ printf 'a\nb\nc\nd\n' | sed -n 'h;n;p;g;p'
b
a
d
c
```

- `h` 把当前行存入保持空间。
- `n` 打印当前行（这里被 `-n` 抑制）并读入下一行。
- `p` 打印下一行。
- `g` 把保持空间里的上一行取回模式空间。
- `p` 打印上一行。

如果行数是奇数，最后一行会在 `n` 处因为没有下一行而退出，可能丢失；实际使用时要先确认行数，或改用其他工具。

### 每行后面加空行

```shell
$ printf 'a\nb\n' | sed 'G'
a

b

```

`G` 把保持空间追加到模式空间；保持空间一直为空，所以每行后面都多一个换行。

### 给行编号

```shell
$ printf 'a\nb\nc\n' | sed = | sed 'N;s/\n/\t/'
1	a
2	b
3	c
```

第一个 `sed =` 输出“行号、内容”交替的行；第二个 `sed` 用 `N` 把行号和内容合并成一行，再把中间的换行换成制表符。

### 删除文件末尾的空行

```shell
$ printf 'a\n\n\n' | sed -e :a -e '/^\n*$/{$d;N;ba' -e '}'
a
```

这条脚本用标签和 `N` 把末尾的空行读进来，遇到最后一行时删除。它可读性不高，实际工作中用 `awk 'NF'`、`perl` 或先 `tac` 再处理往往更清楚。

## 分支与流程控制

`sed` 的流程控制靠标签和 **分支**(branch)命令完成，可以把它看成脚本里的小型跳转。

### 标签、b、t、T

- `:label`：定义一个 **标签**(label)，供跳转使用。
- `b label`：无条件跳到标签。
- `b`：不带标签时跳到脚本末尾，相当于结束当前行、开始下一循环。
- `t label`：如果自上次读取输入行、或上次执行条件分支以来发生过成功的替换，就跳到标签。
- `T label`：和 `t` 相反，如果没发生过替换才跳（GNU 扩展）。

`t` 判断的是“有没有执行过成功的 `s`”，不是“内容有没有变化”。即使替换后的文本和原来完全一样，也算发生过替换。

### 跳过某些行

```shell
$ printf 'skip\nprocess\n' | sed '/skip/b; s/process/PROCESSED/g'
skip
PROCESSED
```

第一行匹配 `/skip/`，执行 `b` 后直接结束当前行，后面的 `s` 不执行；第二行不匹配，正常执行替换。

### 循环直到没有变化

```shell
$ printf 'a     b\n' | sed ':a;s/  / /g;ta'
a b
```

- `:a` 定义标签。
- `s/  / /g` 把所有连续两个空格替换成一个空格。
- `ta`：如果刚才发生了替换，跳回 `a` 再试一次，直到没有连续两个空格。

这个写法适合“一次替换可能产生新的匹配”的场景。注意循环必须有终止条件：如果 `s` 每次都能成功，就会无限循环。

### t 与 T 的对照

```shell
$ printf '1\n2\n3\n' | sed 's/1/X/;T no;s/^/hit:/;b;:no;s/^/miss:/'
hit:X
miss:2
miss:3
```

- 第 1 行：`s/1/X/` 成功，`T no` 不跳，执行 `s/^/hit:/`，输出 `hit:X`。
- 第 2、3 行：`s/1/X/` 失败，`T no` 跳到 `:no`，执行 `s/^/miss:/`，输出 `miss:2`、`miss:3`。

### 标签与分号的兼容性

GNU sed 允许用分号分隔标签和分支命令：

```bash
sed '/1/b x ; s/^/=/ ; :x ; 3d' file
```

BSD/macOS sed 对标签和分号的处理更严格。需要跨平台时，用多个 `-e` 或换行：

```bash
sed -e '/1/b x' -e 's/^/=/' -e ':x' -e '3d' file
```

## 常见误区

- **`n` 和 `N` 搞混**：`n` 是“打印当前行，再读入下一行”，`N` 是“追加下一行”；一个会丢掉当前内容，一个会保留。
- **在最后一行执行 `N`**：GNU 默认会打印当前模式空间再退出，POSIX 行为不同；需要控制边界时用 `$!N`。
- **`D` 在没有换行时还期待它只删第一段**：没有换行时 `D` 等同 `d`，会删除整个模式空间。
- **`H`/`G` 忘了前导换行**：它们先加换行再拼接，保持空间为空时会产生一个空行。
- **`g` 覆盖了当前行**：`g` 用保持空间替换模式空间，当前内容会丢失；需要保留时用 `G` 或 `x`。
- **`t` 以为判断的是“内容变了”**：它判断的是“执行过成功的 `s`”，替换成相同文本也算。
- **`b` 不带标签以为会跳到脚本末尾继续执行**：它结束当前行，开始下一循环，后面的命令不会执行。
- **循环没有终止条件**：`:a; s/.../.../; ta` 如果 `s` 永远成功，就会无限循环；先在副本上测试。

## 自测

- 用 `n` 删除偶数行。
- 用 `N` 把每两行合并，行间用 ` | ` 分隔。
- 反转一个文件的行序。
- 压缩连续空行。
- 删除连续的重复行。
- 跳过包含 `skip` 的行，其余行前加 `> `。

参考答案：

```bash
sed 'n;d' file
sed '$!N;s/\n/ | /' file
sed '1!G;h;$!d' file
sed '/^$/{N;/^\n$/D}' file
sed '$!N;/^\(.*\)\n\1$/!P;D' file
sed '/skip/b; s/^/> /' file
```
