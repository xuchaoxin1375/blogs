前面几篇一直在用 `d`、`p` 和 `s`。这一篇把其他常用命令补齐：怎么删、怎么打印、怎么插入和追加、怎么整行替换、怎么做字符转换、怎么读写文件、怎么提前退出。

多行处理专用的 `n`、`N`、`P`、`D` 和保持空间命令放在 [进阶](06-进阶@多行处理与流程控制.md)，这一篇只在必要处提一下。

## 命令的共同形状

一条 `sed` 命令的基本形状是：

```bash
[地址]命令[参数]
```

例如 `2d` 是“删除第 2 行”，`/error/p` 是“打印包含 error 的行”。地址的写法见 [地址](02-地址@选择要处理的行.md)。

## 删除与打印

### d：删除模式空间并开始下一循环

```shell
$ seq 5 | sed '2d'
1
3
4
5
$ seq 5 | sed '2,4d'
1
5
$ seq 5 | sed '/[24]/d'
1
3
5
```

`d` 删除的是整个模式空间，并且立即开始下一个循环，所以 `d` 后面的命令不会对当前行执行：

```shell
$ printf 'a\nb\n' | sed '/a/{d;s/a/X/}'
b
```

第一行匹配 `/a/`，执行 `d` 后直接进入下一循环，后面的 `s/a/X/` 没有机会执行。

### p：打印模式空间

```shell
$ seq 3 | sed -n '2p'
2
$ seq 3 | sed -n '2,3p'
2
3
```

`p` 通常和 `-n` 搭配。不加 `-n` 时，自动打印和 `p` 会叠加：

```shell
$ seq 3 | sed '2p'
1
2
2
3
```

### =：打印行号

```shell
$ printf 'a\nb\nc\n' | sed '='
1
a
2
b
3
c
```

`=` 输出行号后，自动打印仍然输出原行。只想看行号时加 `-n`：

```shell
$ printf 'a\nb\nc\n' | sed -n '='
1
2
3
```

只对匹配行打印行号：

```shell
$ printf 'a\nb\nc\n' | sed -n '/b/{=;p}'
2
b
```

### l：把不可见字符显示出来

`l` 用可读的转义形式打印模式空间，行尾用 `$` 标记。排查制表符、回车、不可打印字符时非常有用：

```shell
$ printf 'a\tb\n' | sed -n 'l'
a\tb$
```

默认会在较长行上自动换行；`l 0` 表示不换行。`l` 的长度也可以用命令行选项 `-l N` 设置。

### z：清空模式空间

`z` 是 GNU 扩展，把模式空间清空：

```shell
$ printf 'abc\n' | sed 'z' | od -c
0000000  \n
0000001
```

它和 `s/.*//` 的结果类似，但 `z` 更直接，也能处理无效的多字节序列。注意清空模式空间不等于删除行：自动打印仍会输出一个空行。

## 插入、追加与整行替换

### a：在匹配行后追加文本

GNU 支持把文本直接写在 `a` 后面：

```shell
$ seq 3 | sed '2a hello'
1
2
hello
3
```

可移植的写法是 `a\` 加换行，再把文本写在下一行：

```bash
sed '2a\
hello' file
```

带缩进的多行文本也能保留缩进：

```bash
sed '2a\
    indented line' file
```

一个容易忽略的差异：GNU 的单行写法会忽略 `a` 后面的前导空白；`a\` 多行写法会保留文本本身的缩进。需要精确控制缩进时用多行写法。

### i：在匹配行前插入文本

```shell
$ seq 3 | sed '2i hello'
1
hello
2
3
```

多行写法同理：

```bash
sed '2i\
hello' file
```

### c：用一段文本替换整行或整个范围

```shell
$ seq 5 | sed '2,4c hello'
1
hello
5
```

`c` 删除地址选中的行，并输出一次替换文本。注意范围 `2,4` 只输出一次 `hello`，不是每行输出一次。

没有地址时，`c` 会对每一行执行，所以每行都被替换：

```shell
$ printf 'a\nb\n' | sed 'c\
X'
X
X
```

### a、i、c 的文本到哪里结束

`a`、`i`、`c` 的文本读取规则，取决于用哪种写法：

- GNU 单行写法（如 `1aHello`）会读到行尾。
- 多行写法从 `a\`、`i\`、`c\` 开始，读到不以反斜杠结尾的行为止。

两种写法都不能用分号把后面的命令隔开：

```shell
$ seq 2 | sed '1aHello ; 2d'
1
Hello ; 2d
2
```

`; 2d` 被当成了要追加的文本，而不是两条命令。正确做法是用 `-e` 分开，或把文本写在独立行：

```shell
$ seq 2 | sed -e '1aHello' -e '2d'
1
Hello
```

多行文本里，除最后一行外，每行末尾用 `\` 续行；最后一个不带 `\` 的行结束文本：

```bash
sed '2a\
first line\
second line' file
```

### i 和 a 的输出时机

- `i` 立即输出插入的文本。
- `a` 把文本排队，到当前循环结束或读下一行前才输出。

用 `-n` 只保留显式输出，可以看清顺序：

```shell
$ printf 'a\n' | sed -n -e 'i BEFORE' -e 'a AFTER' -e 'p'
BEFORE
a
AFTER
```

### 文本里的反斜杠

`a`、`i`、`c` 的文本里，反斜杠和转义序列会被处理。要输出一个字面反斜杠，写两个：

```bash
sed '1a\
C:\\path' file
```

需要精确控制时，先用 `sed -n 'l'` 查看实际输出。

## 字符转换 y

`y` 做逐字符的一对一替换，不支持正则、分组或范围：

```shell
$ echo 'hello world' | sed 'y/abcdefghij/0123456789/'
74llo worl3
```

源字符和目标字符长度必须相同：

```shell
$ echo abc | sed 'y/abc/de/'
sed: -e expression #1, char 9: strings for `y' command are different lengths
```

`y` 也支持自定义分隔符：

```shell
$ echo abc | sed 'y,abc,def,'
def
```

它适合做简单的字符映射，比如大小写转换、ROT13、数字替换。注意 `y` 没有“只替换第几个”的概念，映射表里出现的字符全部替换。

## 读取与写入文件

### r：把文件内容插入到匹配行后

```shell
$ printf 'HEAD\n' > inc.txt
$ printf '1\n2\n' | sed '1r inc.txt'
1
HEAD
2
```

`r` 把文件内容排队，在当前行处理完、循环结束前插入。文件不存在时不会报错，只是什么也不插入。

### R：每次读一行

`R` 是 GNU 扩展，每次被调用时从文件读一行插入：

```shell
$ printf 'L1\nL2\n' > lines.txt
$ printf 'a\nb\nc\n' | sed '1R lines.txt'
a
L1
b
c
```

只对第 1 行调用，所以只插入 `L1`。写成 `1,2R` 会分别在第 1、2 行后插入 `L1`、`L2`。

### w：把模式空间写入文件

```shell
$ printf 'foo\n' | sed -n 's/foo/bar/w out.txt'
$ cat out.txt
bar
```

`w` 命令和 `s///w` 标志都会在开始处理前创建或截断目标文件；即使没有任何行匹配，文件也会存在（可能为空）。同一个文件名在一条 `sed` 命令里只会打开一次。

### W：只写第一行

`W` 是 GNU 扩展，只把模式空间中第一个换行之前的部分写入文件。和 `w` 对比：

```shell
$ printf 'a\nb\n' | sed -n -e 'N' -e 'w all.txt' -e 'W first.txt'
$ cat all.txt
a
b
$ cat first.txt
a
```

### 文件名会一直读到行尾

`r`、`R`、`w`、`W` 都把后面的内容当作文件名，直到行尾。因此不能在同一行后面直接写别的命令：

```shell
# 不符合预期：文件名变成 "out.txt ; 2d"
sed -n '1w out.txt ; 2d' file

# 正确：拆成多个 -e
sed -n -e '1w out.txt' -e '2d' file
```

### 特殊文件名

GNU sed 支持把 `w` 写到 `/dev/stdout` 和 `/dev/stderr`：

```shell
$ echo foo | sed 's/foo/bar/w /dev/stdout'
bar
bar
```

输出出现两次，是因为 `w /dev/stdout` 写了一次，自动打印又写了一次。只想保留一份时加 `-n`，或用 `s///p` 配合 `-n`。

## 提前退出

### q：处理完当前行后退出

```shell
$ seq 10 | sed '3q'
1
2
3
```

`q` 只接受一个地址。写成范围会报错：

```shell
$ seq 5 | sed '1,2q'
sed: -e expression #1, char 4: command only uses one address
```

默认情况下，`q` 会先打印当前模式空间，再退出；加 `-n` 后不打印：

```shell
$ seq 5 | sed -n '3q'
# 无输出
```

`q` 可以带退出码（GNU 扩展）：

```shell
$ printf 'a\nb\n' | sed 'q42'
a
$ echo $?
42
```

### Q：静默退出

`Q` 和 `q` 类似，但不打印当前模式空间：

```shell
$ seq 5 | sed '3Q'
1
2
$ printf 'a\nb\n' | sed '1Q' | od -c
0000000
```

`Q` 也支持自定义退出码，例如 `Q42`。

## 其他命令

### F：打印当前输入文件名

```shell
$ printf 'a\n' > f1.txt
$ printf 'b\n' > f2.txt
$ sed 'F' f1.txt f2.txt
f1.txt
a
f2.txt
b
```

### e：执行命令

`e` 是 GNU 扩展。不带参数时，执行模式空间里的内容，并用输出替换模式空间：

```shell
$ echo 'echo hi' | sed 'e'
hi
```

带参数时，执行指定命令，把输出直接送到标准输出，模式空间不变：

```shell
$ echo 'x' | sed 'e echo hi'
hi
x
```

`e` 后面的命令也会一直读到行尾，和 `w` 的文件名一样，不能用分号分隔；需要多条命令时拆成多个 `-e`。

`e` 可以执行任意 shell 命令，处理不可信输入时不要使用；`--sandbox` 会禁用它。

### v：检查 sed 版本

`v` 不改变输出，只用来要求最低版本：

```shell
$ printf 'a\n' | sed 'v 4.0'
a
$ printf 'a\n' | sed 'v 99.0'
sed: -e expression #1, char 6: expected newer version of sed
```

脚本里加 `v 4.0` 可以在不支持 GNU 扩展的 `sed` 上尽早失败，而不是悄悄地产生错误结果。

### #：注释

```bash
sed '
# 删除空行
/^$/d
# 去掉行尾空白
s/[[:space:]]*$//
' file
```

脚本第一行的前两个字符如果是 `#n`，会强制启用 `-n`。这是旧脚本的写法，自己写时更推荐显式加 `-n`。

### { }：命令分组

一对花括号把多条命令组合起来，让它们共享地址。这种写法叫 **命令分组**(command grouping)，详见 [命令分组](02-地址@选择要处理的行.md#命令分组)。

## 命令速查

| 命令 | 作用 | 例子 |
| --- | --- | --- |
| `d` | 删除模式空间，开始下一循环 | `2d`、`/debug/d` |
| `p` | 打印模式空间 | `-n '2p'` |
| `=` | 打印当前行号 | `-n '/x/='` |
| `l` | 以转义形式打印 | `-n 'l'` |
| `z` | 清空模式空间 | `z`（GNU） |
| `a` | 在匹配行后追加文本 | `2a hello`（GNU 单行写法） |
| `i` | 在匹配行前插入文本 | `2i hello`（GNU 单行写法） |
| `c` | 用文本替换整行或整个范围 | `2,4c hello` |
| `y` | 逐字符转换 | `y/abc/def/` |
| `r` | 在匹配行后插入文件内容 | `1r inc.txt` |
| `R` | 每次读文件的一行 | `1R lines.txt`（GNU） |
| `w` | 把模式空间写入文件 | `/error/w errors.txt` |
| `W` | 只写第一行 | `N;W first.txt`（GNU） |
| `q` | 处理完当前行后退出 | `3q`、`q42` |
| `Q` | 静默退出 | `3Q`、`Q42`（GNU） |
| `F` | 打印输入文件名 | `F`（GNU） |
| `e` | 执行命令 | `e echo hi`（GNU） |
| `v` | 要求最低版本 | `v 4.0`（GNU） |
| `#` | 注释 | `# comment` |
| `{ }` | 命令分组 | `/x/{=;p}` |

多行命令 `n`、`N`、`P`、`D` 和保持空间命令 `h`、`H`、`g`、`G`、`x` 见 [进阶](06-进阶@多行处理与流程控制.md)。

## 常见误区

- **`d` 后面的命令不会执行**：`d` 立即开始下一循环；需要继续处理时不要用 `d`，改用条件分组。
- **`p` 不加 `-n` 会重复输出**：自动打印仍然生效，`p` 是额外打印一次。
- **`a`/`i`/`c` 后面接分号**：分号和后续内容会被当成文本；用 `-e` 或换行分隔。
- **`c` 对范围只输出一次替换文本**：不是每行输出一次；要逐行替换用 `s`。
- **`r`/`w` 的文件名吃到行尾**：同一行后面不能再写命令；用 `-e` 拆分。
- **`w` 会在开始前创建文件**：即使没有匹配，目标文件也会被创建或截断；不要拿它当“只在匹配时创建”。
- **`q` 默认会打印当前行**：不想打印时用 `-n` 或 `Q`。
- **`y` 不是正则替换**：它只做逐字符映射，长度必须相同，不能写 `y/[0-9]/X/` 这种范围。

## 自测

- 删除第 3 行到第 5 行。
- 只打印包含 `ERROR` 的行，并显示行号。
- 在第 1 行后追加两行文本。
- 把匹配行替换成一行新内容。
- 把 `a` 到 `j` 映射成 `0` 到 `9`。
- 打印到第 10 行后退出。

参考答案：

```bash
sed '3,5d' file
sed -n '/ERROR/{=;p}' file
sed '1a\
first line\
second line' file
sed '/pattern/c\
new content' file
sed 'y/abcdefghij/0123456789/' file
sed '10q' file
```

最后一条会输出前 10 行并在第 10 行后退出，不会继续读后面的内容。
