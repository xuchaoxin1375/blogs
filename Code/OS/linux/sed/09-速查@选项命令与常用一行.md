## 命令与选项

### 常用选项

| 选项 | 作用 | 备注 |
| --- | --- | --- |
| `-n` | 禁止自动打印 | 常与 `p` 搭配 |
| `-e 脚本` | 追加一段脚本 | 用了它之后，非选项参数都当输入文件 |
| `-f 文件` | 从文件读取脚本 | 适合长脚本 |
| `-i[后缀]` | 就地编辑 | GNU 后缀可选；BSD/macOS 必须给参数 |
| `-i.bak` | 就地编辑并保留 `.bak` | 跨平台可用 |
| `-E` | 使用扩展正则 | 推荐 |
| `-r` | 同 `-E` | GNU 旧写法，优先用 `-E` |
| `-s` | 多文件独立处理 | 行号、`$`、范围不跨文件 |
| `-z` | 用 NUL 分隔记录 | 配合 `find -print0` |
| `-u` | 减少缓冲 | 适合实时输入 |
| `-l N` | 设置 `l` 的换行长度 | GNU；`0` 表示不换行 |
| `--debug` | 显示脚本和执行过程 | GNU |
| `--posix` | 关闭 GNU 扩展 | 检查可移植性 |
| `--sandbox` | 禁用 `e`、`r`、`w` | GNU |
| `--follow-symlinks` | `-i` 时修改链接目标 | GNU |
| `-b` | 二进制模式 | 只在 Windows/Cygwin 等平台有效 |
| `--help` | 帮助 | |
| `--version` | 版本 | |

### 退出状态

| 状态 | 含义 |
| --- | --- |
| `0` | 成功 |
| `1` | 命令、语法或正则无效；`--posix` 下用了 GNU 扩展 |
| `2` | 有输入文件打不开，其他文件继续处理 |
| `4` | I/O 错误或严重运行时错误 |
| `qN` / `QN` | 自定义退出码（GNU） |

## 常用一行

### 查看与筛选

```bash
# 打印第 5 行
sed -n '5p' file

# 打印第 5 到第 10 行
sed -n '5,10p' file

# 打印最后一行
sed -n '$p' file

# 打印匹配行
sed -n '/pattern/p' file

# 打印匹配行和行号
sed -n '/pattern/{=;p}' file

# 只保留匹配行（删除不匹配的行）
sed '/pattern/!d' file

# 删除空行
sed '/^$/d' file

# 删除注释行和空行
sed '/^#/d;/^$/d' file

# 删除从 CUTOFF 到文件末尾
sed '/CUTOFF/,$d' file

# 统计行数
sed -n '$=' file
```

### 替换与修改

```bash
# 每行第一个 old 换成 new
sed 's/old/new/' file

# 每行所有 old 换成 new
sed 's/old/new/g' file

# 只替换第 2 个匹配
sed 's/old/new/2' file

# 替换路径（用 | 作分隔符）
sed 's|/old/path|/new/path|g' file

# 删除行尾空白
sed -E 's/[[:space:]]+$//' file

# 去掉首尾空白
sed -E 's/^[[:space:]]+//; s/[[:space:]]+$//' file

# 合并连续空白
sed -E 's/[[:space:]]+/ /g' file

# 行首加前缀
sed 's/^/# /' file

# 行尾加后缀
sed 's/$/;/' file

# 注释所有非注释行
sed '/^#/!s/^/# /' file

# 取消行首的一个 # 和空白
sed -E 's/^#[[:space:]]*//' file

# 交换 key:value
sed -E 's/^([^:]*):(.*)$/\2:\1/' file
```

### 插入与删除

```bash
# 在第 3 行后追加一行
sed '3a\
new line' file

# 在第 3 行前插入一行
sed '3i\
new line' file

# 在匹配行后追加一行
sed '/pattern/a\
new line' file

# 把第 2 到第 4 行替换成一行
sed '2,4c\
new line' file

# 删除第 3 行
sed '3d' file

# 删除第 2 到第 4 行
sed '2,4d' file

# 删除匹配行
sed '/pattern/d' file

# 删除两个标记之间的区块
sed '/^BEGIN$/,/^END$/d' file

# 在第 1 行前插入文件内容（GNU）
sed '0r header.txt' file

# 在第 5 行后插入文件内容
sed '5r insert.txt' file

# 把匹配行写入文件
sed -n '/ERROR/w errors.txt' file
```

### 多行与流程

```bash
# 每两行合并，用空格分隔
sed '$!N;s/\n/ /' file

# 所有行合并成一行
sed ':a;N;$!ba;s/\n/, /g' file

# 反转行序
sed '1!G;h;$!d' file

# 压缩连续空行
sed '/^$/{N;/^\n$/D}' file

# 删除连续重复行
sed '$!N;/^\(.*\)\n\1$/!P;D' file

# 每行后加一个空行
sed 'G' file

# 处理到第 10 行后退出
sed '10q' file

# 找到第一个匹配后退出
sed -n '/pattern/{p;q}' file
```

### 编码与格式

```bash
# 删除行尾 CR（Linux）
sed -i.bak 's/\r$//' file

# 删除 UTF-8 BOM（GNU）
sed -i.bak '1s/^\xEF\xBB\xBF//' file

# 把分号分隔的一行拆成多行（GNU）
sed 's/;/\n/g' file

# 把连续空格转成制表符（GNU，简单场景）
sed 's/  */\t/g' file
```

### 就地编辑

```bash
# GNU：直接改，不备份
sed -i 's/old/new/g' file

# 通用：改并备份
sed -i.bak 's/old/new/g' file

# macOS：不备份
sed -i '' 's/old/new/g' file

# 多文件
sed -i.bak 's/old/new/g' ./*.conf

# 配合 find
find /path/to/dir -name '*.conf' -exec sed -i.bak 's/old/new/g' {} +

# 配合 xargs，处理含空格的文件名
find /path/to/dir -name '*.conf' -print0 |
  xargs -0 sed -i.bak 's/old/new/g'
```

## 平台差异速查

| 场景 | GNU/Linux | macOS/BSD |
| --- | --- | --- |
| 就地编辑不备份 | `sed -i 's/a/b/' f` | `sed -i '' 's/a/b/' f` |
| 就地编辑带备份 | `sed -i.bak 's/a/b/' f` | `sed -i.bak 's/a/b/' f` |
| 扩展正则 | `-E` 或 `-r` | `-E` |
| 替换里换行 | `\n` | 反斜杠 + 真实换行 |
| 单行追加 | `a text` | `a\` + 换行 + 文本 |
| 空白字符 | `\s` 或 `[[:space:]]` | `[[:space:]]` |
| 数字 | `[0-9]` 或 `[[:digit:]]` | `[[:digit:]]` |
| 步长地址 | `1~2` | 不支持 |
| `0,/re/` | 支持 | 不支持 |
| `Q`、`T`、`R`、`W`、`z` | 支持 | 不支持 |

## 调试

```bash
# 显示脚本的规范化形式和逐条执行过程
sed --debug 's/foo/bar/' file

# 显示不可见字符
sed -n 'l' file

# 用最小输入复现
printf 'a\nb\n' | sed 's/a/X/'

# 用 ASCII 规则排除 locale 影响
LC_ALL=C sed -n '/^[a-z]*$/p' file

# 看命令实际收到的脚本
script='s/foo/bar/'
printf '%s\n' "$script"

# 检查退出状态
sed 's/a/b/' file
echo $?
```

排查顺序：先看输入字节，再看正则方言，再看 shell 引号，最后看平台差异。
