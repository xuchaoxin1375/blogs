对 **`screen`、`tmux` 和 `zellij`** 三款**终端多路复用器**的详细对比

## 📊 对比表格：Screen vs Tmux vs Zellij

| 特性                                      | Screen                      | Tmux                                | Zellij                              |
| ----------------------------------------- | --------------------------- | ----------------------------------- | ----------------------------------- |
| 开发语言                                  | C                           | C                                   | Rust                                |
| 最后更新时间                              | 较老（2021 年）             | 活跃维护                            | 活跃维护                            |
| 安装方式                                  | 系统包管理器（如 apt、yum） | 系统包管理器或源码安装              | Cargo、系统包管理器                 |
| 支持分屏                                  | ✅（横向）                   | ✅（横向 + 竖向）                    | ✅（竖向/横向 + 布局模板）           |
| 多窗口管理                                | ✅                           | ✅                                   | ✅                                   |
| 配置文件支持                              | ✅（`.screenrc`）            | ✅（`.tmux.conf`）                   | ✅（`~/.zellij/config.kdl`）         |
| 插件生态                                  | ❌                           | ✅（大量插件如 Tmux Plugin Manager） | ✅（插件系统基于 WASM）              |
| 支持热重载配置                            | ❌                           | ✅（`source-file`）                  | ✅                                   |
| 支持 Web 终端                             | ❌                           | ❌                                   | ✅（通过 zellij-web）                |
| 支持共享会话（多人协作）                  | ✅                           | ✅                                   | ✅                                   |
| 跨平台支持                                | ✅（Unix-like）              | ✅（Unix-like / Windows via WSL）    | ✅（Linux / macOS / Windows / WASM） |
| 用户界面                                  | 基础文本                    | 可高度定制状态栏                    | 更现代 UI，支持主题、面板布局       |
| 启动速度                                  | 快                          | 快                                  | 极快（Rust 编写）                   |
| 内存占用                                  | 低                          | 低                                  | 极低（无额外守护进程）              |
| 是否自带“客户端-服务器”架构               | ✅                           | ✅                                   | ❌（默认不持久化，但可启用）         |
| 是否支持嵌套使用（如 tmux 中运行 zellij） | ✅                           | ✅                                   | ✅                                   |
| 学习曲线                                  | 中等                        | 中等偏高（功能丰富）                | 低到中等（文档友好）                |

---

## 🧠 使用建议（按需求分类）

| 需求                   | 推荐工具                     | 理由                                          |
| ---------------------- | ---------------------------- | --------------------------------------------- |
| 传统运维环境，最小依赖 | `screen`                     | 系统预装率高，兼容性强                        |
| 高度定制、长期使用     | `tmux`                       | 强大的插件生态、稳定可靠、社区活跃            |
| 现代开发体验、Web 支持 | `zellij`                     | 更直观的 UI、跨平台好、启动快、支持 WASM 插件 |
| 团队协作、远程演示     | `zellij` 或 `tmux`           | 支持共享会话，zellij 还提供 Web 界面          |
| 初学者入门学习         | `zellij` > `screen` > `tmux` | zellij 的交互式引导和清晰 UI 更容易上手       |
| 多人在线教学           | `zellij`                     | 支持 web 访问，适合远程演示                   |

---

## 📌 兼容性与部署建议

| 工具     | 默认是否持久化会话 | 是否需要后台服务                               | 是否支持热重载 | 是否支持 WASM 插件 |
| -------- | ------------------ | ---------------------------------------------- | -------------- | ------------------ |
| `screen` | ✅                  | ✅（自动运行）                                  | ❌              | ❌                  |
| `tmux`   | ✅                  | ✅（自动运行）                                  | ✅              | ❌                  |
| `zellij` | ❌（默认非持久）    | ❌（默认不运行后台）<br>✅（可启用 attach 模式） | ✅              | ✅（实验性）        |

---

## 🧩 插件与扩展生态

| 工具     | 插件机制       | 插件数量 | 插件示例                                           |
| -------- | -------------- | -------- | -------------------------------------------------- |
| `screen` | ❌              | 无       | 无                                                 |
| `tmux`   | Shell脚本、TPM | 成百上千 | `tmux-resurrect`, `tmux-continuum`, `tpm`          |
| `zellij` | WASM 插件      | 不断增长 | `status-bar`, `workspace-loader`, `terminal-input` |

---

## 🚀 总结推荐

| 场景                         | 推荐工具                                           |
| ---------------------------- | -------------------------------------------------- |
| 简单任务、旧系统兼容         | `screen`                                           |
| 深度定制、自动化、插件化     | `tmux`                                             |
| 现代开发、轻量快速、Web 支持 | `zellij`                                           |
| 教学、远程演示、团队协作     | `zellij`                                           |
| 长期运行、断开重连           | `tmux` > `screen` > `zellij`（需开启 attach 模式） |

---

如果你已经熟悉 `screen` 或 `tmux`，可以继续使用；如果你是新手或者希望获得更现代化的体验，**强烈推荐尝试 `zellij`**。它结合了现代开发工具的优点，并且易于上手。
