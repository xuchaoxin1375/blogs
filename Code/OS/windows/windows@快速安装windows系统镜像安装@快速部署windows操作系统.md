## abstract

- 原地安装 或升级 windows 系统和安装普通软件的步骤差不多，不太需要讨论。
- 关于 win11 绕过硬件限制和双系统快速部署是有一些技巧，让安装过程更快
  - 目前我用过的最快的部署方法是用 dism++的镜像恢复功能，速度非常快，而且可以提前准备驱动打入，支持各种精简版系统的部署，比如非 ISO 合适的其它镜像文件也支持。
  - 特别是双系统，先选定或划分一个分区，还原镜时勾选添加引导，重启到新系统就行。
    另外建议先备份驱动，然后在重启到新系统前执行驱动导入操作，重启后新系统的驱动也都有了，舒服。
  - 如果是单系统升级或降级操作，则把镜像放到另一个分区，如果没有就分配一个 15～20g 的小分区来暂存系统镜像文件，然后同样的操作恢复镜像文件里的系统完成部署。这种情况下dism++会引导重启到PE系统下进行部署,基本上比较自动,容易操作
  - 总之系统镜像文件,尤其是Dism++(其他系统安装辅助工具也是一样的)和新系统要安装的分区盘符不能是同一个就
- 本文主要介绍如何快速部署或安装windows操作系统(win7之后的系统都支持),特点是安装速度快,容易操作

## 镜像说明

dism++方式安装系统支持范围广泛,不仅支持Microsoft官方系统,也支持精简版系统镜像(非ISO格式也可以)

下面以精简版系统为例介绍安装/部署过程,Microsoft官方镜像的操作方法几乎一样

以不忘初心精简系统为例:

- bwcx(不忘初心)精简版系统需要用辅助工具安装,直接点击内部的setup.exe不能安装

- [【不忘初心】Windows11 24H2 (26100.1000) X64 无更新[纯净精简版\][1.92G](2024.7.3) 24H2 抢先体验-不忘初心系统博客 (pc528.net)](https://www.pc528.net/26100w.html)

不忘初心提供的镜像虽然体积较小,但是部分功能的确实可能会影响体验(比如多语言包和TTS引擎的使用会收到影响,并且系统稳定性多少有影响,安装了功能扩展包有潜在无法开机的可能,之前遇到过突然有一天就开机卡在第一家加载页面了),非老旧或小内存设备不建议使用

如果你的设备是8GB运存或者更大,我推荐LTSC系列的系统,号称windows官方精简版(硬件性能充足仍然可以考虑LTSC系列,它的资源消耗更少,风扇安静的时间会更多)

以windows 24h2 Iot Enterprise LTSC官方系统为例,我在上面运行我自己编写的powershell7模块,载入自定义配置环境的时间大概是260ms,而普通的专业版载入时间是450ms左右,确实在许多场景下相应更快

此外,禁用或移除windows defender,停止系统更新,启用流量计费可以减少后台资源占用和消耗,对老设备更友好

## 安装

1. 推荐PE系统下使用WinNTSetup程序安装，PE系统推荐使用（微PE）比较干净无插件。
2. 使用Rufus将镜像刻录到U盘安装。
3. PE下使用`DISM++`安装。

除了以上，其他工具不推荐，可能会有各种问题。

注意不支持解压后双击 "setup.exe" 安装

## 安装案例

- 考虑到精简版驱动应该不是很完善,有条件的话可以预先把驱动准备好
  - 如果已经安装了一个windows系统并且驱动比较完备,那么可以备份一下驱动,比如用dism++导出驱动
    - 而且使用dism++部署系统操作简单,我十分推荐
  - 如果您的笔记本制造商提供了该型号的驱动集合,您也可以从官网下载,然后手动一个个地去安装(步骤稍多,略微麻烦)
  - 或者下载一个驱动安装软件(比如驱动总裁,360驱动大师等),待系统安装完毕后并重启后再去安装驱动
    - 驱动安装软件一般多多少少会夹带私货,给你弹几个广告,而且可能会安装上不兼容的驱动,也挺烦的

### 正式安装

- 我这里选择无广告的dism++工具来安装/部署windows系统
- 我为一台小内存的轻薄本(core i7-8565U - 8g RAM 设备)安装一个精简版的windows11系统,希望获得一个流畅的现代化操作系统的体验
- 以不忘初心的win11 24h2 精简版镜像(1.9GB,大约2000MB左右的镜像)为例进行安装,整个过程(直到所有驱动安装完毕)大约为10分钟,安装速度很快
  - 首先分区:对于精简版系统,比如压缩出一个80GB的盘用来简单办公,浏览网页,或者远程桌面到其他电脑就可,分区可以用windows自带的工具`diskmgnt`(在命令行中输入执行),为压缩出来的卷分配一个盘符(比如T,甚至是X,Y)和卷名,比如win11Lite(表示精简版win11)
  - 利用dism++的**恢复功能**菜单中的**系统还原**,会弹出一个对话框
    - 选择**系统镜像文件**(可以直接输入路径,也可以点击浏览按钮选择文件)(如果读取成功,上面的目标镜像一栏会有一个下拉列表,如果有多个选择,您可以选择要安装专业版还是工作站等版本,具体列表视不同镜像而定)
    - 然后选择要用来安装系统的**空盘符**(千万不要选错,一定要选择刚压缩出来的空盘符,默认可能是D盘,但这很可能是个资料盘或者双系统盘中的某个系统盘符)
    - 为了让系统重启后可以找到新安装的系统的引导选项,这里需要勾选**添加引导**
    - 然后确认开始还原(部署系统),这个过程中不会重启,大约需要5分钟左右,根据计算机的性能,可能更快也可能更慢于这个时间
  - 部署完成后可以在dism++中打开此系统的会话(点击**打开会话**(open session),初次打开需要几秒点时间

### 为了确保为新安装的系统添加引导

- 如果前面还原镜像时没有勾选添加引导,那么可以补救:点击菜单栏中的**恢复菜单**,选择其中的**修复引导**(repair boot),会弹出一个对话框,选择确认
- 要查看是否修复成功,可以在重启之前,打开系统属性高级面板查看(`systempropertiesadvanced.exe`),选择**启动和恢复**(startup and recovery)中的设置(settings)按钮;点击默认操作系统按钮下的下拉框,如果出现了新的启动项,说明引导修复应该可以成功

- 现在重启系统

### 小结

- 使用上述的DISM++安装系统特点是:
  - 适合安装双系统,原版系统可以,许多精简版系统此方法安装更加合适,因为重启到新系统之前我们就可以把几乎所有的驱动一同安装好
  - 会跳过部分安装引导,直接进入**准备设备**环节,重启次数较少,而对于原版系统初次进入到桌面的引导不会跳过,仍然要求你注册微软账号等

### 其他相关工具

- 安装原版系统的另一种较快方法是提前解压镜像到目标盘符以实现快速安装,相关工具比如软媒魔方提供的`hdbooter.exe`(软媒硬盘装机)
- 无论是`DISM++`还是`hdbooter`这类通过提前解压来加速安装的方法都可以跳过原版系统双击`setup.exe`时询问的更新以及保留资料等选择流程
- `hdbooter`可以选择更新某个已有的系统盘的系统,而DISM则主要用来全新安装

### 安装为单系统

- 常规传统方法
  - 如果是原版系统并且是版本升级,则简单的做法是到系统设置更新里面直接检查更新,或者下载新版本镜像文件,双击引导更新,也可以制作系统盘或U盘引导安装
  - 如果是无法更新的镜像,则一般通过分区盘符安装PE,进入PE系统来还原系统(覆盖原系统位置),或者制作为U盘启动盘
  - 制作成U盘的一个好处是可以给其他机器安装系统,而不仅限于当前机器
- 利用Dism++,执行单系统升级或降级操作，则把镜像放到另一个分区，如果没有就分配一个 15～20g 的小分区来暂存系统镜像文件，然后同样的操作恢复镜像文件里的系统完成部署。
  - 这种情况下dism++会引导重启到PE系统下进行部署,基本上比较自动,容易操作
- 总之系统镜像文件和新系统要安装的分区盘符不能是同一个就可以了 

### 导入驱动问题🎈

如果你备份导出的驱动是从win11,而导入到新安装的第二系统win10(或者是win11pro导出给win11ltsc),都比较有概率出现问题(导入遇到错误或失败的驱动文件)

这种情况下如果遇到导入错误(尤其是错误文件数量较多)时可能会导致系统还原后无法顺利引导开机

如果这样,你可以选择在引导进入新系统前不安装驱动,而开机后安装(但是建议事先准备好驱动包,比如无线网卡驱动缺失的话,会导致新系统无法链接网络!)

此外,部分驱动即便在你重启到新系统前就已经安装完毕,但是初次引导部分驱动不会生效,需要你重启设备生效
