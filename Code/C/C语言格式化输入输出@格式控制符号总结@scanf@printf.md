## 格式化输入输出

格式化输入输出主要用的是`scanf`,`printf`,他们的格式控制类似

## 格式化输出

格式化输出——printf 函数输出函数printf将内部数值转换为字符的形式。下面只讲述该函数最典型的用法

```c
int printf(char *format, arg1, arg2, ...);
```

函数printf 在输出格式format 的控制下，将其参数进行转换与格式化，并在标准输出设备上打印出来。它的返回值为打印的字符数。

### 格式字符串

格式字符串包含两种类型的对象：**普通字符**和**转换说明**。在输出时，

- **普通字符**将原样不动地复制到输出流中

- **转换说明**并不直接输出到输出流中，而是**用于控制printf 中参数的转换和打印**
  - 每个**转换说明**都由一个百分号字符（即**%**）开始，并以一个**转换字符**结束。

#### 转换说明

在转换说明部分中的字符%和转换字符中间**可能 依次包含**下列组成部分：

1. 负号，用于指定被转换的参数按照左对齐的形式输出。 
2. 数，用于指定最小字段宽度。转换后的参数将打印不小于最小字段宽度的字段。如果有必要，字段左边（如果使用左对齐的方式，则为右边）多余的字符位置用空格 填充以保证最小字段宽。 
3. 小数点，用于将字段宽度和精度分开。 
4. 数，用于指定精度，即指定字符串中要打印的最大字符数、浮点数小数点后的位数、
5. 整型最少输出的数字数目。 
6. **字母h或l**，字母h表不将整数作为short类型打印，字母l表示**将整数作为long类型打印**。 

如果%后面的字符不是一个转换说明，则该行为是未定义的。 

### printf 函数基本的转换说明(转换字符)👺

| 字符 | 参数类型：输出形式                                           |
| ---- | ------------------------------------------------------------ |
| d, i | int 类型：**十进制数**(d,i在这里(printf)中使用时效果没有区别,但是scanf中的d,i不同,两者被分开列举) |
| o    | int 类型：无符号八进制数（没有前导 0）                       |
| x, X | int 类型：无符号十六进制数（没有前导 0x 或 0X），10~15 分别用 abcdef 或 ABCDEF 表示 |
| u    | int 类型：无符号十进制数                                     |
| c    | int 类型：单个字符                                           |
| s    | char *类型：顺序打印字符串中的字符，直到遇到 '\0' 或已打印了精度指定的字符数为止 |
| f    | double 类型：十进制小数[-]m.ddddd，其中 d 的个数由精度指定（默认值为 6） |
| e, E | double 类型：科学计数法[-]m.ddddde±xx 或 [-]m.dddddeE±xx，其中 d 的个数由精度指定（默认值为 6） |
| g, G | double 类型：根据指数大小选择 e/E 或 f 格式输出，尾部的 0 和小数点不打印 |
| p    | void *类型：指针（取决于具体实现）                           |
| %    | 不转换参数：打印一个百分号%                                  |

在转换说明中，宽度或精度可以用星号*表示，这时，宽度或精度的值通过转换下一参数（必须为 int 类型）来计算。

例如，为了从字符串 s 中打印最多 max 个字符，可以使用以下语句：

```c
printf("%.*s", max, s);
```

下表说明了在打印字符串 "hello, world"（12 个字符）时根据不同转换说明产生的不同结果。我们在每个字段的左边和右边加上冒号，这样可以清晰地表示出字段的宽度。



| 格式化字符串 | 输出示例            | 含义                                       |
| ------------ | ------------------- | ------------------------------------------ |
| `:%s:`       | `:hello, world:`    | 使用默认宽度输出字符串                     |
| `:%10s:`     | `:hello, world:`    | 右对齐，最小宽度为10个字符                 |
| `:%.10s:`    | `:hello, wor:`      | 截断字符串，最多显示10个字符               |
| `:%-10s:`    | `:hello, world:`    | 左对齐，最小宽度为10个字符                 |
| `:%15s:`     | `:   hello, world:` | 右对齐，最小宽度为15个字符                 |
| `:%-15s:`    | `:hello, world   :` | 左对齐，最小宽度为15个字符                 |
| `:%15.10s:`  | `:     hello, wor:` | 右对齐，最小宽度15个字符，最多显示10个字符 |
| `:%-15.10s:` | `:hello, wor     :` | 左对齐，最小宽度15个字符，最多显示10个字符 |

说明

- `%-10s` 和 `%15s` 分别表示左对齐和右对齐，数值指定的是输出时的最小宽度。
- `%.10s` 表示截断字符串，最多显示10个字符。
- `%15.10s` 表示右对齐、最小宽度15字符，同时截断字符串，最多显示10个字符。

请注意：函数 printf 使用第一个参数判断后面参数的个数及类型。如果参数的个数不够或者类型错误，则将得到错误的结果。请注意下面两个函数调用之间的区别：

```c
printf(s);               /* FAILS if s contains % */
printf("%s", s);         /* SAFE */
```

函数 sprintf 执行的转换和函数 printf 相同，但它将输出保存到一个字符串中：

```c
int sprintf(char *string, char *format, arg1, arg2, ...);
```

sprintf 函数和 printf 函数一样，按照 format 格式格式化参数序列 arg1, arg2, ..., 但它将输出结果存放到 string 中，而不是输出到标准输出中。当然，string 必须足够大以存放放输出结果。

### `%#`为输出的2次幂进制数添加修饰

在 C 语言中，`%#` 是一种格式说明符的修饰符，用于在格式化输出时添加特定的前缀，以标识数值的进制。它通常与以下转换说明符一起使用：`o`（八进制）、`x` 或 `X`（十六进制）、`a` 或 `A`（十六进制浮点数）。

### 用法和效果

- `%#o`：在八进制数前添加前缀 `0`。
- `%#x`：在十六进制小写数前添加前缀 `0x`。
- `%#X`：在十六进制大写数前添加前缀 `0X`。
- `%#a` 或 `%#A`：在十六进制浮点数前添加前缀 `0x` 或 `0X`。

#### 其他例子

下面是一些使用 C 语言 `printf()` 函数的例子，每个例子都展示了如何使用表中的格式说明符来输出不同类型的变量。这些例子假定已经定义了适当的变量并赋予了初始值。



```c
#include <stdio.h>

int main()
{
    int dec = 12,ndec=-12, oct = 012, hex = 0x12, unsigned_dec = 12U;
    char ch = 'A';
    char str[] = "Hello, World!";
    double flt = 3.141592653589793, sci = 126789.0;

    // 十进制数
    printf("%d\n", dec); // 12
    printf("%d\n", oct); // 20
    printf("%d\n", hex); // 18
    // 无符号八进制数
    printf("%#o\n", oct); // 012=10
    printf("%#o\n", dec); // 014=12
    printf("%#o\n", hex); // 022=18


    // 无符号十六进制数 (小写)
    printf("%#x\n", hex); // 0x12
    // 无符号十六进制数 (大写)
    printf("%#X\n", hex); // 0X12

    // 无符号十进制数
    // printf("%#u\n", ndec); // 
    printf("%#u\n", unsigned_dec); // 12

    // 单个字符
    printf("%c\n", ch); // A

    // 字符串
    printf("%s\n", str); // Hello, World!

    // 十进制小数
    printf("%f\n", flt); // 3.141593

    // 科学计数法 (小写 e)
    printf("%e\n", sci); // 1.234568e+08
    // 科学计数法 (大写 E)
    printf("%E\n", sci); // 1.234568E+08

    // 根据指数大小选择 e/E 或 f 格式输出
    printf("%g\n", flt); // 3.14159
    printf("%G\n", sci); // 1.234568E+08

    // 指针
    int *ptr = &dec;
    printf("%p\n", ptr); // 00000000005ffe1c (地址会因运行环境而异)

    printf("%p\n", (void *)ptr); // 00000000005ffe1c (地址会因运行环境而异)

    printf("%#p\n", (void *)ptr); // 0x5ffe1c (地址会因运行环境而异)

    // 打印百分号
    printf("%%\n"); // %

    return 0;
}
```

### 解释

- **`%d`, `%i`**:
  - 输出十进制整数。
  - 例如: `..%d..` 输出 `..12345..`。

- **`%o`**:
  - 输出无符号八进制数。
  - 例如: `..%o..` 输出 `..12345..`。

- **`%x`, `%X`**:
  - 输出无符号十六进制数，`%x` 使用小写字母，`%X` 使用大写字母。
  - 例如: `..%x..` 输出 `..12345..`，`..%X..` 输出 `..12345..`。

- **`%u`**:
  - 输出无符号十进制数。
  - 例如: `..%u..` 输出 `..12345..`。

- **`%c`**:
  - 输出单个字符。
  - 例如: `..%c..` 输出 `..A..`。

- **`%s`**:
  - 输出字符串，直到遇到 `\0`。
  - 例如: `..%s..` 输出 `..Hello, World!..`。

- **`%f`**:
  - 输出十进制小数，默认精度为 6 位小数。
  - 例如: `..%f..` 输出 `..3.141593..`。

- **`%e`, `%E`**:
  - 输出科学计数法，`%e` 使用小写字母 e，`%E` 使用大写字母 E。
  - 例如: `..%e..` 输出 `..1.234568e+08..`，`..%E..` 输出 `..1.234568E+08..`。

- **`%g`, `%G`**:
  - 根据指数大小选择 `e/E` 或 `f` 格式输出，尾部的 0 和小数点不打印。
  - 例如: `..%g..` 输出 `..3.14159..`，`..%G..` 输出 `..1.234568E+08..`。

- **`%p`**:
  - 输出指针的值，具体格式依赖于实现。
  - 例如: `..%p..` 输出类似于 `..0x7ffeeb03a9ac..` 的地址。

- **`%%`**:
  - 输出一个百分号 `%`。
  - 例如: `..%%..` 输出 `..%..`。

希望这些例子能够帮助您更好地理解如何在 C 语言中使用 `printf()` 函数的不同格式说明符。

## 格式化输入



输入函数 scanf 对应于输出函数 printf，它在与后者相反的方向上提供同样的转换功能。具有变长参数表的函数 scanf 的声明形式如下：

```c
int scanf(char *format, ...)
```

scanf 函数从标准输入中读取字符序列，按照 format 中的格式说明对字符序列进行解释，并把结果保存到其余的参数中。格式参数 format 将在接下来的内容中进行讨论。其它所有参数都必须是指针，用于指定经格式转换后的相应输入保存的位置。

当 scanf 函数扫描完其格式串，或者碰到某些输入无法与格式控制说明匹配的情况时，该函数将终止，同时，成功匹配并赋值的输入项的个数将作为函数值返回，所以，该函数的返回值可以用来确定已匹配的输入项的个数。如果到达文件的结尾，该函数将返回 EOF。

注意，返回 EOF 与 0 是不同的，0 表示下一个输入字符与格式串中的第一个格式说明不匹配。下一次调用 scanf 函数将从上一次输入转换的最后一个字符的下一个字符开始继续搜索。

另外还有一个输入函数 sscanf，它用于从一个字符串（而不是标准输入）中读取字符序列：
```c
int sscanf(char *string, char *format, arg1, arg2, ...)
```
它按照格式参数 format 中规定的格式扫描字符串 string，并把结果分别保存到 arg1、arg2、...这些参数中。这些参数必须是指针。

格式串通常都包含转换说明，用于控制输入的转换。格式串可能包含下列部分：
- 空格或制表符，在处理过程中将被忽略。
- 普通字符（不包括%），用于匹配输入流中下一个非空白符字符。
- 转换说明，依次由一个%、一个可选的赋值禁止字符*、一个可选的数值（指定最大字段宽度）、一个可选的 h、l 或 L 字符（指定目标对象的宽度）以及一个转换字符组成。

转换说明控制下一个输入字段的转换。一般来说，转换结果存放在相应的参数指向的变量中。但是，如果转换说明中有赋值禁止字符*，则跳过该输入字段，不进行赋值。输入字段定义为一个不包括空白符的字符串，其边界定义为到下一个空白符或达到指定的字段宽度。这表明 scanf 函数将越过行边界读取输入，因为换行符也是空白符。（空白符包括空格符、横向制表符、换行符、回车符、纵向制表符以及换页符）。

转换字符指定对输入字段的解释。对应的参数必须是指针，这也是 C 语言通过值调用语义所要求的。

###  scanf 函数的基本转换说明👺

| d        | 十进制整数; int *                                            |
| i        | 整型数; int *. 该整型数可以是八进制（以0开头）或十六进制（以0x或0X开头） |
| o        | 八进制整型数（可以带或不带前导0); int *                      |
| u        | 无符号十进制整型数; unsigned int *                           |
| x        | 十六进制整型数（可以带或不带前导0x或0X); int *               |

| %        | 表示“%”，不进行赋值                                          |

### h,l修饰符

转换说明 d、i、o、u 及 x 的前面可以加上字符 h 或 l。

- 前缀 h 表明参数表的相应参数是一个指向 short 类型而非 int 类型的指针，
- 前缀 l 表明参数表的相应参数是一个指向 long 类型的指针。
- 类似地，转换说明 e、f 和 g 的前面也可以加上前缀 l，它表明参数表的相应参数是一个指向 double 类型而非 float 类型的指针。

来看第一个例子。

```c
#include <stdio.h>

main() /* rudimentary calculator */
{
    double sum, v;

    sum = 0;
    while (scanf("%lf", &v) == 1)
        printf("\t%.2f\n", sum += v);
    return 0;
}
```

假设我们要读取包含下列日期格式的输入行：

```
25 Dec 1988
```

相应的 `scanf` 语句可以这样编写：

```c
int day, year;
char monthname[20];

scanf("%d %s %d", &day, monthname, &year);
```

因为数组名本身就是指针，所以，monthname 的前面没有取地址运算符&。

字符串面值也可以出现在 `scanf` 的格式串中，它们必须与输入中相同的字符匹配。因此，我们可以使用下列 `scanf` 语句读入形如 mm/dd/yy 的日期数据：

```c
int day, month, year;
scanf("%d/%d/%d", &month, &day, &year);
```

`scanf` 函数忽略格式串中的空格和制表符。此外，在读取输入值时，它将跳过空白符（空格、制表符、换行符等等）。如果要读取格式不固定的输入，最好每次读入一行，然后再用 `sscanf` 将合适的格式分离出来读入。例如，假定我们需要读取一些包含日期数据的输入行，日期的格式可能是上述任一种形式。我们可以这样编写程序：

```c
while (getline(line, sizeof(line)) > 0) {
    if (sscanf(line, "%d %s %d", &day, monthname, &year) == 3)
        printf("valid: %s\n", line); /* 25 Dec 1988 form */
    else if (sscanf(line, "%d/%d/%d", &month, &day, &year) == 3)
        printf("valid: %s\n", line); /* mm/dd/yy form */
    else
        printf("invalid: %s\n", line); /* invalid form */
}
```

`scanf` 函数可以和其它输入函数混合使用。无论调用哪个输入函数，下一个输入函数的调用将从 `scanf` 没有读取的第一个字符处开始读取数据。

注意，`scanf` 和 `sscanf` 函数的所有参数都必须是指针。最常见的错误是将输入语句写成下列形式：

```c
scanf ("%d", n);
```

正确的形式应该为：

```c
scanf ("%d", &n);
```



## 关于`d`,`i`的使用

在 C 语言中，`%d` 和 `%i` 都是用于格式化整数的转换字符，通常用于 `printf` 和 `scanf` 函数中。不过，它们在某些细微的行为上有所不同。以下是它们的详细比较：

### `%d` 和 `%i` 在 `printf` 中

在 `printf` 函数中，`%d` 和 `%i` 是完全等价的，都用于输出十进制整数。

```c
#include <stdio.h>

int main() {
    int num = 42;
    
    printf("%d\n", num); // 输出 42
    printf("%i\n", num); // 输出 42
    
    return 0;
}
```

### `%d` 和 `%i` 在 `scanf` 中

在 `scanf` 函数中，`%d` 和 `%i` 有一些不同之处：

- `%d` 只接受十进制整数输入。
- `%i` 可以接受十进制、八进制和十六进制整数输入。它根据输入的前缀来判断具体的进制：
  - 没有前缀表示十进制。
  - 前缀 `0` 表示八进制。
  - 前缀 `0x` 或 `0X` 表示十六进制。

```c
#include <stdio.h>

int main() {
    int num_d, num_i;
    
    printf("Enter a number for %%d: ");
    scanf("%d", &num_d);
    printf("You entered (%%d): %d\n", num_d);
    
    printf("Enter a number for %%i: ");
    scanf("%i", &num_i);
    printf("You entered (%%i): %d\n", num_i);
    
    return 0;
}
```

假设用户输入 `42`，`052` 和 `0x2A`：

- 对于 `%d`，无论输入 `42`、`052` 还是 `0x2A`，它都会将它们解释为十进制数。
  - 输入 `42` -> 输出 `42`
  - 输入 `052` -> 输出 `52`（解释为十进制）
  - 输入 `0x2A` -> 输出 `0`（无效输入）

- 对于 `%i`，它会根据前缀识别输入：
  - 输入 `42` -> 输出 `42`（十进制）
  - 输入 `052` -> 输出 `42`（八进制）
  - 输入 `0x2A` -> 输出 `42`（十六进制）

### 总结

- 在 `printf` 中，`%d` 和 `%i` 是等价的。
- 在 `scanf` 中，`%d` 只接受十进制输入，而 `%i` 可以识别并接受十进制、八进制和十六进制输入。
