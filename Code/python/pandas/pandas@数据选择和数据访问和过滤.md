## Pandas数据访问与过滤

DataFrame是Pandas最核心的数据结构，掌握它的访问和过滤方法是数据处理的基础。下面通过典型示例展示各种数据访问和过滤方法。

##  基础数据访问

分别介绍列访问(单列,多列)和行访问(单行,多行)

```python
import pandas as pd

# 创建示例DataFrame
data = {
    '姓名': ['张三', '李四', '王五', '赵六', '钱七'],
    '年龄': [25, 30, 35, 28, 32],
    '城市': ['北京', '上海', '广州', '深圳', '北京'],
    '薪资': [15000, 20000, 25000, 18000, 22000]
}
df = pd.DataFrame(data)
```



### 列访问

```python


# 访问单列（返回Series）
name_series = df['姓名']
print(name_series)
"""
0    张三
1    李四
2    王五
3    赵六
4    钱七
Name: 姓名, dtype: object
"""

# 访问多列（返回DataFrame）
subset = df[['姓名', '年龄']]
print(subset)
"""
   姓名  年龄
0  张三  25
1  李四  30
2  王五  35
3  赵六  28
4  钱七  32
"""
```

`df.loc[:,'姓名']` 的等价写法可以是 `df['姓名']` 或 `df.iloc[:, df.columns.get_loc('姓名')]`。这三种写法都可以用来获取 DataFrame 中名为 '姓名' 的列。

###  行访问

#### 使用.loc访问行

这种方式是主流方式

```python
# 通过索引标签访问行（loc）
print(df.loc[1])  # 访问第二行（索引从0开始）
"""
姓名      李四
年龄      30
城市     上海
薪资    20000
Name: 1, dtype: object
"""

# 通过位置访问行（iloc）
print(df.iloc[1])  # 同样访问第二行
"""
姓名      李四
年龄      30
城市     上海
薪资    20000
Name: 1, dtype: object
"""

# 切片访问多行
print(df.loc[1:3])  # 访问第2到4行（包含结束位置）
"""
   姓名  年龄  城市     薪资
1  李四  30  上海  20000
2  王五  35  广州  25000
3  赵六  28  深圳  18000
"""

print(df.iloc[1:4])  # 访问第2到4行（不包含结束位置）
"""
   姓名  年龄  城市     薪资
1  李四  30  上海  20000
2  王五  35  广州  25000
3  赵六  28  深圳  18000
"""
```

#### 使用df[]切片访问行

df对象可以通过`[slice]`的方式进行行访问,效果和`df.loc[slice]`类似

### 小结

> ❗注意：不要使用 `df.column_name` 这种属性式访问方式，因为如果列名和 DataFrame 的方法名冲突（如 `df.index`），会导致错误。 

| 目标     | 语法                          | 返回类型    |
| -------- | ----------------------------- | ----------- |
| 获取单列 | `df['A']`                     | `Series`    |
| 获取多列 | `df[['A', 'B']]`              | `DataFrame` |
| 添加列   | `df['new'] = ...`             | -           |
| 删除列   | `del df['A']`或`df.drop(...)` | -           |
| 行切片   | `df[0:2]`                     | `DataFrame` |
| 行筛选   | `df[df['A'] > 1]`             | `DataFrame` |

------

如果你需要更精细地访问数据，比如同时选择行和列，可以使用 `.loc[]` 和 `.iloc[]`，它们提供了标签和位置索引的功能。

`df[]`、`.loc[]` 和 `.iloc[]` 是 Pandas 中访问 DataFrame 数据的三种常用方式，它们各有适用场景和限制。

## `df[]`、`.loc[]` 和 `.iloc[]` 详细用法对比

### 1. `df[]`：基础访问方式

可以做什么：

- **选取单列**：`df['A']`
- **选取多列**：`df[['A', 'B']]`
- **行切片（按整数位置）**：`df[0:3]`
- **布尔筛选**：`df[df['A'] > 1]`

❌ 不支持：

- 同时选择行和列
- 使用位置索引选择列
- 更复杂的条件筛选组合

示例：

```python
df = pd.DataFrame({'A': [1, 2, 3], 'B': [4, 5, 6]}, index=['x', 'y', 'z'])

print(df['A'])         # 选列
print(df[['A', 'B']])  # 多列
print(df[0:2])         # 行切片（位置）
print(df[df['A'] > 1]) # 布尔筛选
```

---

### 2. `.loc[]`：基于标签的访问器（label-based）

可以做什么：

- 按 **行标签** 和 **列标签** 访问数据
- 同时选择行和列
- 支持切片和列表

示例：

```python
print(df.loc['x'])          # 单行
print(df.loc[['x', 'y']])   # 多行
print(df.loc[:, 'A'])       # 所有行，某一列
print(df.loc['x':'y', 'A':'B'])  # 行和列切片
```

⚠️ 注意：

- 标签必须存在，否则会报错
- 切片是 **包含终点** 的（不同于 Python 切片）

---

### 3. `.iloc[]`：基于位置的访问器（position-based）

可以做什么：

- 按 **整数位置** 访问数据
- 同样支持行和列的同时选择
- 支持切片和列表

示例：

```python
print(df.iloc[0])            # 第一行
print(df.iloc[[0, 1]])       # 前两行
print(df.iloc[:, 0])         # 第一列
print(df.iloc[0:2, 0:2])     # 行和列切片
```

⚠️ 注意：

- 类似于 NumPy 的数组访问方式
- 切片不包含终点（与 Python 一致）

| 方法      | 支持的功能               | 索引类型                     |
| --------- | ------------------------ | ---------------------------- |
| `df[]`    | 选择列、行切片（按位置） | 列名、布尔掩码、整数切片     |
| `.loc[]`  | 行+列标签访问            | 标签（label-based）          |
| `.iloc[]` | 行+列位置访问            | 位置索引（integer position） |

### 快速标量访问|单元素访问

`.at[]` 和 `.iat[]` 是 Pandas 中用于**快速访问单个元素**的工具，它们是 `.loc[]` 和 `.iloc[]` 的“更快版本”，专门用于访问**单一标量值（scalar value）**。下面我们来详细对比一下它们的用法和区别。

---

📌 一、功能概述

| 方法     | 索引方式                 | 是否支持多值访问   | 是否推荐     |
| -------- | ------------------------ | ------------------ | ------------ |
| `.at[]`  | 标签（label-based）      | ❌ 只能访问单个元素 | 快速访问标量 |
| `.iat[]` | 位置（integer position） | ❌ 只能访问单个元素 | 快速访问标量 |

---

🧩 二、语法与使用示例

我们先定义一个 DataFrame 示例：

```python
import pandas as pd

df = pd.DataFrame({'A': [10, 20, 30],
                   'B': [40, 50, 60]},
                  index=['x', 'y', 'z'])
```

输出为：

```
    A   B
x  10  40
y  20  50
z  30  60
```

---

### `.at[]`：基于标签访问单个元素

- 通过 **行标签 + 列标签** 访问数据。
- 速度比 `.loc[]` 更快，因为只处理一个元素。

#### 示例：

```python
print(df.at['y', 'B'])  # 输出: 50
```

#### 修改值：

```python
df.at['y', 'B'] = 999
print(df)
# 输出:
#     A    B
# x  10   40
# y  20  999
# z  30   60
```

---

### `.iat[]`：基于位置访问单个元素

- 通过 **行号 + 列号**（整数索引）访问数据。
- 类似于 NumPy 数组中的 `arr[i, j]`。

#### 示例：
```python
print(df.iat[1, 1])  # 输出: 50 （第1行第1列）
```

#### 修改值：

```python
df.iat[1, 1] = 888
print(df)
# 输出:
#     A    B
# x  10   40
# y  20  888
# z  30   60
```

---

📊 四、使用建议总结

| 场景                             | 推荐方法              |
| -------------------------------- | --------------------- |
| 获取某一行某一列的值（已知标签） | `.at[]`               |
| 获取某一行某一列的值（已知位置） | `.iat[]`              |
| 修改某个单元格的值               | `.at[]` 或 `.iat[]`   |
| 获取多个行/列或进行切片操作      | `.loc[]` 或 `.iloc[]` |

---

🧪 五、性能对比小实验（简单说明）

如果你在循环中频繁访问 DataFrame 的每个元素，使用 `.at[]` 或 `.iat[]` 比 `.loc[]` 或 `.iloc[]` **快很多**，因为后者每次都要构造一个子 DataFrame。

例如：

```python
for i in range(len(df)):
    val = df.iat[i, 1]  # 快速获取
```

比：

```python
for idx in df.index:
    val = df.loc[idx, 'B']  # 稍慢
```

更高效。

---

### 总结：

> - 使用 `.at[]` 来**按标签快速访问单个元素**
> - 使用 `.iat[]` 来**按位置快速访问单个元素**
> - 它们比 `.loc[]` 和 `.iloc[]` 更快，但只能访问单个值，不能用于切片或多元素选择。



在 Pandas 中，`df[]` 是用于访问 `DataFrame` 数据的一种基本方式。它可以接受多种类型的输入值，根据传入的不同参数实现不同的功能（如选择列、行切片、布尔索引等）。下面是 **对 `df[]` 中允许放入的值的全面总结**：

---

##  `df[]` 参数类型总结🎈

列出此表的意义主要在于能够看懂别人的pandas代码

在自己编写pandas的代码时,我们可能会更加倾向于使用df.loc或df.iloc来访问数据,他们的功能比直接的df更加完整和强大

虽然写法和df[]有所不同,但是从功能的角度,是.loc[],(.iloc[])比df[]要完善的

> 然而,df.loc相比于df[]在访问列数据上,后者会更加简洁,例如`df.loc[:,'A']`可以用`df['A']`表示得更加简洁
>
> 在**行**访问上,`df.loc[]`则是兼容`df[]`的行切片方式,而且支持更加多的方式访问

| 类型                       | 示例                         | 功能说明           |
| -------------------------- | ---------------------------- | ------------------ |
| **字符串（str）**          | `df['A']`                    | 选取单列           |
| **列表（list of str）**    | `df[['A', 'B']]`             | 选取多列           |
| **整数切片（int slice）**  | `df[0:3]`                    | 行切片（按位置）   |
| **布尔 Series**            | `df[df['A'] > 1]`            | 布尔筛选（选出行） |
| **可调用函数（callable）** | `df[lambda df: df['A'] > 1]` | 使用 lambda 筛选   |
| **None（特殊用途）**       | 不适用                       | 通常不直接使用     |

### bool series

过滤数据时,经常使用`df[bool_series]`(或者配合其他条件)的形式过滤,以这种基础形式为例,会筛选出df中的若干行,为`bool_series`中取值为True对应的行;

这种方式,df的每一行都被明确告知是否要保留到返回的结果中

例如

```python
s=[True,True,False,False,True]
df[pd.Series(s)]
```

返回值等价于

```python
df.loc[[0,1,4],:]
```

> 但是注意,列表s如果不转换为pd.series对象,也能够识别
>
> 而非bool序列,例如[1,1,0,0,1]则无法识别

结合上一节的例子,结果和以下df写法返回值一样

```python
df[(df["城市"] == "上海") | (df["城市"] == "北京")]
```

这里`(df["城市"] == "上海") | (df["城市"] == "北京")`的结果是一个bool型pd.series对象,它的值如下:

```
0     True
1     True
2    False
3    False
4     True
Name: 城市, dtype: bool
```



### 注意事项

| 注意事项                | 说明                                               |
| ----------------------- | -------------------------------------------------- |
| `df['col']` vs `df.col` | 推荐使用前者，属性访问容易出错（如列名与方法冲突） |
| 添加新列                | `df['new_col'] = value` 可以添加新列               |
| 删除列                  | `del df['col']` 或 `df.drop(...)`                  |
| 不支持同时选择行列      | 如需同时选择行和列，请使用 `.loc[]` 或 `.iloc[]`   |
| 不能使用位置索引选列    | 如想按列的位置选列，请使用 `.iloc[]`               |

---



###  示例代码汇总

```python
import pandas as pd

df = pd.DataFrame({'A': [1, 2, 3], 'B': [4, 5, 6]}, index=['x', 'y', 'z'])

print(df['A'])                # 单列 -> Series
print(df[['A', 'B']])         # 多列 -> DataFrame
print(df[0:2])                # 行切片 -> DataFrame
print(df[df['A'] > 1])        # 布尔索引 -> DataFrame
print(df[lambda d: d['A'] > 1])  # lambda 函数 -> DataFrame
```

在 Pandas 中，`df.loc[]` 是一个非常强大的访问器，用于**基于标签（label-based）**地访问和操作 DataFrame 的数据。它支持多种类型的输入，可以灵活地选择行和列。

---

## `df.loc[]` 参数类型总结

和`df[]`的列优先不同,`df.loc[]`是行优先的,并且后者访问控制能力更强

| 类型                                     | 示例                                                         | 功能说明             |
| ---------------------------------------- | ------------------------------------------------------------ | -------------------- |
| **单个标签（scalar label）**             | `df.loc['row_label']`                                        | 选取某一行           |
| **多个标签组成的列表（list of labels）** | `df.loc[['row1', 'row2']]`                                   | 选取多行             |
| **切片（slice）**                        | `df.loc['row1':'row3']`                                      | 行切片（包含终点）   |
| **布尔 Series**                          | `df.loc[df['col'] > 10]`                                     | 布尔索引筛选行       |
| **可调用函数（callable）**               | `df.loc[lambda df: df['col'] > 10]`                          | 使用 lambda 函数筛选 |
| **元组(tuple)**                          | `df.loc[:, 'col']` (dataframe)或 `df.loc['row', 'col']`(标量)或<br />`df.loc['row',col_list]`或`df.loc[row_list,'col']`(这两种情况会返回pd.series对象) | 同时选择行和列       |

```python

df = pd.DataFrame({

```

2. **多个标签组成的列表**

```python

```

输出：
```

```

3. **切片（包含终点）**

4. **布尔 Series**

```python

```

输出：
```

```

5. **可调用函数（lambda）**

输出同上。

6. **元组：行+列组合**

✅ 单个单元格

```python
df.loc['x', 'B']
```

```python

```


✅ 所有行或所有列

```python

```

### 注意事项

| 注意事项                       | 说明                                 |
| ------------------------------ | ------------------------------------ |
| 标签必须存在                   | 否则会抛出 `KeyError`                |
| 支持字符串、整数等任意类型标签 | 不仅限于字符串                       |
| 切片是闭区间                   | `df.loc['a':'c']` 包含 `'c'`         |
| 可以结合条件表达式使用         | 如 `df.loc[df['A'] > 1]`             |
| 不支持位置索引                 | 如果你想要位置索引，请使用 `.iloc[]` |

### 对比 `.loc[]` 和 `.iloc[]`

| 特性                    | `.loc[]` | `.iloc[]` |
| ----------------------- | -------- | --------- |
| 索引方式                | 标签     | 位置      |
| 是否包含终点            | 是       | 否        |
| 支持布尔索引            | ✅        | ✅         |
| 支持 callable           | ✅        | ❌         |
| 适用于非连续/非整数索引 | ✅        | ❌         |



##  条件过滤🎈

### 2.1 单条件过滤

```python
# 筛选年龄大于30的员工
older_than_30 = df[df['年龄'] > 30]
print(older_than_30)
"""
   姓名  年龄  城市     薪资
2  王五  35  广州  25000
4  钱七  32  北京  22000
"""

# 筛选北京地区的员工
beijing_employees = df[df['城市'] == '北京']
print(beijing_employees)
"""
   姓名  年龄  城市     薪资
0  张三  25  北京  15000
4  钱七  32  北京  22000
"""
```

### 2.2 多条件组合过滤

与或非条件的使用

1. `&`
2. `|`
3. `~`

```python
# AND条件：年龄大于30且薪资大于20000
condition = (df['年龄'] > 30) & (df['薪资'] > 20000) #pd.series对象
result = df[condition]
print(result)
"""
   姓名  年龄  城市     薪资
2  王五  35  广州  25000
4  钱七  32  北京  22000
"""

# OR条件：年龄小于28或薪资大于20000
condition = (df['年龄'] < 28) | (df['薪资'] > 20000)
result = df[condition]
print(result)
"""
   姓名  年龄  城市     薪资
0  张三  25  北京  15000
2  王五  35  广州  25000
4  钱七  32  北京  22000
"""

# NOT条件：不在北京工作的员工
condition = ~(df['城市'] == '北京')
result = df[condition]
print(result)
"""
   姓名  年龄  城市     薪资
1  李四  30  上海  20000
2  王五  35  广州  25000
3  赵六  28  深圳  18000
"""
```

### 2.3 复杂条件过滤🎈

这类过滤依赖于df提供的适合于过滤的方法,pandas对一些常用逻辑的包装,需要了解api,比如pd.series访问器(`pandas.core.strings.accessor.StringMethods`)



```python
# 使用isin筛选多个值
cities = ['北京', '上海']
result = df[df['城市'].isin(cities)]
print(result)
"""
   姓名  年龄  城市     薪资
0  张三  25  北京  15000
1  李四  30  上海  20000
4  钱七  32  北京  22000
"""

# 使用字符串方法过滤
result = df[df['姓名'].str.startswith('张')]
print(result)
"""
   姓名  年龄  城市     薪资
0  张三  25  北京  15000
"""

# 使用query方法（更简洁的语法）
result = df.query('年龄 > 30 and 薪资 > 20000')
print(result)
"""
   姓名  年龄  城市     薪资
2  王五  35  广州  25000
4  钱七  32  北京  22000
"""
```

## 混合访问（行和列同时筛选）

```python
# 筛选年龄>30的员工的姓名和薪资
result = df.loc[df['年龄'] > 30, ['姓名', '薪资']]
print(result)
"""
   姓名     薪资
2  王五  25000
4  钱七  22000
"""

# 使用iloc按位置筛选
result = df.iloc[1:4, [0, 2]]  # 第2-4行，第1和第3列
print(result)
"""
   姓名  城市
1  李四  上海
2  王五  广州
3  赵六  深圳
"""

# 复杂混合筛选
condition = (df['城市'] == '北京') & (df['薪资'] > 15000)
result = df.loc[condition, ['姓名', '年龄']]
print(result)
"""
   姓名  年龄
4  钱七  32
"""
```

## 总结表格：常用访问过滤方法对比

| 方法              | 用途         | 示例                                   |
| ----------------- | ------------ | -------------------------------------- |
| `df[列名]`        | 选择单列     | `df['姓名']`                           |
| `df[[列1,列2]]`   | 选择多列     | `df[['姓名','年龄']]`                  |
| `df.loc[行标签]`  | 按标签选择行 | `df.loc[1]`                            |
| `df.iloc[行位置]` | 按位置选择行 | `df.iloc[0]`                           |
| `df[条件]`        | 布尔索引     | `df[df['年龄']>30]`                    |
| `df.loc[条件,列]` | 混合选择     | `df.loc[df['城市']=='北京','姓名']`    |
| `df.query()`      | 查询语法     | `df.query('年龄>30 and 城市=="北京"')` |
| `df.isin()`       | 多值筛选     | `df[df['城市'].isin(['北京','上海'])]` |
