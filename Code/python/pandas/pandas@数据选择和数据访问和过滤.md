## Pandas数据访问与过滤

DataFrame是Pandas最核心的数据结构，掌握它的访问和过滤方法是数据处理的基础。下面通过典型示例展示各种数据访问和过滤方法。

## 1. 基础数据访问

分别介绍列访问(单列,多列)和行访问(单行,多行)

### 1.1 列访问

```python
import pandas as pd

# 创建示例DataFrame
data = {
    '姓名': ['张三', '李四', '王五', '赵六', '钱七'],
    '年龄': [25, 30, 35, 28, 32],
    '城市': ['北京', '上海', '广州', '深圳', '北京'],
    '薪资': [15000, 20000, 25000, 18000, 22000]
}
df = pd.DataFrame(data)

# 访问单列（返回Series）
name_series = df['姓名']
print(name_series)
"""
0    张三
1    李四
2    王五
3    赵六
4    钱七
Name: 姓名, dtype: object
"""

# 访问多列（返回DataFrame）
subset = df[['姓名', '年龄']]
print(subset)
"""
   姓名  年龄
0  张三  25
1  李四  30
2  王五  35
3  赵六  28
4  钱七  32
"""
```

### 1.2 行访问

```python
# 通过索引标签访问行（loc）
print(df.loc[1])  # 访问第二行（索引从0开始）
"""
姓名      李四
年龄      30
城市     上海
薪资    20000
Name: 1, dtype: object
"""

# 通过位置访问行（iloc）
print(df.iloc[1])  # 同样访问第二行
"""
姓名      李四
年龄      30
城市     上海
薪资    20000
Name: 1, dtype: object
"""

# 切片访问多行
print(df.loc[1:3])  # 访问第2到4行（包含结束位置）
"""
   姓名  年龄  城市     薪资
1  李四  30  上海  20000
2  王五  35  广州  25000
3  赵六  28  深圳  18000
"""

print(df.iloc[1:4])  # 访问第2到4行（不包含结束位置）
"""
   姓名  年龄  城市     薪资
1  李四  30  上海  20000
2  王五  35  广州  25000
3  赵六  28  深圳  18000
"""
```

## 2. 条件过滤

### 2.1 单条件过滤

```python
# 筛选年龄大于30的员工
older_than_30 = df[df['年龄'] > 30]
print(older_than_30)
"""
   姓名  年龄  城市     薪资
2  王五  35  广州  25000
4  钱七  32  北京  22000
"""

# 筛选北京地区的员工
beijing_employees = df[df['城市'] == '北京']
print(beijing_employees)
"""
   姓名  年龄  城市     薪资
0  张三  25  北京  15000
4  钱七  32  北京  22000
"""
```

### 2.2 多条件组合过滤

```python
# AND条件：年龄大于30且薪资大于20000
condition = (df['年龄'] > 30) & (df['薪资'] > 20000)
result = df[condition]
print(result)
"""
   姓名  年龄  城市     薪资
2  王五  35  广州  25000
4  钱七  32  北京  22000
"""

# OR条件：年龄小于28或薪资大于20000
condition = (df['年龄'] < 28) | (df['薪资'] > 20000)
result = df[condition]
print(result)
"""
   姓名  年龄  城市     薪资
0  张三  25  北京  15000
2  王五  35  广州  25000
4  钱七  32  北京  22000
"""

# NOT条件：不在北京工作的员工
condition = ~(df['城市'] == '北京')
result = df[condition]
print(result)
"""
   姓名  年龄  城市     薪资
1  李四  30  上海  20000
2  王五  35  广州  25000
3  赵六  28  深圳  18000
"""
```

### 2.3 复杂条件过滤

```python
# 使用isin筛选多个值
cities = ['北京', '上海']
result = df[df['城市'].isin(cities)]
print(result)
"""
   姓名  年龄  城市     薪资
0  张三  25  北京  15000
1  李四  30  上海  20000
4  钱七  32  北京  22000
"""

# 使用字符串方法过滤
result = df[df['姓名'].str.startswith('张')]
print(result)
"""
   姓名  年龄  城市     薪资
0  张三  25  北京  15000
"""

# 使用query方法（更简洁的语法）
result = df.query('年龄 > 30 and 薪资 > 20000')
print(result)
"""
   姓名  年龄  城市     薪资
2  王五  35  广州  25000
4  钱七  32  北京  22000
"""
```

## 3. 混合访问（行和列同时筛选）

```python
# 筛选年龄>30的员工的姓名和薪资
result = df.loc[df['年龄'] > 30, ['姓名', '薪资']]
print(result)
"""
   姓名     薪资
2  王五  25000
4  钱七  22000
"""

# 使用iloc按位置筛选
result = df.iloc[1:4, [0, 2]]  # 第2-4行，第1和第3列
print(result)
"""
   姓名  城市
1  李四  上海
2  王五  广州
3  赵六  深圳
"""

# 复杂混合筛选
condition = (df['城市'] == '北京') & (df['薪资'] > 15000)
result = df.loc[condition, ['姓名', '年龄']]
print(result)
"""
   姓名  年龄
4  钱七  32
"""
```

## 总结表格：常用访问过滤方法对比

| 方法              | 用途         | 示例                                   |
| ----------------- | ------------ | -------------------------------------- |
| `df[列名]`        | 选择单列     | `df['姓名']`                           |
| `df[[列1,列2]]`   | 选择多列     | `df[['姓名','年龄']]`                  |
| `df.loc[行标签]`  | 按标签选择行 | `df.loc[1]`                            |
| `df.iloc[行位置]` | 按位置选择行 | `df.iloc[0]`                           |
| `df[条件]`        | 布尔索引     | `df[df['年龄']>30]`                    |
| `df.loc[条件,列]` | 混合选择     | `df.loc[df['城市']=='北京','姓名']`    |
| `df.query()`      | 查询语法     | `df.query('年龄>30 and 城市=="北京"')` |
| `df.isin()`       | 多值筛选     | `df[df['城市'].isin(['北京','上海'])]` |

掌握这些数据访问和过滤方法，你就能高效地从DataFrame中提取所需数据，为后续分析处理打下坚实基础。
