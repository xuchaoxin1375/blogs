Python 的 **海象运算符 (Walrus Operator)** 是在 Python 3.8 中引入的一个新语法，官方名称为 **“赋值表达式” (Assignment Expressions)**。

它的符号是 `:=`，因为长得像侧过来的海象眼睛和长牙而得名。

简单来说，它允许你在**表达式内部**给变量赋值(使得代码更加紧凑)。

- **传统方式：** 你必须先赋值，再使用变量。
- **海象运算符：** 你可以一边赋值，一边判断或使用。

例如在if语句中,`if (n := len(my_list)) > 10:...`,被判断的表达式`(n := len(my_list)) > 10`中完成变量赋值,同时这个表达式也能完成bool计算

------

###  代码对比

#### 场景 A：在 `if` 语句中使用

假设我们要检查一个列表的长度：

**以前的做法：**

```python
n = len(my_list)
if n > 10:
    print(f"列表太长了，共有 {n} 个元素")
```

**使用海象运算符：**

```python
if (n := len(my_list)) > 10:
    print(f"列表太长了，共有 {n} 个元素")
```

> **解析：** `n := len(my_list)` 完成了两个动作：1. 计算长度并赋值给 `n`；2. 返回这个长度用于 `> 10` 的比较。

------

#### 场景 B：在 `while` 循环中使用（最常用）

比如读取用户输入，直到输入 "quit" 为止：

**以前的做法：**

```python
command = input("请输入指令: ")
while command != "quit":
    print(f"执行: {command}")
    command = input("请输入指令: ") # 这里需要重复写一遍赋值
```

**使用海象运算符：**

```python
while (command := input("请输入指令: ")) != "quit":
    print(f"执行: {command}")
```

> **优点：** 代码更简洁，避免了在循环前和循环末尾写重复的赋值代码。

------

###  注意事项

1. **括号是必须的：** 在大多数情况下（如 `if` 或 `while` 中），你需要**用括号把赋值表达式括起来**，否则 Python 可能会解析出错。
2. **不要滥用：** 虽然它能减少行数，但如果在一行里写得太复杂，会降低代码的可读性。
3. **版本限制：** 必须是 **Python 3.8** 或更高版本才能运行。

------

### 总结

海象运算符的核心价值在于 **“计算、赋值、返回”** 一气呵成。它最适合用于那些“如果不赋值就得调用两次函数”或者“需要缩减循环逻辑”的场景。
