## Edge浏览器翻译|自动翻译设置

[在 Microsoft Edge 浏览器中使用 Microsoft Translator - Microsoft 支持](https://support.microsoft.com/en-us/topic/use-microsoft-translator-in-microsoft-edge-browser-4ad1c6cb-01a4-4227-be9d-a81e127fcb0b)

- 进入浏览器设置,从首选语言列表中移除多余的语言设置
  - 网站将以受支持语言列表中的第一种语言进行显示。若要重新排序首选项、提供翻译并以某种语言显示 Microsoft Edge，请选择语言旁的“更多操作...”。
- 将默认语言设置为中文(浏览器以中文显示)
- 移除非中文语言
  - 比如,若列表中有英文(比如英语美国 English(United States)),移除它
  - 如果不移除也能够达到地址栏弹出翻译选项,那么也可以考虑保留
- 设置英语选项(勾选让我选择此语言翻译页面)
- 语言列表下方勾选"让我选择不是我所阅读的语言的页面"
  - 启用此设置时，Microsoft Edge检测网页上的语言，如果检测到的语言未在"首选语言"下列出，则提供翻译服务。
  - 网页文本将发送到Microsoft Translator服务进行翻译，在该服务中存储文本以进行服务改进。详细了解Microsoft Translator服务如何使用数据 [Microsoft 隐私声明](https://privacy.microsoft.com/en-us/privacystatement)。

## 右键翻译

- 无论上述翻译设置如何,通常始终可以通过在阅读的网页右键,然后找到翻译功能,只是每次刷新页面都得这么操作,不是太方便

### 显示原文

- 只要edge翻译了网页(无论是何种方式触发翻译),总是可以在地址栏中看到一个翻译的标记,点开它,设置显示原文(show origin),就可以临时关闭本次翻译
- 如果要长期生效,需要在更多中设置
