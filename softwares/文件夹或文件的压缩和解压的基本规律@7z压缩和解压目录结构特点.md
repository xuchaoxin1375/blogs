## abstract

正确认识压缩软件的一些行为有助于我们更准确的编写网站部署等目录操作相关的脚本;

下面以7z为例

---



例如,我有个wordpress站点压缩包,它是本地的站点,根目录为`.../1.us`,我使用7z将`1.us`这个目录打包压缩,并且命名为`domain.com.7z`;

现在我将其上传到服务器上的`/www/sites/`目录下,我希望将其原网站根目录(`1.us`)中的所有内容解压放到`/www/sites/zsh/domain.com/wordpress/`下,也就是说,这个wordpress目录成为服务器上网站的正式根目录

那么解压命令如何写?

```bash
#将包解压到`/www/sites/zsh/domain.com/wordpress/`,将会得到`/www/sites/zsh/domain.com/wordpress/1.us`
7z x /www/sites/domain.com.7z -o/www/sites/zsh/domain.com/ 

#将1.us目录重命名为wordpress即可
mv /www/sites/zsh/domain.com/1.us /www/sites/zsh/domain.com/wordpress
```

如果打包前将`1.us`重命名为`domain.com`,然后打包压缩为`domain.com.7z`(重命名压缩包文件名不会影响到解压后的结果)

```bash
7z x /www/sites/domain.com.7z -o/www/sites/zsh/domain.com/  #得到/www/sites/zsh/domain.com/domain.com
mv /www/sites/zsh/domain.com/domain.com /www/sites/zsh/domain.com/wordpress/ #重命名即可
```

或者另一种方案

```bash
7z x /www/sites/domain.com.7z -o/www/sites/zsh/domain.com/wordpress
mv /www/sites/zsh/domain.com/wordpress/domain.com/* ..
rm /www/sites/zsh/domain.com/wordpress/domian.com -r
```

### 压缩文件名和解压后的目录名

```bash

7z x ddir.7z -o888
```
