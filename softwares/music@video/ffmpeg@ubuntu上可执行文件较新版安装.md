### abstract

官网仅提供源码:[Download FFmpeg](https://www.ffmpeg.org/download.html)

预编译版本安装参考:[Install FFmpeg (8.0 Updated) via PPA in Ubuntu 22.04 | Ubuntu 24.04 | UbuntuHandbook](https://ubuntuhandbook.org/index.php/2024/04/ffmpeg-7-0-ppa-ubuntu/)

添加新源(ffmpeg 8)

```bash
sudo add-apt-repository ppa:ubuntuhandbook1/ffmpeg8
```

更新后查询可用版本:

```
apt show ffmpeg
```

安装

```bash
sudo apt install ffmpeg
```
