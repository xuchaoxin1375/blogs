- 执行这类操作前,需要了解选择一列或一行的操作
  - [在 Excel 中选择单元格内容 - Microsoft 支持](https://support.microsoft.com/zh-cn/office/在-excel-中选择单元格内容-23f64223-2b6b-453a-8688-248355f10fa9) 这里面包括选择一行或一列的方法
- 移动或复制一列或一行的方法有多种
  - office excel中允许您对一个表单中的数据区域列或行作移动/插入操作,但是不允许对**表格**直接执行移动列操作,Can't move cells in a filtered range or table.[移动或复制单元格、行和列 - Microsoft 支持](https://support.microsoft.com/zh-cn/office/移动或复制单元格-行和列-3ebbcafd-8566-42d8-8023-a2ec62746cfc)
- 最常见的需求是第$i$列的内容移动到第$j$​列的位置(即**剪切和插入**效果)
  - 通常推荐用**快捷键的方式**,可以免去定位出**移动指针**的麻烦
  - 如果借助于**鼠标拖动方式**,需要区分鼠标拖动的几类不同功能,主要分为两大类:**替换**和**插入**
    - 其中替换又分为剪切替换和复制替换,插入分为剪切插入和复制插入
    - 点击列(行)的坐标,以选中列(行)
    - 然后按住`shift`键不放,鼠标靠近需要操作的列(行)边框(位置不一定在第一格,可以往中间位置找),当鼠标指针变为十字形状(称为移动指针),就可以拖动列(行)位置
    - 否则放下鼠标后会被认为是要执行替换并给出警告

## FAQ:表格中的列无法移动或插入问题👺

### 情况1

在 Excel 表格中尝试重新排列单元格时可能会出现了一个错误提示：`“You can't rearrange cells within a table this way, because it might affect other table cells in an unexpected way.”` 这通常是因为你在一个受保护的表格或是一个表格对象 (Table Object) 中进行操作，而 Excel 不允许直接移动单元格来重新排列表格中的数据。

#### 原因

1. **表格对象 (Table Object)**：你的数据是一个表格对象，而不是普通的单元格区域。表格对象具有一定的结构和规则，不能随意拖动单元格。
2. **保护工作表或工作簿**：工作表或工作簿可能被保护，导致无法重新排列单元格。
3. **表格的关系数据**：表格中的数据可能存在某些关联性（如公式或引用），直接拖动单元格会破坏这些关系。

#### 解决方法

1. **转换为普通区域**：
   - 选中整个表格。
   - 在工具栏上选择 `表格设计` 选项卡（或 `Table Tools Design`）。
   - 点击 `转换为区域`（Convert to Range）。
   - 这将表格转换为普通的单元格区域，你可以自由拖动单元格。

2. **排序和筛选**：
   - 使用 Excel 的排序和筛选功能来重新排列数据。
   - 选择表格中的任意一个单元格。
   - 在 `数据` 选项卡中，使用 `排序` 或 `筛选` 工具来重新排列表格中的数据。

3. **解除保护**：
   - 如果工作表或工作簿受保护，点击 `审阅` 选项卡。
   - 点击 `撤销工作表保护` 或 `撤销工作簿保护`。
   - 你可能需要输入密码来解除保护。

4. **移动数据**：
   - 如果你只是需要移动某些行或列的数据，可以先剪切（Ctrl + X）这些数据，然后在目标位置粘贴（Ctrl + V）。

#### 示例步骤：转换为普通区域

1. 选中整个表格（例如通过点击表格左上角的箭头）。
2. 在 `表格设计` 选项卡中点击 `转换为区域`。
3. 确认转换后，你将可以自由地重新排列单元格。

### 情况2

另一种可能是`Can't move cells in a filtered range or table.`,即处于被筛选的状态也不能移动

错误提示“Can't move cells in a filtered range or table.” 意味着你试图移动单元格，但由于表格被过滤或应用了筛选，Excel 不允许这样做。这是因为在过滤的状态下移动单元格可能会破坏数据的完整性和一致性。以下是出现这种情况的原因和解决方法：

#### 原因

1. **过滤 (Filter)**：当前表格应用了筛选，导致某些行被隐藏。
2. **表格对象 (Table Object)**：你正在一个表格对象中进行操作，而表格对象具有一些限制。
3. **保护工作表或工作簿**：工作表或工作簿可能被保护，不允许移动单元格。

#### 解决方法

清除筛选,在进行任何移动操作之前，清除表格中的筛选。

**步骤：**

1. 选择有筛选的表格区域。
2. 在 `数据` 选项卡中，点击 `清除` （Clear）以移除所有筛选。

## 跨列居中👺 

在 Excel 中，"跨列居中" 是一种格式设置，**允许你将一个单元格的内容跨越多列居中显示**。

这在制作报表或表头时特别有用，可以**让标题或说明文本在多个列之间居中对齐，而无需合并单元格**

### 设置跨列居中的步骤

#### 简要步骤

1. **选中需要跨列居中的单元格和其右侧的列**：
   - 例如，如果你希望 A1 的内容跨越 A、B、C 列居中显示，选中 A1 到 C1 的区域。

2. **在“开始”选项卡中找到“跨列居中”按钮**：
   - 在 Excel 的菜单栏中，选择“开始”选项卡。
   - 找到“对齐方式”组。

3. **点击“跨列居中”**：
   - 在“对齐方式”组中，点击“跨列居中”按钮。这个按钮的图标通常是一个带有箭头的对齐图标。

#### 详细步骤

1. **选中要跨列居中的单元格和其右侧的列**：
   - 例如，选中 A1 到 C1。

2. **打开“单元格格式”对话框**：
   - 按 `Ctrl + 1` 或右键点击选中的单元格区域，然后选择“设置单元格格式”。

3. **选择“对齐”选项卡**：
   - 在“单元格格式”对话框中，选择“对齐”选项卡。

4. **在“水平对齐”下拉菜单中选择“跨列居中”**：
   - 在“文本对齐”部分，找到“水平对齐”下拉菜单，选择“跨列居中” (Center Across Selection)。

5. **点击“确定”**：
   - 点击“确定”按钮以应用设置。

通过这些步骤，你可以在 Excel 中实现跨列居中的效果，使你的表格更加美观和易读。

### 与合并单元格的区别

"跨列居中" 与“合并单元格”有一些相似之处，但也有重要的区别：

- **合并单元格** (Merge Cells)：将多个单元格合并为一个单元格，合并后的单元格仅能放置一个内容。如果需要重新编辑单元格内容，可能会影响表格的其他部分。
- **跨列居中** (Center Across Selection)：只是在视觉上将内容跨列居中显示，但不会实际合并单元格。这样保持了单元格的独立性，可以更方便地进行数据处理和编辑。
