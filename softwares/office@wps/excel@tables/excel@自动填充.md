## 复制式填充

但如果 Excel 仍然尝试递增，你可以使用以下方法确保它保持原样：

### 方法 1：按 **Ctrl** + 拖动填充

1. 选中你的 IP 地址单元格。
2. 鼠标移动到单元格右下角，出现“填充柄”十字形状。
3. 按住 **Ctrl** 键的同时，拖动填充柄向下，即可**仅复制**原始 IP 地址，而不会递增。



------

### 方法 2：将 IP 地址列格式改为 **文本**

1. 选中 IP 地址所在的整列（如 A 列）。
2. 在 Excel 上方的“**开始**”选项卡中，找到 **“数字格式”** 下拉菜单。
3. 选择 **“文本”** 格式。
4. 再次输入 IP 地址后，下拉填充时 Excel 只会复制，不会递增。

这样 Excel 就不会把 IP 地址当作数字来处理，从而避免自动递增的问题。
