## 填充

复制式填充

默认情况下 Excel 自动填充尝试递增,你可以使用以下方法复制式填充而不是推测序列递增：

### 按 **Ctrl** + 拖动填充

1. 选中你的 IP 地址单元格。
2. 鼠标移动到单元格右下角，出现“填充柄”十字形状。
3. 按住 **Ctrl** 键的同时，拖动填充柄向下，即可**仅复制**原始 IP 地址，而不会递增。

## 常用语法🎈

### 判断(if)

Excel 中的 **`IF`** 语句用于进行逻辑判断，根据条件的真假返回不同的结果。它的基本语法如下：

```excel
IF(逻辑测试, 条件为真时的返回值, 条件为假时的返回值)
```



### **参数说明：**

- **逻辑测试**：这是一个表达式，Excel 会判断它的结果为 **TRUE**（真）还是 **FALSE**（假）。
- **条件为真时的返回值**：当逻辑测试结果为 **TRUE** 时，返回的值。
- **条件为假时的返回值**：当逻辑测试结果为 **FALSE** 时，返回的值。

### **例子 1：基础的 `IF` 语句**

假设你有一个学生的成绩数据，在 **A1** 单元格，想要判断成绩是否及格（假设及格线是 60 分），如果及格显示 "Pass"，不及格显示 "Fail"。

在 **B1** 中输入以下公式：

```excel
=IF(A1 >= 60, "Pass", "Fail")
```

- 如果 **A1** 中的成绩大于或等于 60，则 **B1** 显示 "Pass"。
- 如果 **A1** 中的成绩小于 60，则 **B1** 显示 "Fail"。



域名规范化

配合公式和自动填充来实现列映射,只要编写一行映射规则(通常是第一行要抓换的),那么相关列就可以配合利用自动填充实现列映射

```bash
=IF(LEFT(B2,4)="www.",LOWER(B2),"www."&LOWER(B2))
```

```bash
= if(Not(ISBLANK(B2)),LOWER(if(left(B2,4)="www.",B2,"www."&B2)),"")
```



------

### **例子 2：多条件的 `IF` 语句（嵌套 `IF`）**

假设你想要根据分数给学生评分，评分等级如下：

- 90 分及以上：`A`
- 80 到 89 分：`B`
- 70 到 79 分：`C`
- 60 到 69 分：`D`
- 60 分以下：`F`

在 **B1** 中输入以下公式：

```excel
=IF(A1 >= 90, "A", IF(A1 >= 80, "B", IF(A1 >= 70, "C", IF(A1 >= 60, "D", "F"))))
```

- 如果 **A1** 中的分数大于或等于 90，返回 "A"。
- 如果 **A1** 中的分数大于或等于 80 且小于 90，返回 "B"。
- 如果 **A1** 中的分数大于或等于 70 且小于 80，返回 "C"。
- 如果 **A1** 中的分数大于或等于 60 且小于 70，返回 "D"。
- 否则，返回 "F"。

------

### **例子 3：使用 `IF` 判断文本**

假设你有一列员工的工作状态数据（"Active" 或 "Inactive"），如果是 "Active"，显示 "Working"；如果是 "Inactive"，显示 "Not Working"。

在 **B1** 中输入以下公式：

```excel
=IF(A1 = "Active", "Working", "Not Working")
```

- 如果 **A1** 中的内容是 "Active"，则 **B1** 显示 "Working"。
- 如果 **A1** 中的内容是 "Inactive"，则 **B1** 显示 "Not Working"。

------

### **例子 4：`IF` 和 `AND` 结合**

假设你想判断某个学生是否及格并且提交了作业。如果成绩大于或等于 60 并且作业已提交（假设作业提交状态存储在 **B1** 单元格，"Yes" 表示已提交），则返回 "Pass"；否则返回 "Fail"。

在 **C1** 中输入以下公式：

```excel
=IF(AND(A1 >= 60, B1 = "Yes"), "Pass", "Fail")
```

- 如果 **A1** 中的成绩大于或等于 60 且 **B1** 中显示 "Yes"，则 **C1** 显示 "Pass"。
- 否则，**C1** 显示 "Fail"。

------

### **总结**

| 语法                                                  | 说明                                                         | 示例                                         |
| ----------------------------------------------------- | ------------------------------------------------------------ | -------------------------------------------- |
| `IF(条件, 真时返回, 假时返回)`                        | 判断一个条件，结果为真时返回一个值，假时返回另一个值         | `=IF(A1 > 10, "Yes", "No")`                  |
| `IF(条件, 真时返回, IF(条件2, 真时返回2, 假时返回2))` | 多层嵌套 `IF`，用于多个条件判断                              | `=IF(A1 > 90, "A", IF(A1 > 80, "B", "C"))`   |
| `AND(条件1, 条件2, ...)`                              | `IF` 和 `AND` 结合，判断多个条件                             | `=IF(AND(A1 > 10, B1 = "Yes"), "Yes", "No")` |
| `OR(条件1, 条件2, ...)`                               | `IF` 和 `OR` 结合，判断多个条件，只要其中一个条件为真，返回真 | `=IF(OR(A1 > 10, B1 = "Yes"), "Yes", "No")`  |

`IF` 语句非常强大，能帮助你根据不同的条件自动执行不同的操作。

## excel中的空和空字符串

在 Excel 中，"空" 和 "空白字符串" 是两个不同的概念，理解它们的区别很重要，尤其在使用公式时。下面是详细解释：

### 1. 空（Empty）

"空" 指的是单元格没有任何内容。也就是说，这个单元格没有填充任何文本、数字或公式，甚至没有空格。空的单元格在公式中通常表示没有值或不存在值。

### 2. 空白字符串（Blank String）

"空白字符串"（`""`）是一个包含零个字符的字符串，也就是一个看起来为空的字符串，但它实际上在单元格中是有一个字符串值的，只不过这个字符串没有显示任何字符。

### 区别：

- **空单元格**：在 Excel 中，空单元格没有任何内容。你可以使用 **`ISBLANK()`** 函数来检测单元格是否为空。例如：

  ```excel
  =ISBLANK(A1)
  ```

  如果 **A1** 是空单元格，结果返回 `TRUE`，否则返回 `FALSE`。

- **空白字符串**：空白字符串 `""` 是一个长度为零的字符串。它不同于空单元格，因为它是存在于单元格中的，只是没有显示字符。你可以用以下公式检测一个单元格是否为空白字符串：

  ```excel
  =A1 = ""
  ```

  如果 **A1** 的值是空白字符串，结果返回 `TRUE`，否则返回 `FALSE`。

### 3. 示例：空和空白字符串的区别

假设 **A1** 单元格的值为：

| **A1** | **A2** (公式)  | **A3** (公式) |
| ------ | -------------- | ------------- |
| 空     | `=ISBLANK(A1)` | `=A1 = ""`    |
| `""`   | `=ISBLANK(A2)` | `=A2 = ""`    |

- 在 

  A1

   为空的情况下：

  - `ISBLANK(A1)` 返回 `TRUE`，表示单元格 **A1** 为空。
  - `A1 = ""` 返回 `FALSE`，因为 **A1** 为空单元格，不是空白字符串。

- 在 

  A2

   为 

  ```
  ""
  ```

   的情况下：

  - `ISBLANK(A2)` 返回 `FALSE`，表示 **A2** 不是空单元格（它含有一个空字符串）。
  - `A2 = ""` 返回 `TRUE`，表示 **A2** 中是空白字符串。

### 4. 影响：

- 使用 **空单元格** 时，很多公式（如 `SUM`、`COUNT` 等）会忽略它。
- 使用 **空白字符串** 时，公式和函数（如 `LEN`、`TEXT` 等）会将其视为一个有效的值。

### 小结：

- **空单元格**：没有内容，可以使用 `ISBLANK()` 判断。
- **空白字符串 `""`**：是一个包含零个字符的字符串，不是空单元格，可以通过 `A1 = ""` 判断。

理解这两者的区别对于写出更精确的公式非常重要。
