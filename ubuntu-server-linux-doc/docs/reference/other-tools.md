# Other tools

Terminal Multiplexers can be a useful tool for system administrators who need to execute multiple sessions in one terminal or SSH connection. They also tolerate detaching or disconnection from remote sessions.

- [Terminal Multiplexers](other-tools/terminal-multiplexers.md#terminal-multiplexers)

`pam_motd` is a PAM module that allows customized “Message Of The Day” (MOTD) messages to be shown.

- [pam_motd](other-tools/pam-motd.md#pam-motd)

`sudo-rs` is a safety-oriented and memory-safe implementation of `sudo` written in Rust.

- [sudo-rs](other-tools/sudo-rs.md#sudo-rs)
