# Networking

This section contains introductions to (and more details about) various aspects of networking in Ubuntu.

## Introduction

If you are new to networking, you should start with these pages to obtain an understanding of the key terms and concepts.

- [Introduction to networking](intro-to/networking.md)
- [Networking key concepts](networking/networking-key-concepts.md)

## Configuration

Network configuration in Ubuntu is managed using Netplan. Find out more [About Netplan](networking/about-netplan.md#about-netplan) or get started with our [network configuration](networking/configuring-networks.md#configuring-networks) walk-through, which gives a practical demonstration.

## Network tools

In our how-to section, we show how to set up virtual switching using Open vSwitch (OVS) and the Data Plane Development Kit (DPDK) library. This page discusses DPDK in more detail.

- [About DPDK](networking/about-dpdk.md#about-dpdk) discusses DPDK in more detail

## DHCP

The Dynamic Host Configuration Protocol (DHCP) handles automatic IP address assignment.

- [About DHCP](networking/about-dhcp.md#about-dhcp) gives details about DHCP and how it works

## Time synchronisation

- [About time synchronisation](networking/about-time-synchronisation.md#about-time-synchronisation) discusses the Network Time Protocol (NTP) and how it works

## Network shares

Samba and Active Directory are two tools you will need if you want to share resources and directories between Linux and Windows systems.

- [Introduction to Samba](intro-to/samba.md#introduction-to-samba) will talk you through the key concepts you will need to be able to follow our how-to guides on Samba

- Our [Active Directory integration](active-directory.md#explanation-active-directory-integration) section has both an introduction and in-depth discussion about Active Directory integration
