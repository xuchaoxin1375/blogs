# Web services

Web servers are used to serve content over a network (or the Internet). If you want more of an introduction to the different types of web servers available in Ubuntu, check out our [Introduction to web services](../explanation/intro-to/web-servers.md#introduction-to-web-services).

## Proxy servers

This section shows how to set up a Squid proxy caching server.

- [Install nginx](web-services/install-nginx.md#install-nginx)

- [Configure nginx](web-services/configure-nginx.md#configure-nginx)
