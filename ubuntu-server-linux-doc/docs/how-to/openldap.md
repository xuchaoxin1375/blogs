# OpenLDAP

The Lightweight Directory Access Protocol, or LDAP, is a protocol for managing hierarchical data and accessing directories. The open source implementation used in Ubuntu is OpenLDAP.

These guides are intended to be sequential, so following them in the order presented below is suggested.

- [Install OpenLDAP](openldap/install-openldap.md)
- [Set up access control](openldap/access-control.md)
- [OpenLDAP with replication](openldap/replication.md)
- [User and group management](openldap/users-and-groups.md)
- [OpenLDAP and TLS](openldap/ldap-and-tls.md)
- [Backup and restore](openldap/backup-and-restore.md)
- [Introduction to passthrough authentication](openldap/ldap-saslauthd-authentication-intro.md)
- [Passthrough authentication with Kerberos](openldap/ldap-saslauthd-kerberos.md)
