## 内存压缩

Windows内存压缩是一项由微软引入的内存管理技术，主要用于在物理内存紧张时改善系统性能。当系统检测到可用物理内存不足时，内存压缩功能会自动压缩一些暂时不活跃或者低优先级的内存页，将其保存在物理内存中而不是转移到磁盘上的虚拟内存文件（交换文件）。这样一来，系统能够腾出更多的物理内存给当前活跃的应用程序使用，从而减少了由于频繁的内存页交换到硬盘而导致的性能损失。

内存压缩的优点在于：

- 提升响应速度：由于数据压缩和解压缩是在内存中完成的，所以相比传统的虚拟内存交换机制，内存压缩能够更快地访问被压缩的数据，降低了I/O延迟。
  
- 更有效地利用内存：通过压缩内存页，即使物理内存相对有限，系统也能更高效地运行多个应用程序。

缺点则包括：

- CPU开销：内存压缩和解压缩过程会消耗一定的CPU资源，如果CPU本身就已经过载或者性能较低，可能会影响整体性能。

### 查看功能是否启用

- Powershell执行` Get-MMAgent|select memoryCompression`
  - 或者直接执行` Get-MMAgent`

- ```bash
  PS C:\Users\cxxu\Desktop> Get-MMAgent|select memoryCompression
  
  memoryCompression
  -----------------
               True
  ```

- 返回True表示压缩功能启用,否则表示未启用

### 配置压缩功能(关闭或启用)👺

- `Disable-MMAgent -mc` 禁用 Windows 内存压缩
- `Enable-MMAgent -mc` 启用 Windows 内存压缩
- 可能需要重启生效

### 开不开内存压缩?

关于Windows中的内存压缩功能（Memory Compression），是否应该开启主要取决于以下几个因素：

1. **系统内存容量**：
   - 如果你的计算机内存（RAM）较小（如8GB及以下），开启内存压缩可能有助于提高性能，因为它可以在物理内存不足时通过压缩暂时不用的数据来节省内存空间，避免频繁地与硬盘交换数据（虚拟内存操作）。

2. **CPU性能**：
   - 内存压缩和解压缩过程确实需要CPU资源，如果你的CPU性能较强且能够有效处理这种额外负担，则开启内存压缩可能不会导致明显的性能下降。但如果CPU性能较弱或已经处于高负荷状态，开启内存压缩可能会增加系统响应延迟和功耗，进而影响整体性能。

3. **应用场景**：
   - 在特定的应用场景下，比如游戏或对实时响应要求较高的专业软件中，如果发现性能问题如掉帧、卡顿等，可以根据实际情况尝试开启或关闭内存压缩来优化体验。

4. **系统版本和优化**：
   - 随着Windows系统的不断更新和优化，内存压缩算法也可能有所改进，因此针对最新版的Windows 11/10，Microsoft的默认设置可能是根据大多数用户的硬件配置和使用习惯进行了调整。

- 在决定是否开启内存压缩时，应考虑你的实际硬件配置以及日常使用需求。
- 如果你的内存较少而CPU性能尚可，开启内存压缩或许有益；反之，如果你拥有足够的内存（比如超过16GB），且CPU性能一般或你希望最大化CPU效率，关闭内存压缩可能是一个更好的选择。
- 在不确定的情况下，可以尝试在两种状态下运行系统，通过观察系统性能监控工具或实际体验来判断哪种模式更适合你的设备。

### 何时解压?

- 对于已经被压缩的内存,几遍我们关闭了很多程序,将内存占用降了下来,但是windows并不会立即将被压缩的内存抽取出来
- 考虑到被压缩的内存数据是相对不活跃的,这可能会在需要这些被压缩的数据的时候从压缩状态被抽取出来

### 个人建议

- 对于小内存设备,使用开启内存压缩功能是很有用的

- 对于中等内存和大内存设备,我仍然建议开启内存压缩

  - 从测试机来看(windows11系统,内存为16GB),系统占用不超过50%时不会进行压缩,也就是说压缩量是0
  - 当内存占用超过50%(我打开20个网页,一个typora编辑器,这两项就占用了3GB内存),比如达到60%,系统会压缩一部分内存
  - 因此如果您的内存很大,打开内存压缩通常不会带来不良影响,特别是平时占用率不高的场景
  - 如果您占用率比较高,那么内存压缩这时候可以让你多开一些程序,尽管这会消耗cpu资源,当可以尽量避免爆内存(但是不能频繁切换不同的程序,这对于内存压缩是很大的考验,需要频繁压缩和解压缩)
  - 实际试验中,700MB的内存可以被压缩到200MB,压缩后的占用是未压缩时的30%左右,

- 理论上,物理内存越大,内存压缩能够施展的拳脚就越大;
  - 假设8GB的物理内存中,最多将2GB的内存数据压缩为0.5GB,这带来1.5GB内存节省
  - 那么从线性的角度看,在16GB内存中,可以将4GB内存压缩到1GB,这带来了3GB的内存节省
