## 注册表方式

- [How to Change Windows  Startup Sound in 3 Steps (windowsreport.com)](https://windowsreport.com/windows-11-change-startup-sound/)
- 有效性自己测试,可能不生效

- 管理员方式打开命令行(cmd或powershell)

- 执行以下命令行

  - ```bash
    reg add "HKEY_CURRENT_USER\AppEvents\EventLabels\WindowsLogon" /v ExcludeFromCPL /t REG_DWORD /d 0
    ```

- 顺利的话可以从**更改系统声音**中看到`windows logo`的声音设置

- 实操

  - ```
    #查询是否有相应的注册表项
    PS> reg query "HKEY_CURRENT_USER\AppEvents\EventLabels\WindowsLogon" /v ExcludeFromCPL
    
    HKEY_CURRENT_USER\AppEvents\EventLabels\WindowsLogon
        ExcludeFromCPL    REG_DWORD    0x1
        
    #执行修改
    PS> reg add "HKEY_CURRENT_USER\AppEvents\EventLabels\WindowsLogon" /v ExcludeFromCPL /t REG_DWORD /d 0
    
    Value ExcludeFromCPL exists, overwrite(Yes/No)? yes
    The operation completed successfully.
    ```

### 其他备用操作

- 如果上述操作不生效,可以尝试以下方案

- ```bash
  reg add HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Authentication\LogonUI\BootAnimation /t REG_DWORD /d 1 /v DisableStartupSound
  ```

- 实操

  - ```bash
    PS C:\Users\cxxu\Music\rings> reg add HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Authentication\LogonUI\BootAnimation /t REG_DWORD /d 1 /v DisableStartupSound
    
    Value DisableStartupSound exists, overwrite(Yes/No)? yes
    The operation completed successfully.
    ```
