## windows 常用配置工具

在 Windows 操作系统中，注册表、组策略和本地安全策略都是用于管理和配置系统设置的重要工具。它们各有优劣势，适用于不同的管理场景。

### 1. 注册表 (Registry)

#### 定义
注册表是一个层次结构的数据库，存储了操作系统和应用程序的配置和选项。

#### 主要特点
- **范围广泛**：注册表包含系统和应用程序的所有配置信息。
- **灵活性高**：几乎所有系统和应用程序设置都可以在注册表中找到和修改。
- **风险高**：错误修改注册表可能导致系统不稳定或无法启动。

#### 常用位置
- **HKEY_LOCAL_MACHINE (HKLM)**：包含系统范围的设置。
- **HKEY_CURRENT_USER (HKCU)**：包含当前用户的设置。

#### 使用方法
- 使用注册表编辑器 (regedit.exe) 进行查看和修改。
- 可以通过脚本或程序批量修改。



### 2. 本地组策略 (Local Group Policy, gpedit.msc)

#### 定义
本地组策略是用于配置和管理计算机和用户的策略设置的管理工具。

#### 主要特点
- **图形界面**：通过图形界面配置设置，易于使用。
- **分级结构**：分为计算机配置和用户配置，分别影响整个计算机和单个用户。
- **集中管理**：适用于本地计算机和小型网络环境，不适用于域环境。

#### 常用位置
- **计算机配置**：影响所有用户的设置。
- **用户配置**：影响特定用户的设置。

#### 使用方法
- 使用组策略编辑器 (gpedit.msc) 进行配置。
- 可通过模板管理和设置安全、软件、脚本等。

#### 示例
禁用任务管理器的组策略路径：
```plaintext
路径: 用户配置 -> 管理模板 -> 系统 -> Ctrl+Alt+Del 选项
设置: 删除任务管理器
状态: 已启用
```

### 3. 本地安全策略 (Local Security Policy, secpol.msc)

#### 定义
本地安全策略是用于管理计算机上安全设置的工具，主要关注账户策略和安全设置。

#### 主要特点
- **专注于安全**：专门用于安全相关的配置。
- **细粒度控制**：提供详细的安全设置选项，如账户策略、审计策略和用户权限分配。
- **本地化管理**：主要适用于本地计算机和工作组环境。

#### 常用位置
- **账户策略**：密码策略和账户锁定策略。
- **本地策略**：审计策略、安全选项、用户权限分配。

#### 使用方法
- 使用本地安全策略工具 (secpol.msc) 进行配置。
- 配置密码复杂度、最小密码长度、账户锁定阈值等。

#### 示例
设置最小密码长度：
```plaintext
路径: 本地策略 -> 账户策略 -> 密码策略
设置: 最小密码长度
数值: 8
```

### 比较总结👺

| 特性             | 注册表 (Registry)                            | 本地组策略 (Local Group Policy) | 本地安全策略 (Local Security Policy) |
| ---------------- | -------------------------------------------- | ------------------------------- | ------------------------------------ |
| **作用范围**     | 系统和应用程序的所有设置                     | 计算机配置和用户配置            | 安全相关的策略                       |
| **配置方式**     | 手动编辑，脚本和程序                         | 图形界面配置                    | 图形界面配置                         |
| **易用性**       | 较复杂，需谨慎操作                           | 相对简单，适合图形界面用户      | 相对简单，专注于安全设置             |
| **管理粒度**     | 细粒度                                       | 中粒度                          | 细粒度                               |
| **主要适用场景** | 深度系统配置和应用程序设置                   | 计算机和用户策略配置            | 安全策略配置                         |
| **风险**         | 较高，不正确操作可能导致系统不稳定或无法启动 | 较低，图形界面减少错误可能      | 较低，主要影响安全设置               |

这三个工具各有特点，用户可以根据具体需求选择合适的工具进行系统和安全配置管理。

## 本地安全策略组



### 配置安全策略设置

本文描述了在本地设备、加入域的设备和域控制器上配置安全策略设置的步骤。您必须拥有本地设备的管理员权限，或者您必须具有在域控制器上更新组策略对象（GPO）的适当权限才能执行这些程序。

当本地设置无法访问时，表明当前有一个GPO控制该设置。

### 使用本地安全策略控制台配置设置(secpol)

1. 要打开**本地安全策略**，请在**开始**屏幕上输入**secpol.msc**，然后按ENTER键。
2. 在控制台树的**安全设置**下，请执行以下操作之一：
   - 选择**账户策略**以编辑**密码策略**或**账户锁定策略**。
   - 选择**本地策略**以编辑**审核策略**、**用户权限分配**或**安全选项**。
3. 当您在详细信息窗格中找到策略设置时，双击要修改的安全策略。
4. 修改安全策略设置，然后选择**确定**。

备注：
- 某些安全策略设置需要在设置生效之前**重新启动设备**。
- 对账户的用户权限分配的任何更改将在账户所有者**下次登录**时生效。

### 使用本地组策略编辑器控制台配置安全策略设置(gpedit)

您必须拥有安装和使用Microsoft管理控制台（MMC）的适当权限，并且必须具有在域控制器上更新组策略对象（GPO）的权限才能执行这些程序。

1. 打开本地组策略编辑器（gpedit.msc）。
2. 在控制台树中，单击**计算机配置**，选择**Windows设置**，然后选择**安全设置**。
3. 请执行以下操作之一：
   - 选择**账户策略**以编辑**密码策略**或**账户锁定策略**。
   - 选择**本地策略**以编辑**审核策略**、**用户权限分配**或**安全选项**。
4. 在详细信息窗格中，双击要修改的安全策略设置。
   - 备注：如果此安全策略尚未定义，请选择**定义这些策略设置**复选框。


5. 修改安全策略设置，然后选择**确定**。
   - 备注：如果您想为网络上的多个设备配置安全设置，您可以使用组策略管理控制台。
